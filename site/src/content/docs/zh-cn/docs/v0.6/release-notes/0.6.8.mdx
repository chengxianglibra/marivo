发布于 2026 年 11 月 17 日。Marivo 0.6.8 统一了 Population 操作，改进了数据源
错误诊断，并修复了分析结果正确性问题。

## 亮点

- Population 分类会追加字段或标识角色，并保留完整的输入坐标组合。使用 `project`
  显式选择坐标轴，使用 `where` 筛选已有坐标值。
- 标量字段、标识角色、image 和 preimage 使用显式的 `mv.path(...)` 关系路径。
  路径可以指定源和目标的版本时间；image 返回去重后的目标标识，preimage 保留
  完整的输入坐标组合。
- 已认证的读取服务通过 `/v2/semantic/objects/{id}/datasource-properties` 返回
  当前 Catalog 快照中允许公开的数据源配置。项目令牌持有者可看到允许的连接配置和
  DuckDB 路径；宿主需负责用户授权，密钥应放在凭据引用中，而非配置字面值中。

## 变更

- **Population 迁移：**`mv.identity` 描述标识轴；成员所属时间由
  `session.members(..., at=...)` 指定。请使用 `mv.path(...)` 构建关系路径，
  并在路径上指定源与各步骤的版本，替代关系元组和 `image(..., at=...)`。
  `classify` 会保留原有轴，需要减少轴时请使用 `project`。
- `session.read(..., on=...)` 保留 Population 坐标，并可显式选择标识角色；
  `identities(on=...)` 从角色中提取去重后的直接 Entity 标识。已捕获的 Frame 坐标
  可用于后续筛选，无需重新读取数据源。
- 原生 SQL 失败时提供结构化原因、已观察到的执行状态及有长度限制且已脱敏的后端
  诊断；识别出原因时提供针对性修复建议。

## 修复

- 原生样本归约保留必要的标识与成员校验，包括空样本；查询准备阶段也会保留源归约
  所需的分支。
- 不兼容的 Decimal 比较现在会抛出结构化语义错误。
- 当区间范围已先行检查时，不支持的聚合错误不再错误地声称没有读取业务数据。
- 时间坐标的成员判断同时匹配时间与普通坐标。当区间报表依赖数据源或 Frame 的键时，
  会在读取依赖的 Metric 前检查输出范围。

## 文档

- 更新 Population 和数据源指南，补充版本化路径及 Trino SQL 排障说明，并增加
  一篇介绍智能体友好型工具的中英文文章。
- 将 v0.6 读取服务指南同步到当前的 DataFrame 引用和 Catalog 接口。

## 内部

- 增加可选的形式化验证门禁，加强公共 Help、类型和指南的一致性检查。
