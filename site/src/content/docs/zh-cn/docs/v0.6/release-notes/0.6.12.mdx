发布于 2026 年 11 月 20 日。Marivo 0.6.12 改进了分析结果的正确性和执行性能。

## 亮点

- 显式 Metric 样本在每个输出层和嵌套样本层按完整共享坐标匹配，区间按精确边界匹配；没有相容样本的输出行仍会保留。详见 [Population](/zh-cn/docs/v0.6/analysis/population/#explicit-metric-samples)。
- Frame 执行复用分组和行索引，对整数比较及规约进行向量化，并合并符合条件的相邻筛选，减少重复计算。

## 修复

- Population 计数和样本规约按实际日历与区间坐标匹配，并根据事实坐标检查必需的输出覆盖范围。
- MySQL 系列数据库的整数求和结果按绑定整数类型进行范围校验和转换。
- 修正语义搜索和关系绑定的实时 Help 示例。

## 文档

- 重写分析代数指南，围绕输出键、贡献出现、缺失值以及等价改写的条件说明分析语义。

## 内部改进

- 将可选的数据源 Runtime 测试环境整合到共享 Podman 环境。
