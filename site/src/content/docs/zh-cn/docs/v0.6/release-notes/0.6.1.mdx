发布于 2026 年 11 月 4 日。Marivo 0.6.1 改进了 0.6 API 的后端兼容性和数据源读取可靠性。

## 亮点

- MySQL 和 MariaDB 字符串维度在 Attribute 分组、成员判断和共用的观测筛选中使用源列的排序规则。
  已完成的 Frame 和跨期对齐保留各端点实际返回的字符串；不同的分组代表值仍视为不同的键。
- 原生日历计算支持 MariaDB 10.3，并继续支持当前 MySQL 和 MariaDB 版本，无需 `JSON_TABLE`。

## 变更

- `duckdb`、`all` 和 `dev` 可选依赖将 DuckDB 约束从固定的 1.5.3 调整为 `>=1.5.3,<2`。
  已使用 DuckDB 1.5.6 和 Ibis 12.0.0 验证兼容性。
- ClickHouse 数据源读取在识别到临时容量、连接或网关故障后，按带随机抖动的退避间隔最多重新提交两次相同查询。
  超时、内存限制及未识别错误直接传播，不触发 Marivo 重试。驱动状态重试默认关闭；显式设置正数
  `extra["query_retries"]` 可启用额外的驱动尝试。

## 修复

- 后端断开失败后，后续关闭会再次尝试断开，只有断开成功才记录为已释放。
- MySQL 读取器在 MySQL 和 MariaDB 原生超时设置均不可用时，会在业务读取前失败，避免未执行请求的超时约束便继续读取。
- DuckDB 域捕获在成功和失败后均恢复原始数据源绑定，包括准备捕获期间发生的失败。
- DuckDB 和 ClickHouse 的 UInt64 聚合输入改写仅作用于聚合分支，保留 DISTINCT、UNION 等其他使用方的精确 schema。

## 文档

- 更新中英文后端指南，说明依赖约束、ClickHouse 重试和 MySQL/MariaDB 字符串比较行为。

## 内部改进

- 执行时复用已完成资格检查且不带参数的编译读取。
- 增加 MySQL/MariaDB 跨版本日历和字符串归因回归覆盖，并加强断开、超时和域捕获测试。
