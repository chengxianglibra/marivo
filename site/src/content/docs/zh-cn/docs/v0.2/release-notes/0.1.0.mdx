Marivo 0.1.0 是 Marivo 的第一个公开版本：一个面向智能体驱动的 analytics 的
原生 Python 语义建模与分析库。

## 重点

- 用 Python 声明数据源、领域、实体、维度、指标和
  关系。
- 目录加载与就绪检查会在分析前阻止未完成的语义对象。
- 以指标为中心的分析会话，提供 observe、比较、decompose、
  correlate、forecast 和质量检查等类型化操作。
- 类型化 frames 作为分析步骤之间的边界，提供有界展示和可复现的操作交接。
- 记录证据项、命题和评估，让分析结果可以追溯回输入。
- 随包提供面向智能体的语义编写与分析流程技能。
- 静态文档站点提供隔离的 `latest` 和 `v0.1` 快照。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[all]"
```

Marivo 0.1.0 需要 Python 3.12 或更高版本。

## 包含的后端

Marivo 为 DuckDB、MySQL 和 Trino 提供可选扩展。数据源 credentials
通过项目状态中的环境变量引用，而不是直接写入语义声明。

## 当前范围

- Marivo 0.1.0 是面向 early adopters 的 alpha release。
- 公共接口以 Python 库为中心：`marivo.datasource`、`marivo.semantic`
  和 `marivo.analysis`。
- Marivo 不是 hosted service、聊天界面或 text-to-SQL 包装器。
- 在稳定的 1.0 release 之前，API 细节仍可能变化。
