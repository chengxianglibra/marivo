Marivo 0.2.6 是 v0.2 系列的补丁版本发布，聚焦 Trino 和 MySQL 上由字符串支撑的
时间维度。作者仍然编写 Python `strptime` 格式，Marivo 会在 SQL emission 阶段
翻译后端特定日期解析令牌。

## 重点

- Trino 和 MySQL 分析路径现在会在解析字符串时间维度时，把 Python
  `strptime` 格式翻译为 MySQL-compatible 日期解析格式。
- Python `%M` 在 Trino/MySQL 上现在会保持作者期望的 minute 语义，并翻译为 MySQL `%i`；
  `%S` 也会翻译为 MySQL `%s`。
- `%Y-%m-%d %H:%M:%S` 这类常见时间戳格式现在可以在 DuckDB、Trino、MySQL 和
  Postgres-backed 分析路径中保持一致。

## 修复

- 修复使用 Python `%M` 编写 minute-granularity 字符串时间维度时，Trino
  `date_parse` 和 MySQL `STR_TO_DATE` SQL 会 malformed 的问题。
- MySQL-家族后端上不支持或含义分歧的 Python directives 现在会产生清晰的
  分析错误，而不是静默生成语义不同的 SQL。

## 文档

- 更新语义层时间-字段格式设计和文档，说明 Python `strptime` 格式的
  后端 translation 边界。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.6 需要 Python 3.12 或更高版本。
