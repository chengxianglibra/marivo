Marivo 0.2.0 收紧了 0.1.0 中引入的面向智能体的语义与分析
契约。这个版本增加了更明确的语义编写辅助函数，缩小公共
surfaces，并修复智能体在写入-运行-读取流程中依赖的证据与分析
结果细节。

## 重点

- 新增语义列编写辅助函数，让智能体可以用更小、更类型化的
  接口声明列含义。
- 新增 `ms.count(entity=...)` 辅助函数，作为实体 count 指标的唯一公共
  route。
- 用经过验证的 `ms.ai_context(...)` 构造器替换原始类型化-dict 上下文
  形状。
- 收紧数据源与语义公共接口，减少辅助函数发现中的歧义或
  internal 路径。
- 新增由 GitHub Release 驱动的 PyPI Trusted Publishing，方便后续版本发布。

## 变更

- 语义值对象在进入声明前会通过公共构造器验证。
- 半可加指标的 `over=...` 现在必须提供明确的时间维度引用。
- 可加性帮助与验证 messages 现在统一使用 underscore enum 值。
- 移除了运行时 startup 中的 startup garbage 集合。

## 修复

- 半可加指标 ledger 证据现在可以 JSON serialize。
- Point anomaly 候选现在会补齐 `observed_value`、`baseline_value` 和
  `delta`。
- `VerifyResult.render()` 现在会显示问题与警告的详情行，不再隐藏
  可执行内容。
- 实体 brief 展示请求头现在与底层列 profile 字段名称对齐。
- 语义装饰器 docstrings 现在可以被接受。

## 文档

- 新增语义列编写设计说明，并与公共 API principles 对齐。
- 修复不再匹配当前 API 的语义层文档示例。
- 新增 v0.2 文档快照，与 `latest` 和 `v0.1` 并列。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.0 需要 Python 3.12 或更高版本。
