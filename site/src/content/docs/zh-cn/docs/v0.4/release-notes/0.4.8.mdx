Marivo 0.4.8 扩展了类型化运行时组合和面向 agent 的发现流程，增强了 JSON
数据源投影能力，并让时间与质量证据的边界更加明确。

## 重点

- `mv.runtime_metric.linear(add=[...], subtract=[...], label=...)` 可以在受治理的
  指标上构造有边界的加减组合。该表达式支持 replay、嵌套组合、组成成分元数据、
  readiness 和观测；运行时会统一数值子项，使 Decimal 和 float 指标可以共同参与计算。
- `md.json(...)` 现在支持列表形式的 query、body 和运行时 source 参数，并会在 authoring
  与 snapshot 中保持往返一致。Schema 字段可以用 `a.b`、`a[0].b` 和 `a[].b` 等点号、
  索引或数组遍历路径选择嵌套值；声明类型会在执行前按 Ibis 类型字符串校验。
- 分析发现流程现在从紧凑的根帮助和受保护的首次观测路径开始。语义 catalog 可以从
  类型化集合查找继续进入 details 和类型化 ref，不需要 agent 手工重建 registry key。
- 多轴归因默认采用 `joint`；`decompose` 和 funnel 模式仍需显式选择，返回结果的
  contract 会暴露实际采用的模式。

## 变更

- 语义周期观测现在区分范围覆盖与数据到达。Frame 会暴露已观测数据范围和完整数据
  信号；当尾部周期被数据截断时，evidence 会明确标记，而不会把它当作完整周期。
- 多指标融合观测会保留物化 Frame 上的语义周期元数据，包括可用时的输出周期 key。
- 周期查找修复保持为基于日历 details、枚举和 readiness 的过程，不再提供采样得到的
  key 候选。
- Quality assessment 会校验可接受的 Frame 形状，并可在线序列和 panel Frame 上发现
  value density 偏低的问题，给出结构化修复指引。
- Readiness 会把缺少 guardrails 的情况聚合成一条 warning，并在 details 中保留受影响
  的 refs，让真正的 blocker 更容易被看见。

## 修复

- Catalog 查找现在可以往返解析展示出来的同类型化 key，同时保留 kind 与 scope 校验；
  对缺失、格式错误或类型不符的 key 会给出明确失败信息。

## 安装

国内网络建议运行：

```bash
curl -fsSL https://marivo.io/install-marivo-cn.sh | bash
```

也可以使用标准安装器：

```bash
curl -fsSL https://marivo.io/install.sh | bash
```

手动安装：

```bash
pip install marivo
```

请为计划使用的数据源安装对应后端扩展。Marivo 0.4.8 要求 Python 3.10 或更高版本。
