Marivo 0.2.8 是 v0.2 系列的补丁版本发布，聚焦面向智能体分析 workflows。
它新增只读 `marivo doctor` 诊断命令，将 `observe(...)` 扩展到同一范围下的
多指标观测，在会话知识中记录有界观测摘要，并收紧
若干 observe planner 边界情况。

## 重点

- `marivo doctor` 现在可以在智能体开始编写或运行分析 work 前，执行只读的
  environment、项目、语义和数据源检查。它可以检查语义文件，并可选验证
  数据源 connectivity。
- `observe(...)` 现在接受同一范围下的非空指标序列，用于多指标
  观测。Marivo 会融合兼容的执行工作，投影请求的指标列，并将本次观测
  记录为一个证据步骤。
- 会话知识现在包含 `observe(...)` 和 `derive_metric_frame(...)` commits 的有界
  观测摘要。智能体可以复查已经观察到的内容，而不必重新读取完整 frames。

## 变更

- `marivo init` 现在会把 bundled 技能安装到共享 `.agents/skills` 目录，同时保留 Claude
  代码和 Codex 兼容性目标。
- 分析意图现在会通过 frames、血缘和帮助输出携带显式 purpose，使证据
  能说明一个结果为何被产出。

## 修复

- 扩散-side `where` 切片现在会在 merge-粒度 distinct 规划前应用，从而让
  跨数据集 observe 结果与已编写 filters 保持一致。
- 基础 observe 查询会在执行前裁剪未使用的投影，减少不必要的 selected 列。
- Slice 集合 shorthand 会在执行前被一致地归一化。
- ClickHouse 数据源编写会在不支持 autogenerated SQLAlchemy 会话的场景中禁用该行为。

## 文档

- 新增多指标观测、观测摘要、`marivo doctor` 和共享 `.agents/skills`
  安装目标的文档与示例。
- 新增多指标 observe 和累计指标的设计规范。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.8 需要 Python 3.12 或更高版本。
