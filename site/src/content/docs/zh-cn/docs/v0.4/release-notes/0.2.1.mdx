Marivo 0.2.1 是 v0.2 系列的补丁版本发布。这个版本修复了报告-本地时间桶
normalization，并让语义文档继续对齐当前面向智能体的契约。

## 重点

- 修复报告-本地桶 timestamps，确保 windowed 分析结果保留预期的
  报告时区语义。
- 清理语义对象文档、帮助 text 与技能中已经过时的 `description`
  引用。
- 打磨中文 `latest` 文档文案，提升可读性和术语一致性。

## 修复

- 分析 executor 现在会一致地归一化报告-本地桶 timestamps。
- 采样 folded observe 结果现在保留预期的桶 encoding。
- 查询记录现在会保留归一化后的报告-本地时间戳形状。

## 文档

- 让语义层站点示例对齐当前元数据契约。
- 移除语义对象指引中过时的 `description` 引用。
- 为 v0.2 和 `latest` 文档快照增加本次补丁版本发布说明。

## 破坏性变更

- 该历史版本的数据源编写证据当时迁移到 historical 发现 API 家族，
  并保留原始-SQL 诊断 escape hatch。`latest` 指南不把已移除 symbols 写成可运行 API；
  immutable v0.2 文档保留准确的 release-era API history。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.1 需要 Python 3.12 或更高版本。
