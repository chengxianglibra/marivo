Marivo 0.4.1 扩展了累计指标与非可加指标的类型化分析能力，加入本体-guided
语义发现，并进一步收紧面向智能体的公共契约，使分析结果更确定、更可验证。

## 重点

- 累计观测现在持久化 evaluation cutoff 与可比周期证据。分析支持
  累计层级比较、all-history 层级变更与累计归因，并对范围、
  cutoff 和对账做显式验证。
- 归因支持去重计数与分位数度量，提供独立的 multiresolution 执行、
  类型化证据和失败即停止产物校验。
- 本体编写与目录加载支持单边语义 hypothesis 发现、稳定的
  候选选择，以及候选身份和血缘。
- 类型化度量绑定成为指标轴解析的权威来源。分析只按声明的轴
  对齐，保留相关单位状态，并将漏斗可用操作收敛为封闭集合。
- Installer 使用 uv 管理 Unix 与窗口 Bash 环境。默认安装覆盖 DuckDB、Trino 和 ClickHouse；
  MySQL 仍需显式 opt-in。

## 破坏性变更

- 公共 `LineageStep`、`Lineage`、`FrameSummaryEntry`、`JobSummary` 和 `SessionSummary`
  数据 class 改为仅支持 keyword 参数构造。
- 删除无界的 `session.list`，请改用有界的 `session.recent(...)` 与 `session.inspect(...)`。
- 分析产物身份统一为仅引用；原有 identifier alias 需要迁移到规范 `.ref`
  契约。
- 删除旧的会话 alias、兼容性 shim 与无调用的错误；请使用规范公共名称
  与条目 point。
- All-history 累计比较表示为带 evaluation-end 证据的层级变更，而不是
  区间-流程 equivalence。

## 变更

- 分析会在执行前拒绝与结果 protocol 列冲突的维度/输出列，并验证
  多指标轴与覆盖率契约。
- 归因 hierarchy 列使用 namespaced layout；不支持的归因输入会收到可执行
  的修复指引。
- Development 依赖默认不再安装 MySQL，type checking 基线升级到 mypy 2.3。

## 修复

- 累计 comparable-周期对齐对不支持的旧版日历标识符失败即停止，并在
  加载时校验持久化证据。
- 面板 forecast 轴、folded 派生指标、跨实体粒度 requirement 与产物 reuse
  purpose 现在都有显式校验或元数据记录。
- 实时帮助目标、公共导出与运行时 representation 保持确定性，并与已安装指引
  对齐。

## 文档

- 新增累计比较、累计归因、不可加归因、本体
  extension 与面向智能体公共接口规范。
- 更新中英文指标-首个分析流程、语义层指南与跨平台安装说明。

## 安装

```bash
pip install marivo
```

请为计划使用的数据源安装对应后端扩展。Marivo 0.4.1 要求 Python 3.12 或更高版本。
