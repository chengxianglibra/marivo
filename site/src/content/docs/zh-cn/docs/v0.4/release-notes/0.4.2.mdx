Marivo 0.4.2 统一了 semantic authoring、analysis selection、alignment、evidence 与
forecasting 中的 temporal semantics，加入可认证的自定义周期、命名 occurrence、工作日
schedule，以及让这些能力可复现的类型化契约。

## 重点

- Temporal semantics 现在由彼此独立、可复用的 authority 组成：`PeriodCalendar` 负责 fiscal
  与 retail period，`TemporalSet` 负责命名的 interval 或 date，`WorkSchedule` 负责经过认证的
  working-day 状态。`Grain`、`TimeScope` 与 `AlignmentPolicy` 会携带精确的语义 variant 和
  provenance。
- Semantic authoring 与 catalog loading 支持认证 period calendar、calendar level、temporal
  occurrence 和 work schedule。Analysis 复用 project-local 的精确 snapshot 与 digest，不再在
  不同路径中独立推导 boundary 或 holiday。
- Certified semantic grain 支持 observation、roll-up、comparison 和 custom-period forecasting；
  它们使用带精确 key 与 bound 的 ordinal period。Snapshot 不完整、过期或不匹配时，会在写入
  artifact 前 fail closed。
- Comparison 新增类型化的 `period_progress`、`period_correspondence`、`occurrence_progress`
  与 `working_day_progress` policy，分别用于周期内等进度、命名 period 映射、命名 occurrence
  和 working-day ordinal 对齐。

## 破坏性变更

- Temporal authority 必须使用精确的 typed semantic reference 或 catalog entry。Analysis 不再
  从名称、locale 或 analysis-local 参数推断 fiscal period、holiday、occurrence 或 working-day
  状态。
- Analysis artifact 使用 `analysis-artifact/v8`。旧 artifact schema 以及
  `component_graph_ref` 等已移除字段会 fail closed，不再迁移或 dual-read；升级后请重新创建
  analysis session。

## 变更

- Temporal binding、period correspondence、occurrence scope、work schedule 和 alignment policy
  以类型化 evidence 持久化，其中包括 authority ref、snapshot digest、boundary timezone 与精确
  的半开区间边界。
- Frame metadata 现在保留 coverage 与 quality 计算所使用的 report timezone；计算 coverage ratio
  前会先 canonicalize 混合 timezone。
- Public error 与 contract 对缺失 temporal authority、无效 coverage、保留列和不支持的 metric
  arity 给出更精确的修复位置。Live help、public export 与 runtime surface 保持确定性一致。
- Documentation site 新增双语首页与 design blog，补充搜索和 indexing signal，并将 Sphinx API
  reference 纳入 repository check。

## 修复

- Comparison 与 correlation evidence 现在绑定到报告实际使用的精确 period 或 lag。
- 没有 coverage sidecar 时不再声称存在 coverage；attribution extraction 失败也不会隐藏仍可
  读取且可 reconciliation 的行。
- Certified roll-up key、temporal occurrence identity 和 forecast period boundary 在持久化与重新
  加载过程中得到保留。

## 文档

- 新增 unified temporal semantics specification，覆盖 period calendar、temporal set、work
  schedule、grain、scope 与 alignment。
- 更新中英文 analysis workflow，说明 certified temporal selection、alignment、working-day
  comparison 和 semantic-grain forecasting。

## 安装

```bash
pip install marivo
```

请为计划使用的 datasource 安装对应 backend extra。Marivo 0.4.2 要求 Python 3.12 或更高版本。
