Marivo 0.3.1 通过窗口化累计指标、证据优先的数据源编写流程和更安全的分析保护，
进一步强化了面向智能体的编写与分析工作流。

## 重点

- 累计指标现在通过 `ms.cumulative(...)` 上新增的 `anchor=` 参数支持三种累计锚点。
  `anchor=None` 保留 v1 的全部历史累计。`ms.grain_to_date(grain=...)` 在每个重置粒度边界重置
  累计值（MTD / QTD / YTD / WTD）。`ms.trailing(count=..., unit=...)` 是固定大小的滚动窗口，
  空窗口为真零，部分窗口展示实际累计值。
- `transform.rollup(...)` 现在可以重新聚合累计 frame。传入 `grain=` 将时间轴重新分桶；累计
  frame 携带 `rollup_fold="last"`，因此每个周期贡献其周期末值。未携带折叠且不可重新聚合的
  frame 仍会被拒绝并给出教学错误。
- `compare` 现在按锚点分派。`all_history` 维持拒绝；当两个 frame 共享相同锚点负载时
  `trailing` 允许；对单周期、边界锚定的窗口 `grain_to_date` 允许，并在结果 DeltaFrame 上记录
  to-日期对齐信息。
- 数据源编写现在遵循证据优先的快照流程。类型化目录对象、限定范围的检查和持久化
  证据替代了旧的宽泛发现流程，帮助编写者从真实来源证据一次形成一个
  语义对象。
- JSON 现在是 DuckDB 的一等文件来源。Marivo 可以与其他支持的数据源输入一起检查和使用
  本地或 HTTP JSON 数据。
- 分析分解现在支持显式的多轴归因 mode；质量评估也会在后续分析把结果视为
  可靠之前，阻断不安全的小时级覆盖范围。

## 变更

- `contract()`、`show()` 和 `mv.help(ref)` 现在会呈现锚点特定的注意事项，因此在你正在阅读的
  frame 上即可看到允许的路径。
- `rollup` 转换表条目现在将 `grain` 与 `drop_axes` 一并列出。
- 语义层与分析流程站点文档（EN + CN）记录了粒度兼容规则（在
  month/quarter/year 重置下使用 week 粒度是非法的）与整数倍规则（尾随 span 必须是查询
  粒度的整数倍）。
- installer 现在可以初始化 Marivo 项目，同一个安装脚本也可通过
  `https://marivo.io/install.sh` 获取。

## 修复

- 就绪检查会拒绝未声明的 naive 时间轴，避免将含糊的时间语义带入分析。
- 类型化文件结构会在运行时保留，避免物化期间丢失已声明的来源结构。

## 文档

- 更新了语义层、分析流程、安装、快速开始和证据的中英文
  文档，覆盖精简后的智能体工作流。
- 新增累计指标 v2、数据源快照、类型化目录导航、JSON 来源和
  精炼后的分析接口的设计规范。

## 安装

```bash
pip install marivo
```

安装你计划使用的数据源对应的后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.3.1 要求 Python 3.12 或更高版本。
