执行日志记录查询与执行结果，使用遥测记录操作与耗时。它们都保存在本地；需要读取分析数值时，使用保存的 Frame。

## 找到正确记录

| 记录 | 位置 | 用途 |
| --- | --- | --- |
| 执行日志 | `.marivo/logs/execution-YYYY-MM-DD.NNN.jsonl` | 查看提交的 SQL、结果与耗时 |
| 使用遥测 | `.marivo/telemetry/events-YYYY-MM-DD.NNN.jsonl` | 查看操作、结果与耗时摘要 |

通过 query ID 对应一次 SQL 的提交和完成。

## 选择采集模式

| 模式 | 行为 |
| --- | --- |
| `on` | 默认模式，记录执行、失败、保存与复用等操作 |
| `full` | 记录更广泛的公开操作 |
| `off` | 关闭使用遥测，执行日志仍然保留 |

在 `marivo.toml` 中设置项目默认值：

```toml
[telemetry]
enabled = "off"
```

环境变量 `MARIVO_TELEMETRY` 可设为 `on`、`off` 或 `full`，优先于项目配置。

## 理解保留与分享

文件按 UTC 日和约 128 MiB 分段。历史记录通常保留 14 天，历史总量按 1 GiB 清理；当天文件不参与清理，因此整个目录可能超过该大小。

执行日志包含 SQL，可能带有业务条件和字面值。使用遥测可能保留会话问题和 SQL 的 reason。分享记录前检查其中是否有敏感内容。
