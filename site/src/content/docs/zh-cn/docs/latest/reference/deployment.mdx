## 在代理运行的位置部署 Marivo

Marivo 是 Python 库，不是托管服务。请在代理运行的环境中安装它，并将项目的数据源和
语义声明纳入版本控制。数据源凭据应通过 `*_env` 字段引用的环境变量提供，不要把凭据
提交到项目中。

如需从本仓库开发，请创建环境，以可编辑模式安装带有所需扩展的包，然后验证导入：

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev,duckdb,trino]"
.venv/bin/python -c "import marivo; print(marivo.__name__)"
```

安装后，在选定环境中运行 `marivo doctor`，核对 Marivo 版本、Python 可执行路径、加载的包路径
和项目状态。如果环境没有激活，请调用该环境中的 `marivo` 可执行文件。CLI 只负责 bootstrap
检查。进入 Python 后，查阅专项实时契约：

```python
import marivo

marivo.help("datasource.<target>")
marivo.help("semantic.<target>")
marivo.help("analysis.<target>")
```

对于使用已发布版本的项目，请按[安装](/zh-cn/docs/latest/installation/)说明安装所需的后端扩展，
`marivo init` 是可选命令；只有部署需要固化 manifest 或让宿主从文件系统发现智能体技能时才
运行。将已提交的语义层保留在代理可访问的位置，以便每次运行都解析同一组声明。
