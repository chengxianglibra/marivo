## 仅安装所选 driver

| 后端 | Extra | 配置事实 |
| --- | --- | --- |
| DuckDB | <code style="white-space: nowrap">duckdb</code> | 本地表及准入文件来源；教程无需服务器 |
| PostgreSQL | <code style="white-space: nowrap">postgres</code> | 只读账户及原生 libpq 前提 |
| MySQL | <code style="white-space: nowrap">mysql</code> | 原生客户端与构建前提，以及原生查询配置 |
| Trino | <code style="white-space: nowrap">trino</code> | 显式 catalog/schema、只读访问与原生查询配置 |
| ClickHouse | <code style="white-space: nowrap">clickhouse</code> | 准入 scalar types，分析要求有效 `join_use_nulls=1` |

Analysis 使用项目本地 SQLite 保存元数据，与数据源支持无关。

基础包包含本地结果所需 Arrow。发现未选择 provider 不导入其 driver。
所选依赖缺失时，typed repair 指明所需 extra。

## 准入具体数值路线

数值 Query 路线按所选 backend、来源形式、真实 schema 和具体方法准入。模板在 Run 准入前由实际后端编译；依赖实例化后仍在消费前校验。datasource 访问成功本身不构成数值 Runtime 资格。

{/* example: csv-semantic-model */}

```python
import marivo.datasource as md
import marivo.semantic as ms

facts = ms.entity(name="facts", datasource=ms.ref.datasource("warehouse"),
                  source=md.csv("data/facts.csv"),
                  primary_key=["tenant", "id", "revision"])
amount = ms.measure_column(name="amount", entity=facts, column="amount",
                           additivity=ms.additive_all())
happened = ms.time_dimension_column(name="happened", entity=facts,
                                    column="happened", granularity="second",
                                    parse=ms.timestamp(timezone="UTC"), is_default=True)
finalized = ms.finalize()
facts = finalized.resolve(facts)
amount = finalized.resolve(amount)
happened = finalized.resolve(happened)

@ms.metric()
def total():
    return amount.sum(time=happened)
```

此处声明字段和命名 Metric。声明或成功 preview 不授予所有 CSV/JSON/HTTP 分析形态资格；不支持的路线在受影响业务读取前拒绝。来源模板在 Run 准入前预验证，实际实例化输入仍会再次校验。

## 来源和本地执行

来源 Ibis 在所选声明 datasource 执行并返回 pandas；字面量/参照和本地域/值阶段使用 pandas，PyArrow 负责编码与读取终端输出。Artifact 是只读产物，不能进入 DSL；没有固定 Artifact 执行路线或隐藏本地 SQL 引擎。

来源计算接受 Ibis/provider 原生数值精度损失。Ibis lowering 不为统一后端返回类型或传输保真添加 cast，业务语义必需的转换仍保留。pandas 交接为直接字段、规约值和内部组件确定有效数值类型，供后续本地计算和发布使用，保留完整键、空值政策、单位和时间语义。cast 不能恢复来源精度；产物往返保真针对实际已提交值。

DuckDB 读取通过 Ibis Arrow 结果构造采用 nullable Arrow extension dtype 的 pandas 整数列。大整数与 null 共存时保持精确，不经过 float64 中间转换。本地计算仍使用 pandas；这项转换保证不推广到其他后端。

时间准备和 temporal rewrite 使用实际所选 engine。远端来源块在获得自身等价证据前采用未融合路线。本地计算是 eager，可能保留全部所需向量；失败不换路线或截断输入。

DuckDB 原生 INTERVAL 仅在来源侧检查拒绝 year、month、day 分量后按微秒准入，不能仅靠 cast 当作 elapsed time，也不会产生纳秒精度。合格文件路线中的 Arrow Duration 保留文件声明的 tick 单位。

PostgreSQL、MySQL、Trino 和 ClickHouse 的普通模板按真实类型和表达式准入 count、count_distinct、sum、min、max、mean 和 weighted_mean。精确来源 median/quantile 当前仅准入 DuckDB 和 PostgreSQL。MySQL、Trino 和 ClickHouse 在 Run 前按具体方法拒绝；ClickHouse 的 Ibis Quantile lowering 是近似算法，不能满足精确请求。精确/近似规约保留定义所属算法。缺必需映射、非有限、溢出及必要覆盖错误阻止发布。

ClickHouse Distributed 准入合格的普通分组聚合。需要 Distributed IN/JOIN 的来源路线（包括按键交接的 `Session.read`）因尚未具备 `distributed_product_mode` 下的 join 资格而在 Run 前拒绝。MergeTree join 单独准入，不隐式扩展到 view 或其它 engine 拓扑。Marivo 不修改服务器设置或替换为本地表。

## 资源和保存边界

datasource 原生 timeout 保留后端含义，没有默认图 deadline 或替代执行器。取消与 close 由驱动拥有，远端终止未知时保持未知。原子发布和 journal reconciliation 保留已提交成功及精确资源归属。

Store 11 保存项目本地输出。新产物与重开产物读取相同已提交数据，无需当前 Catalog/来源；旧图格式原样拒绝。完整导出保留 int64/Decimal、NA、presence、完整键、时区及投影。聚焦本地检查、远端 Runtime 与发布验收是不同证据。具体修复见[故障排查](/zh-cn/docs/latest/reference/troubleshooting/)。
