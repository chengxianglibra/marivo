Backend extra 安装 driver，连接证明可访问，二者都不授予全部分析方法。
准入依赖实际 backend、source form、有序物理类型、domain、时间依据、保留状态与 method。
当前 relation contract 和 focused Help 是操作依据。

## 仅安装所选 driver

| 后端 | Extra | 配置事实 |
| --- | --- | --- |
| DuckDB | <code style="white-space: nowrap">duckdb</code> | 本地表及准入文件来源；教程无需服务器 |
| PostgreSQL | <code style="white-space: nowrap">postgres</code> | 只读账户及原生 libpq 前提 |
| MySQL | <code style="white-space: nowrap">mysql</code> | 原生客户端与构建前提，以及原生查询配置 |
| Trino | <code style="white-space: nowrap">trino</code> | 显式 catalog/schema、只读访问与原生查询配置 |
| ClickHouse | <code style="white-space: nowrap">clickhouse</code> | 准入 scalar types，分析要求有效 `join_use_nulls=1` |

Analysis 使用项目本地 SQLite 保存元数据，与数据源支持无关。

基础包包含本地结果所需 Arrow。发现未选择 provider 不导入其 driver。
所选依赖缺失时，typed repair 指明所需 extra。

## 明确选择来源形态

DuckDB 表与本地 Parquet 是主要本地分析路径。CSV 和本地 JSON 适配器具有更窄的
原始 sum-zero 路径：完整 typed keys、准入数值和明确 UTC 事件轴。
HTTP JSON 声明与 preview 不授予 HTTP 分析执行能力。不能从另一适配器成功推断能力。

{/* example: csv-semantic-model */}

```python
import marivo.datasource as md
import marivo.semantic as ms

facts = ms.entity(name="facts", datasource=ms.ref.datasource("warehouse"),
                  source=md.csv("data/facts.csv"),
                  primary_key=["tenant", "id", "revision"])
amount = ms.measure_column(name="amount", entity=facts, column="amount",
                           additivity=ms.additive_all())
happened = ms.time_dimension_column(name="happened", entity=facts,
                                    column="happened", granularity="second",
                                    parse=ms.timestamp(timezone="UTC"), is_default=True)
finalized = ms.finalize()
facts = finalized.resolve(facts)
amount = finalized.resolve(amount)
happened = finalized.resolve(happened)

@ms.metric()
def total():
    return amount.sum(time=happened)
```
当前示例只声明来源和局部 Metric。R1.4 尚未发布该 Metric，R2 尚未接通新的表达式执行；因此不能将此构造片段作为 CSV 分析执行资格。来源类型或 preview 成功也不能证明新路线的执行能力。

## 理解执行路径

| 输入 | 行为 |
| --- | --- |
| Live sources | 已治理 Ibis 在来源执行并返回 pandas 数据，或为已注册本地算法准备 DataFrame |
| Fixed Artifacts | 持久化 Result Parquet 读入 pandas 后交给已注册本地 consumer |
| 混合 source 与 fixed | 在 Run 准入或任一业务输入读取前拒绝 |

准入的 Ibis 计划能够表达的关系工作留在数据源侧。Ibis 与 provider 负责把返回行转为
pandas，默认转换可能有损，例如把非法日期转为空值。Marivo 不再对来源数据增加严格
Arrow 往返审计。请求的行数/时间边界、完整键与 Cell 检查，以及既有 Result Parquet
schema 检查继续生效。源读取和本地统计都是 eager；完整向量可能载入内存。失败不切换
实现，也不通过其他 executor 重试。远程来源配置使用只读权限，仅使用后端支持的原生超时配置，
不支持则跳过。执行图没有默认期限，资源清理和原子发布仍必须完成。

准备分析会直接从声明路径读取本地 Parquet，不创建临时副本。Marivo 会在运行前后
检查文件身份和内容，发现变化时使本次 Run 失败；查询执行期间这项检查不提供文件系统快照。

## 遵守数值与方法限制

Decimal scale、timestamp precision、Duration unit、原始组成状态、完整网格和
各根路径仍是方法与保留状态契约。这些契约应用于 Ibis/provider 转换之后，不承诺来源到
pandas 的无损往返。Ibis 编译成功或 Readiness 通过不足以证明物理执行。
Quantile 精确性属于定义，不支持的精确聚合不回退到近似计算。
统计方法不能继承普通 scalar Metric 的后端支持。
