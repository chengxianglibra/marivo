先读结构化错误的 expected、received 与 repair，在修复边界时保持原业务含义。

## 环境和语义范围

使用所选环境的 `marivo doctor --project-root <project>`，并在同一环境安装所需 datasource extra。无效配置或缺失根目录按具体修复指引处理，凭据保留为环境引用。未知名称通过 Catalog 发现；连通性、readiness、有界 preview 与执行是不同证据。

## 完整键与 Query 归属

Column 属于当前精确 Query 输入。使用该输入的列，或先明确 align/broadcast 再组合独立输入。接续[本地教程](/zh-cn/docs/latest/guides/python-quick-start/)：

{/* example: repair-query-domain */}

```python
aligned = current.align(baseline, how="outer")
difference = aligned.select({"difference": aligned["left.revenue"] - aligned["right.revenue"]})
difference.contract().show()
```

exact 要求完整键唯一且完全对应，outer 通过独立 presence 保留缺侧。缺失值不能替代键或授权补零；字段 Null 是合法类别。完整元组成员谓词保留每个分量，使用 null-safe AND/OR，不能拆成各列独立成员测试。

属性读取使用 `session.read(population, {"name": field})`，域须为单个完整 Entity 身份轴且归属同一 Session。按需提供单值声明 field.via((relationship,)) 路径和精确 field.at(anchor)。缺少必需映射在消费前失败，后置筛选不能隐藏错误。没有 Population.read 或隐式 Session 查找；计算 Measure 应交 observe。

## 时间和数值政策

用 session.instant/time_scope 构造精确边界。naive Python datetime、歧义/不存在墙钟时刻、冲突日历权威须明确修复。ordinal 需要相同 Grain、相容时区/日历及完整名义桶；outer 不能修复半桶。日粒度闰日 previous_year 无对应，应明确 outer 或调整期间/粒度，不夹日。

除法默认 zero_denominator 为 null，仅当新被需求除法须失败时选 error；它不会覆盖输入子式政策。非有限、溢出和必要覆盖错误阻止发布。无合格物理路线是能力错误，不能改算法、来源或引擎来绕过。

## 终端输出与失败 Run

保留精确 Session/Artifact ID 和项目本地状态。`session.artifact(id)` 打开已提交元数据，产物不能传入 compare/observe 或转回 Query。对保存行使用 to_pandas；新来源计算构造新 Query。

已准入错误的 run_ref 定位精确 Run，通过 `session.get_run(run_ref).show()` 检查。修复后 execute 是新 invocation。reconciliation 解析原 journal，不重放计算；生命周期入口可清理未完成/失败 Run 的资源并保留历史。

旧 Store 原样拒绝。缺失/损坏输出不能在恢复时重跑来源补救；保留原状态，按要求使用全新当前格式项目。preview 限制只影响展示，不截断执行或完整导出。
