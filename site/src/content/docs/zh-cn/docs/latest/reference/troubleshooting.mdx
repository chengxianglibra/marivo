按现象选择修复。保留原错误，以及 Doctor 报告的解释器、包版本和项目根。 排查历史执行时，读取[执行日志](/zh-cn/docs/latest/reference/telemetry/)中的事件 runtime 身份；Doctor 只说明当前环境。

| 现象 | 如何确认 | 修复 |
| --- | --- | --- |
| 文档 API 不存在 | 检查版本与加载路径 | 使用匹配开发源码或对应版本指南 |
| 连接失败 | 检查命名环境变量、驱动、网络 | 修正配置，再运行来源测试 |
| 模型加载失败 | 检查重名、缺失引用、声明语法 | 修复指定文件；导入依赖修改后重启进程 |
| readiness 被阻止 | 查看所选物理依赖和时间产物 | 修复依赖或认证完整日历范围 |
| 方法不支持 | 检查后端、来源形式、表达式和类型 | 选择受支持方法或显式新观察，不能静默换指标 |
| 列或轴属于其他输入 | 查看句柄来自哪个确切 Frame | 从接收者重取句柄，或显式对齐输入 |
| 差异意外未知 | 检查行存在、空值和零基准 | 解释缺失，不能一律补零 |
| 时期比较拒绝 | 检查完整边界、时区与匹配规则 | 选择完整时期或受支持的显式对应 |
| 重开后无法贡献分析 | 保存数据没有来源声明 | 为新问题重建显式来源输入 |
| 保存结果无法读取 | 检查会话/结果 ID、缺文件与 Marivo 版本 | 保留状态，用原兼容版本读取旧数据 |

## 保存结果不确定时

先恢复所属会话，核对原事务，再考虑重新提交。显式重提可能产生另一份结果，也可能重新读取已变化来源。应及时保存返回 ID，没有隐式最新结果查询。

不要把删除 `.marivo/` 或强制初始化作为通用修复。旧状态不会自动迁移；保留它并用兼容环境读取导出，不兼容的新工作使用新项目。

通过 [Help](#查询已安装版本)查询错误的精确修复目标。 Frame/Column 校验指向拒绝输入的公共操作。例如，向 `over` 传入旧统计量会指向 `analysis.analysis_frame.over`，修复时应从接收 Frame 重建统计量；pending 导出指向 `analysis.analysis_frame.to_pandas`，应先求值再导出返回的 Frame。没有唯一公共所有者的内部错误仍可指向较宽的 Help。求助时附上去掉凭据和私有数据的最小复现。

## 查询 API

任务指南用于学习流程，Live Help 用于查询精确调用与限制，[Python API 参考](/api/)提供自动生成的英文参考。

### 查询已安装版本

```python
import marivo

marivo.help()
marivo.help("authoring")
marivo.help("analysis")
marivo.help("analysis.analysis_frame")
```

CLI 使用相同目标：`.venv/bin/python -m marivo help analysis`。已知返回对象时，`marivo.help(type(result))` 查询类型；属性通过字符串 Help 目标查询。

按当前缺少的信息选择入口，各主题不要求依次读取。

| 需要的信息 | Help 目标 |
| --- | --- |
| 已有语义输入、成员域或时间 | `analysis.inputs` |
| 指标观察、成员计数或新来源事实 | `analysis.source` |
| 构造 Frame 或对当前数据计算 | `analysis.frame` |
| 完整内存数值或保存结果 | `analysis.execution` |
| 查看数据、导出或读取保存审计 | `analysis.results` |
| 创建或恢复确切会话与保存 Frame 身份 | `analysis.sessions` |

已知目标可以直接查询。source 构造捕获显式问题，不读取业务数据；pending Frame 求值仍可能执行已捕获的来源依赖。完成或重开的 Frame 可以继续数据计算，但不会恢复原始来源声明。

编写定义时从 `authoring` 选择 datasource、semantic 或 ontology。datasource 区分连接、来源、检查和语义交接；semantic 区分模型定义、表达式角色、时间、目录查询和校验。精确 API 保留其自身目标，共同前缀不一定是主题页。

执行导入使用 `marivo.datasource as md`、`marivo.semantic as ms` 和 `marivo.analysis as mv`。通过 `mv.session.get_or_create` 创建会话，没有顶层 `marivo.session` 别名。

### 有效求助

记录 Doctor 显示的版本、解释器、包路径、项目选择、最小相关声明与代码、完整结构化错误、预期与实际结果。移除秘密和私有数据，通过仓库现有问题跟踪或贡献入口求助，不在示例中发布凭据。
