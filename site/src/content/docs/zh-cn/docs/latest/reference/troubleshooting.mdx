先读结构化错误的 expected input、received facts 和具体 repair。
修复所述边界时保留原业务含义；下一次调用不熟悉时再读确切 Help。

## 选择正确环境与项目

运行所选解释器的 `-m marivo doctor --project-root <project>`。Doctor 是只读的。
缺少可选配置使用默认值；无效 TOML 或配置的 layer root 缺失需要修复。
在同一环境安装所选 datasource extra。保持 secret 环境引用，验证所需 datasource
时不展示凭据值。

## 修复语义输入

未知 ref 需要通过 catalog 发现，而不是猜名称。Readiness blockers 属于所选语义闭包，
跟随确切 repair。Richness warnings 是建议性的。有界 preview 与 source-health 失败
不改变 Readiness，连接成功不能授权 Metric 方程。

## 修复混合输入

Python 教程绑定 `current`、`baseline`后，此故意失败示例把保存输入与 live 定义混合。

{/* example: mixed-input-setup */}

```python
saved_current = current.execute()
```

{/* example: mixed-input-error */}

```python
# This intentionally combines fixed and live inputs and must fail.
saved_current.compare(baseline).execute()
```

明确问题：像教程一样比较当前 live 定义，或执行两端后比较其兼容保留结果。
不要上传保存行绕过准入。物化选择前构造下游 live 观察，或跟随接收者要求的执行边界。

## 修复谓词与对应关系

这套独立 commerce 模型声明 order amount、customer region、order_customer 关系。`current`和 `reference`是兼容数量。

{/* example: verification-premises */}

```python
orders = session.members(ms.ref.entity("commerce.order"))
amounts = orders.read(ms.ref.measure("commerce.order.amount"))
regions = orders.read(
    ms.ref.dimension("commerce.customer.region"),
    via=ms.ref.relationship("commerce.order_customer"),
)
quotient = current.ratio(reference, align=mv.exact())
change = current.compare(reference, align=mv.exact())
quotient.contract().show()
```

先选择 Defined 值，再调用数值谓词。完整 typed key tuples、Session ownership 与单位
必须匹配。关系完整匹配信任消费契约，保留为未验证前提，不自动查询验证。
目标记录存在但字段为空时，仍返回 `Null(source_null)`；缺失目标操作数在字段消费时失败。
后续过滤或归约不能隐藏该失败：字段读取结果只消费一次，后续计算复用该结果。
这不构成匹配检查证明，也不新增缺失规则。
键配对固定 checked，未知键集合相等性会检查；适用声明和冻结构造证据仍有效。
compare 的缺侧可用 `align=mv.outer()` 显式保留。

时期比较通过 `align.time` 显式选择 ordinal、weekday、holiday 或 holiday_then_weekday，均输出规范 string 键。星期和节假日映射要求日粒度网格，节假日 occurrence 必须具有与对应网格时区一致的整日边界。exact 要求对齐键集合相等，outer keep
允许任一侧网格更长。`empty_value` 不能修复另一窗口外未观察的时间键：应改用
keep 或调整窗口。对齐输出保留两侧原时间投影，但不挂载 time_grid；时间分组、
runs、forecast 和显式 lag correlate 应在原端点上完成，再比较。普通筛选与行统计
仍遵循各自准入契约。

## 修复恢复与输出

保留确切 Session ID、Artifact ref 和项目本地状态。旧代拒绝读取且不迁移；
恢复不能通过重放来源修复不可读或缺失的所需数据。需要当前数据时，显式创建新的 live 结果。
`show(n=0)`可查看元数据，按需提高展示预算。展示限制不改变查询或执行预算。
