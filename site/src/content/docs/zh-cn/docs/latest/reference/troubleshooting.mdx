## 环境与语义范围

在选定环境运行 `marivo doctor --project-root <project>` 并安装所需 datasource extra。
未知身份按需发现 Catalog，凭据使用环境引用。readiness、preview、source health 与实际方法
求值是不同证据。同路径定义变化本身不拒绝旧输入，仍保留 kind/root/grain/unit/time/null 检查；
业务版本身份锚点是独立合同。

## 完整键与精确 Frame 句柄

Column/FrameAxis 属于精确输入；从接收者重新取得，或显式对齐完整轴。
同名、指纹或导出 attrs 不能重新绑定。继续[教程](/zh-cn/docs/latest/guides/python-quick-start/)：

{/* example: repair-query-domain */}

```python
aligned = current.align(
    baseline, on=((current.axes[0], baseline.axes[0]),), how="outer",
)
difference = aligned.select({"difference": aligned["left.revenue"] - aligned["right.revenue"]})
difference.show()
```

exact 要求唯一完整联合键对应；outer 保留缺侧与独立 presence，不自动补零。
Field Null 是合法类别。read 要求完整 Entity 身份域、非空字段、合法单值路径与版本锚点，
后置过滤不能隐藏必要错误。新来源事实要显式提供受治理输入与普通轴 population_from 映射；
on 必填，零轴允许 on=()。

## 时间与数值政策

使用 Session instant/time_scope。部分日历桶在 exact/outer 下都不能 match；outer 不能修复
缺失冻结数据。选择后不压缩原 ordinal。闰日 previous_year 无对应，选择合法政策或期间，
不夹日期。不支持的 offset 需要支持范围内的显式来源问题，不能静默切换规则。

除零政策只作用新算子，不覆盖严格子式。非有限值、溢出与必要覆盖失败阻止完成。
缺少执行路线不授权改算法、来源或精度。

## 精确数据恢复与发布 Run

保留 Session ID 与 frame.artifact.id，恢复该 Session 后用字符串调用
`session.persisted_frame(id)`。Frame 拥有数据操作，`.artifact` 拥有审计；
Artifact/ID 对象及 RawSqlResult 不是计算操作数。compute 失败不创建 Run；发布失败的
run_ref 指向精确 Run，reconciliation 解决原提交而不重算。
缺失或损坏的消费数据不是 cache miss，不能回放来源修复。

Store 12 拒绝所有旧 generation 数据且保持字节不变，不迁移或双读。缺少当前 generation 的
发现可返回 None/空而不暴露旧状态；create/get_or_create 不能绕过仅有旧 Store 的项目。
切换前用原版本导出必要结果，或保留兼容读取环境。预览限制只影响显示，不截断完整执行。

列明破坏性 API、量名、延期能力与恢复选择。
