## 确认访问与结构

读取数据行时，使用[有界样本](/zh-cn/docs/latest/guides/datasources/#限制行数据证据)，选择所需列并显式指定范围。范围必须包含正数 `max_rows` 与 `timeout_seconds`；后端可能跳过不支持的超时请求。`max_rows` 限制返回行数，不限制扫描字节数。只有显式设置 `persist_values=True` 时，样本值才会以明文保存在项目本地状态中。
