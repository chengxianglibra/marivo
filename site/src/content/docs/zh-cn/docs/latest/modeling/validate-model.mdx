## 先检查定义，再检查数据

编辑模型后，请在项目根目录运行检查。以下示例使用[本地 Python 教程](/zh-cn/docs/latest/start/python/)
中的 `sales.orders.amount` measure：

```python
import marivo.semantic as ms

catalog = ms.load()
amount_entry = catalog.get("measure:sales.orders.amount")
assert amount_entry.kind == "measure"
amount = amount_entry.value
catalog.readiness(refs=[amount]).show()
```

`ms.load()` 检查模型声明、引用、依赖循环和表达式契约。`catalog.readiness(...)`
检查所选物理输入和已认证的时间产物。这两步都不会打开数据源连接。

若要查看当前来源数据，请用显式有界范围调用 `catalog.preview(...)`。
`catalog.source_health(...)` 默认检查当前连接与结构；只有显式传入检查规则及其有界范围时，才会读取业务数据。
[加载与检查](/zh-cn/docs/latest/modeling/semantic-layer/#加载与检查)一节提供完整的预览和来源健康检查示例。
