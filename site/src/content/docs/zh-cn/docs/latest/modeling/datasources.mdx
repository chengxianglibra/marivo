---
title: 数据源配置
description: 配置 DuckDB、PostgreSQL、MySQL、ClickHouse 和 Trino 数据源。
---

Marivo 提供五种数据源构造函数。将声明保存在 `models/datasources/` 下；loader 收集配置时不会打开连接。按后端选择构造函数，再从 Entity 引用其名称。远程示例是配置模板：测试前请替换主机和数据库，并设置所引用的环境变量。

每张表列出构造参数及其 Python 默认值。省略可选值时，由后端、Marivo 适配器或驱动采用默认行为。测试连接前，请设置所引用的环境变量。

| 后端 | 构造函数 | 用途 |
| --- | --- | --- |
| DuckDB | `md.duckdb` | 本地数据库与文件来源 |
| PostgreSQL | `md.postgres` | PostgreSQL |
| MySQL | `md.mysql` | MySQL |
| ClickHouse | `md.clickhouse` | ClickHouse |
| Trino | `md.trino` | 分布式 catalog |

## DuckDB — `md.duckdb`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `name` | 是 | — | 项目内全局唯一的小写 snake_case 数据源名称，用 `ms.ref.datasource(name)` 引用。 |
| `path` | 否 | `':memory:'` | DuckDB 文件路径，`":memory:"` 为进程内数据库；教程使用文件。 |
| `read_only` | 否 | `False` | 为 True 时只读打开数据库。 |
| `http_scope` | 否 | `None` | 限定远程 JSON 认证范围的 HTTP(S) URL 前缀；指定 HTTP 认证方式时必须提供。 |
| `http_bearer_token_env` | 否 | `None` | Bearer token 的环境变量名；与请求头认证互斥。 |
| `http_headers_env` | 否 | `None` | HTTP 请求头名到保存秘密值的环境变量名的映射；与 Bearer 认证互斥。 |
| `ai_context` | 否 | `None` | 可选 `ms.ai_context(...)` 业务上下文与使用约束。 |
| `extra` | 否 | `None` | 未在此列出的其他 JSON 可序列化 Ibis 连接参数。 |


```python
# models/datasources/warehouse.py
import marivo.datasource as md

md.duckdb(name="warehouse", path="warehouse.duckdb", read_only=False)
```

精确参考：`marivo.help("datasource.duckdb")`.

## PostgreSQL — `md.postgres`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `name` | 是 | — | 项目内全局唯一的小写 snake_case 数据源名称，用 `ms.ref.datasource(name)` 引用。 |
| `host` | 是 | — | 数据库服务器主机名或 IP 地址。 |
| `database` | 是 | — | 要连接的数据库。 |
| `port` | 否 | `None` | 连接端口；使用非默认端点时请显式指定。 |
| `schema` | 否 | `None` | 表解析使用的默认 schema。 |
| `autocommit` | 否 | `None` | 驱动自动提交行为的覆盖值。 |
| `user_env` | 否 | `None` | 保存数据库用户名的环境变量名。 |
| `password_env` | 否 | `None` | 保存密码的环境变量名。 |
| `ai_context` | 否 | `None` | 可选 `ms.ai_context(...)` 业务上下文与使用约束。 |
| `extra` | 否 | `None` | 未在此列出的其他 JSON 可序列化 Ibis 连接参数。 |


```python
# models/datasources/reporting.py
import marivo.datasource as md

md.postgres(
    name="reporting", host="postgres.example.internal", database="sales",
    port=5432, schema="public",
    user_env="PG_USER", password_env="PG_PASSWORD",
)
```

精确参考：`marivo.help("datasource.postgres")`.

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `name` | 是 | — | 项目内全局唯一的小写 snake_case 数据源名称，用 `ms.ref.datasource(name)` 引用。 |

| `password_env` | 否 | `None` | 保存密码的环境变量名。 |
| `ai_context` | 否 | `None` | 可选 `ms.ai_context(...)` 业务上下文与使用约束。 |

```python
# models/datasources/events.py
import marivo.datasource as md

md.clickhouse(
    name="events", host="clickhouse.example.internal", database="analytics",
```

## Trino — `md.trino`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `name` | 是 | — | 项目内全局唯一的小写 snake_case 数据源名称，用 `ms.ref.datasource(name)` 引用。 |
| `host` | 是 | — | 数据库服务器主机名或 IP 地址。 |
| `catalog` | 是 | — | Trino catalog，连接时映射到 Ibis database 参数。 |
| `user_env` | 是 | — | 必填的 Trino 用户环境变量名，不隐式回退到后端默认用户。 |
| `port` | 否 | `None` | 连接端口；使用非默认端点时请显式指定。 |
| `schema` | 否 | `None` | 表解析使用的默认 schema。 |
| `source` | 否 | `None` | 发送给 Trino 的客户端应用标识。 |
| `timezone` | 否 | `None` | Trino 引擎会话时区，与 Analysis Session 报告时区不同。 |
| `http_scheme` | 否 | `None` | HTTP 传输协议；使用 TLS 时请设为 `"https"`。 |
| `client_tags` | 否 | `None` | 客户端标签元组，传给 Trino 时转换为列表。 |
| `session_properties` | 否 | `None` | Trino 会话属性映射。 |
| `auth_env` | 否 | `None` | 服务器要求认证时所用认证材料的环境变量名。 |
| `ai_context` | 否 | `None` | 可选 `ms.ai_context(...)` 业务上下文与使用约束。 |
| `extra` | 否 | `None` | 未在此列出的其他 JSON 可序列化 Ibis 连接参数。 |


```python
# models/datasources/lake.py
import marivo.datasource as md

md.trino(
    name="lake", host="trino.example.internal", catalog="hive", schema="sales",
    user_env="TRINO_USER", auth_env="TRINO_AUTH", http_scheme="https",
    client_tags=("marivo", "reporting"),
)
```

精确参考：`marivo.help("datasource.trino")`.

## 凭据与连接检查

凭据通过 `*_env` 引用环境变量名；Marivo 不会推断变量名。`md.load().test(...)` 成功完成连接往返后，Marivo 可能将从环境变量解析的值以明文缓存到用户级 `~/.marivo/secrets.toml`。设置 `MARIVO_PERSIST_CREDENTIALS=0` 或 `CI` 环境变量非空时会关闭缓存。缓存文件权限限制为仅所有者可读写（`0600`），父目录权限为 `0700`，且 Marivo 不会将其写入 Git 仓库内。请勿将秘密值写入模型文件或 `extra`。

创建[教程数据库](/zh-cn/docs/latest/start/python/)后，从项目根运行：

```python
import marivo.datasource as md
import marivo.semantic as ms

warehouse = ms.ref.datasource("warehouse")
md.load().test(warehouse).show()
md.inspect(warehouse, md.table("orders"), workspace_dir=".").show()
```

## 连接与物理来源

`md.table(...)` 可在受支持的后端中选择表或视图。`md.parquet(...)` 和 `md.csv(...)` 描述由 DuckDB 读取的文件来源；`md.json(...)` 可描述文件或 HTTP 来源。这些都是来源描述符，不是新增的数据源类型。`md.inspect(...)` 读取物理元数据。若要采集行样本，请在 inspection 上调用 `inspection.sample(...)`，显式指定范围、列以及正数 `max_rows` 和 `timeout_seconds`。后端不支持的原生超时请求可能会跳过；`max_rows` 限制返回行数，不限制扫描字节数。样本值默认只保留在内存中；设置 `persist_values=True` 才会将有界样本以明文保存在项目状态中。Analysis 支持 DuckDB 本地 GET JSON，以及在源定义中写入具体请求值的 HTTP(S) GET/POST JSON。每次计算复用一份响应，不自动翻页；未填入的来源参数会在获取数据前报错。参见[有界数据源检查指南](/zh-cn/docs/latest/guides/datasources/#限制行数据证据)、[后端与方法限制](/zh-cn/docs/latest/reference/backends-and-limits/)，然后[定义 Entity](/zh-cn/docs/latest/modeling/semantic-layer/)。

PostgreSQL、MySQL/MariaDB 和 Trino 的 CHAR/CHARACTER 列保留物理类型与长度，Entity/Dimension 验证将其映射为逻辑字符串；也支持表达式 Entity 输入与声明主键。该映射不增加 SQL cast、trim、补空格或排序规则模拟，读取、比较与分组遵循原生后端。CHAR 不能作为数值 Measure。
