使用 `compare` 方法，将当前分析结果（`AnalysisFrame`）与同一分析会话（`Session`）中的一个或多个基准进行比较。结果保留当前值，并为每个基准添加基准值、绝对变化、相对变化和行存在状态。缺失行和 NA 值不会按零处理；基准值为零时，相对变化为 NA。

参阅[分析 DSL 中的基准比较](/zh-cn/docs/latest/analysis/dsl/#比较与对齐)，查看可运行示例以及轴和时间范围的匹配规则。

稀疏本期与基期按两侧实际行外连接。只有基期数据且能映入本期目录的日期也保留，
其 `current.present=False`，差额与相对变化为 NA；两侧都缺行的日期不输出。
若无事实日期应作为零参与同比或环比，须在两端分别显式构造完整 Population。
完整时间目录继续决定对应关系，不按返回行的位置匹配。
