调用 `session.observe(...)`，即可按所选输出域构造 Metric 计算，并返回待执行的
`AnalysisFrame`。调用 `compute()` 执行计算；调用 `persist()` 则完成计算并发布结果。

用 `where=scope` 选择报告范围，用 `by=(grain,)` 选择输出粒度。仅指定范围时，
筛选来源贡献，输出不增加时间轴。仅指定 Grain 时，返回实际有贡献的时间桶。
两者合用时形成有限的报告桶域。`by` 的元组中可同时放入普通 Dimension、Grouping
和一个 Grain；也可直接传入完整 Population。

每个源规约在定义时固定贡献时间，可显式传入 `time=field`，或继承所属 Entity 的
`default_time`。使用报告范围或 Grain 时，每个 Metric 的每个分支都须具备贡献时间。
组合 Metric 可以保留各分支不同的时间字段。

例如，`amount` 是已加载的 Measure，`booked_at` 和 `paid_at` 是已加载的 TimeDimension：

```python
import marivo.analysis as mv

scope = session.time_scope(start="2026-11-01", end="2026-12-01")
booked = amount.sum(time=booked_at)
paid = amount.sum(time=paid_at)
frame = session.observe(
    {"booked": booked, "paid": paid, "difference": booked - paid},
    where=scope,
    by=(mv.grain("day"),),
).compute()
```

用 `where=(scope, status == "paid")` 将一个报告范围与行谓词取交集。
`where=paid_at.within(scope)` 是绑定到固定来源字段的谓词，可筛选没有贡献时间的
Metric。窗口端点由报告时间上下文提供。若某个分支缺少贡献时间，请修订该分支的定义，
或在此次观察中省略报告时间。

精确契约见 `marivo.help("semantic.metric.define")` 和
`marivo.help("analysis.session.observe")`。

完整说明和示例见[分析 DSL 的 observe 部分](/zh-cn/docs/latest/analysis/dsl/#观察指标)。
