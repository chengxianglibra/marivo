## 汇总和归一化当前行

直接单段值列的 sum/mean 和 row_count 可用单个统计量或非空 tuple 省略名称，
固定名称为 `<name>_sum`、`<name>_mean` 和 `row_count`。业务名称、表达式或配对统计、
多段值路径应使用显式 Mapping。重复候选名在捕获时拒绝；求值和持久化保留原名称及顺序。

## 相关性使用共同样本

使用 `frame.correlate(x, y, method="pearson")` 或 `method="spearman"`，两个数值
Column 必须来自同一个确切 Frame。结果包含 `coefficient` 和 `n_pairs`。任一端为 NULL
时整对排除；不足两对或某端恒定时，系数为 NULL，但仍保留配对数。

`n_pairs` 统计非 NULL 配对，也包括有效 NaN 或 Infinity，因此它不代表有限值配对数。
相关性遵循 pandas 算法，非有限值或极端数值可能返回 NaN 或报错。Spearman 对并列值取平均秩。

pandas 示例使用共同的存在且非空掩码。不能按行号拼接无关导出。各组系数也不能直接平均得到总体相关性。

归一化返回占比 0.25、0.75，每行总额为 800、行数为 2。先筛选再计算会改变分母，计算后筛选则保留分母。空输入的求和为 0；非空但数值全为 NULL 时，求和为 NULL。行存在与数值缺失是不同信息。

外部统计不会自动生成 Frame 方法事实。应说明样本、缺失策略、方法和假设。需要其他方法时[导出结果](/zh-cn/docs/latest/analysis/results/)。

## 一个可核对的配对样本

保存为 `paired_sample.py` 并运行。五对值都满足 y = 2x，因此 Pearson 系数为 1。重复值仍作为独立样本计数。

```python
from analysis import session, region

sample = session.values(
    by=(region,),
    columns={"x": "1", "y": "1"},
    rows=(
        (("a",), {"x": 1, "y": 2}),
        (("b",), {"x": 2, "y": 4}),
        (("c",), {"x": 2, "y": 4}),
        (("d",), {"x": 3, "y": 6}),
        (("e",), {"x": 4, "y": 8}),
    ),
).compute()
correlation = sample.correlate(sample["x"], sample["y"], method="pearson").compute()
paired = correlation.to_pandas()
assert paired["n_pairs"].tolist() == [5]
assert abs(paired["coefficient"].iloc[0] - 1.0) < 1e-12
```

## 数值行为

本地 Frame 的 SUM 和 mean 使用 Arrow 原生算术。本地 int64 SUM 保持 int64，可能回绕；原生
内核也可能抛出溢出异常。Decimal 标量表达式遵循 Decimal context，来源端计算遵循实际后端的
算术行为。接近数值范围边界时，结果可能丢失精度，并因后端或数值类型不同而异；原生内核
也可能返回有效 NaN/Infinity 或报错。保存后的 Frame 会将有效 NaN/Infinity 作为值保留，
与 NULL 区分。
