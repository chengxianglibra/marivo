## 汇总和归一化当前行

直接单段值列的 sum/mean 和 row_count 可用单个统计量或非空 tuple 省略名称，
固定名称为 `<name>_sum`、`<name>_mean` 和 `row_count`。业务名称、表达式或配对统计、
多段值路径应使用显式 Mapping。重复候选名在捕获时拒绝；求值和持久化保留原名称及顺序。

```python
from analysis import mv, current, saved
```

{/* example: query-result-statistics */}

```python
summary = current.reduce(
    (current["revenue"].sum(), current["revenue"].mean(), mv.row_count())
).compute()
assert summary.output_names == ("revenue_sum", "revenue_mean", "row_count")
summary_rows = summary.to_pandas()
assert summary_rows["revenue_sum"].tolist() == [800]
assert summary_rows["revenue_mean"].tolist() == [400]
assert summary_rows["row_count"].tolist() == [2]
summary.show()
```

x = current["revenue"]

## 相关性使用共同样本

原生 Pearson 或 Spearman 使用 `frame.correlate(x, y, method="pearson")` 或 `method="spearman"`，两个数值 Column 必须来自同一个确切 Frame。结果包含 `coefficient` 和 `n_pairs`。任一端未知时整对排除；端点恒定或不足两对时系数未知，仍保留实际配对数。Spearman 对并列值取平均秩。

pandas 示例使用共同的存在且非空掩码。不能按行号拼接无关导出。各组系数也不能直接平均得到总体相关性。

归一化返回占比 0.25、0.75，每行总额为 800、行数为 2。先筛选再计算会改变分母，计算后筛选则保留分母。空输入的求和为零，非空且全未知的求和未知；行存在与数值未知仍有区别。

外部统计不会自动获得类型化 Evidence。应说明样本、缺失策略、方法和假设。需要其他方法时[导出结果](/zh-cn/docs/latest/analysis/results/)。

## 一个可核对的配对样本

保存为 `paired_sample.py` 并运行。五对值都满足 y = 2x，因此 Pearson 系数为 1。重复值仍作为独立样本计数。

```python
from analysis import session, region

sample = session.values(
    by=(region,),
    columns={"x": "1", "y": "1"},
    rows=(
        (("a",), {"x": 1, "y": 2}),
        (("b",), {"x": 2, "y": 4}),
        (("c",), {"x": 2, "y": 4}),
        (("d",), {"x": 3, "y": 6}),
        (("e",), {"x": 4, "y": 8}),
    ),
).compute()
correlation = sample.correlate(sample["x"], sample["y"], method="pearson").compute()
paired = correlation.to_pandas()
assert paired["n_pairs"].tolist() == [5]
assert abs(paired["coefficient"].iloc[0] - 1.0) < 1e-12
```
