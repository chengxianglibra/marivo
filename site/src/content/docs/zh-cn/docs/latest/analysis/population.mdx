---
title: Population
description: 定义完整成员与坐标域，区分输出键与贡献，统计正确的 Population。
---

Population 表示完整坐标元组的有限集合，例如订单、客户、地区或多轴的相关组合。它保留域含义与依赖，不是度量值表。名为 customer_id 的 Dimension 不自动成为实体身份；身份必须包含全部有序主键组成部分。Null 可以是维度类别，但身份组成部分不能为 null。

先完成[快速开始](/zh-cn/docs/latest/start/python/)，并按 [DSL 共享示例](/zh-cn/docs/latest/analysis/dsl/#完整示例与后续输入)创建 `analysis.py`。将本页 Python 块保存到同一个脚本中顺序运行。Population 捕获是延迟的；`session.frame(P).compute()` 读取完整键，`session.observe({"count": P.count()}).compute()` 计算其大小。

```python
from analysis import mv, session, revenue, region, august, current

orders_entry = session.catalog.get("entity:sales.orders")
assert orders_entry.kind == "entity"
Orders = orders_entry.value
```

## 字面坐标：`mv.coordinates`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | 有序闭合字段或身份分组，每个位置定义一个坐标轴；时间轴使用 product 组合。 |
| `keys` | 是 | — | 每个轴对应一个值的完整元组；身份值本身也是完整主键元组，单列身份也不例外。重复元组去重。 |


```python
requested = mv.coordinates(
    by=(mv.identity(Orders),),
    keys=(((4,),), ((5,),), ((6,),), ((999,),)),
)
requested_count = session.observe({"members": requested.count()}).compute()
assert requested_count.to_pandas()["members"].tolist() == [4]
```

订单 999 被显式请求，但教程来源中不存在；字面成员计数仍包含它。键不证明来源记录存在。`keys=()` 表示空域；当 `by=()` 时，`keys=((),)` 表示有一个元素的零轴域。

来源分析信任声明的身份、关系基数和版本粒度，不复核唯一性或匹配记录是否存在：scalar 匹配缺失时产生 Null，read/classify 保留请求身份并返回 Null 属性；关系遍历遵循实际连接与集合语义。使用显式 `source_check` 检查数据质量。身份输出仍须非空；数值检查、严格 Null 策略、输出 Population 覆盖和保存结果完整性继续执行。

## 身份分组：`mv.identity`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `target` | 是 | — | 定义身份轴的闭合 Entity 或显式有向关系路径。 |
| `at` | 否 | `None` | 版本化身份所需的精确 `session.instant(...)` 锚点；`None` 不提供锚点，适用于非版本化实体。 |

## 来源成员：`session.members`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `entity` | 是 | — | 来自当前 Session Catalog 的闭合 Entity。 |
| `at` | 否 | `None` | 版本选择的精确时刻，版本化 Entity 必须指定，否则为 `None`；不会借用后续观察范围。 |
| `where` | 否 | `None` | 可选来源字段或成员谓词；`None` 保留范围内全部来源已表示身份。 |


```python
east_orders = session.members(Orders, where=region == "east")
east_count = session.observe({"members": east_orders.count()}).compute()
assert east_count.to_pandas()["members"].tolist() == [4]
```

这些成员是跨两个月的订单 1、2、4、5。成员时间与 Metric 观察时间是独立选择。快照或有效期实体须显式提供 `at=session.instant(...)`。

## 输出域与贡献筛选

`by=P` 选择确切完整输出键，不会隐式把事实过滤到该集合。需要同时限定贡献时使用 `where=mv.in_population(P)`。显式筛选后，输出域必须覆盖所有必要贡献键，否则求值会抛出覆盖错误；各轴分别出现的值不能代替联合元组。

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `population` | 是 | — | 作为语义成员谓词使用的完整选定域；不隐式分摊或重新归一化。 |


### 笛卡尔积：`mv.product`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `factors` | 是 | — | 至少两个位置参数：Population、TimeScope 或 CalendarAxis。各因子轴须不同，Session 所有权兼容；任一因子为空时乘积为空。 |

```python
domain = mv.product(august, requested)
observed = session.observe(
    {"revenue": revenue}, by=domain, where=mv.in_population(requested)
).compute()
assert sorted(observed.to_pandas()["revenue"].tolist()) == [0, 100, 100, 600]
```

订单 999 因为没有贡献而保留收入零；存在记录但金额全部为空的订单求和则是未知。`mv.product(*factors)` 接收有序 Population、TimeScope 或 CalendarAxis 因子（没有默认参数），生成笛卡尔积，不推测哪些组合在业务上有效。

## 分类、投影与计数

### `P.classify`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | 单一身份 Entity 的直接属性，可以保留身份轴；求值时读取所需属性。 |

### `P.project`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | 保留或重排的已有轴；投影元组去重，不能读取新属性。 |


```python
all_orders = session.members(Orders)
classified = all_orders.classify(by=(all_orders.axes[0], region))
regions = classified.project(by=(region,))
counts = session.observe(
    {"orders": classified.count(), "regions": regions.count()}
).compute()
assert counts.to_pandas()["orders"].tolist() == [6]
assert counts.to_pandas()["regions"].tolist() == [2]
```

`P.count()` 无参数，返回统计完整去重元组的延迟 Metric，包含 Null 类别及来源缺失的显式身份。保留身份时统计六笔订单，先投影地区后则统计两个地区。它们均不同于按事实贡献统计的 `Entity.count()` 或按 Frame 行统计的 `mv.row_count()`。`P.axes` 只有坐标规则，没有选定键或分摊规则；传递 P.axes 会丢失 Population 域。

## 集合选择与关系映射

### `P.where`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `predicate` | 是 | — | 由 `mv.in_population(...)`、`&`、`\|`、`~` 组合、可由接收方现有轴投影的成员谓词；不新增字段读取。 |

### `P.union / P.intersection / P.difference`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `other` | 是 | — | 具有兼容完整绑定轴的 Population。union 合并，intersection 保留共有元组，difference 去除匹配元组。 |

### `P.image`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `via` | 是 | — | 通向目标身份的非空、显式、连续有向关系路径。 |
| `at` | 否 | `None` | 需要时指定目标版本的精确锚点；`None` 不提供。 |

### `P.preimage`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `targets` | 是 | — | 选定的兼容目标身份域；返回结果仍受接收方 P 限制。 |
| `via` | 是 | — | 从接收方身份到目标的显式有向关系路径。 |


```python
present_requested = requested.intersection(all_orders)
missing_requested = requested.difference(all_orders)
set_counts = session.observe(
    {"present": present_requested.count(), "missing": missing_requested.count()}
).compute()
assert set_counts.to_pandas()["present"].tolist() == [3]
assert set_counts.to_pandas()["missing"].tolist() == [1]
```

image 保留到达的目标外键身份，即使目标档案行缺失。preimage 选择能到达任一目标的接收方身份，不因关系多重性重复计数。订单映射到客户再映射回来可能包含该客户的其他订单，不保证恢复原子集。

## 从 Frame 选择继续：`session.population_from`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `frame` | 是 | — | 同 Session Frame，使用其已表示的普通键构造选定域。 |
| `on` | 是 | — | 显式 FrameAxis → 闭合字段或 Entity 配对，声明业务对应；投影后对完整选定键去重。 |


```python
chosen = current.top(1, by=current["revenue"]).compute()
chosen_regions = session.population_from(chosen, on=((chosen.axes[1], region),))
chosen_count = session.observe({"regions": chosen_regions.count()}).compute()
assert chosen_count.to_pandas()["regions"].tolist() == [1]
```

这里将西部固定为选定地区，后续观察不会重新排名。桥接不会恢复原始来源图、历史事实或未选择属性。`session.frame(P)` 用于读取键，`session.read(P, fields)` 用于单一实体身份域的属性；跨 Session 输入会被拒绝。精确参考：`analysis.population`、`analysis.coordinates`、`analysis.session.members`、`analysis.session.population_from`。
