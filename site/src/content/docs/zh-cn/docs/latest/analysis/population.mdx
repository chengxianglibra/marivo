title: Population
description: 选择完整成员与坐标域，区分输出键和贡献筛选，并统计选中成员。
---

分析对象集合（Population）是完整坐标元组的有限集合，例如订单、客户、地区或多个相关坐标轴组成的组合。它描述分析所覆盖的范围，观察则为其中的成员计算度量值。`customer_id` 这样的字段本身不是客户身份；身份包含全部有序主键字段。字段值为 `NULL` 时可以作为类别，Entity 身份的主键值必须非空。

先完成[快速开始](/zh-cn/docs/latest/start/python/)，并将 [DSL 共享示例](/zh-cn/docs/latest/analysis/dsl/#完整示例与后续输入)保存为 `analysis.py`。在项目根目录中，将本页未标注标题的代码块保存为 `population.py`，然后运行 `.venv/bin/python population.py`。Population 的构造采用延迟求值：`session.frame(P).compute()` 生成完整键，`session.observe({"count": P.count()}).compute()` 计算域的大小。

```python
from analysis import mv, session, revenue, region, august, current

orders_entry = session.catalog.get("entity:sales.orders")
assert orders_entry.kind == "entity"
Orders = orders_entry
```

## 字面坐标：`mv.coordinates`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | 有序字段或身份分组，每个位置定义一个坐标轴。可用 `mv.product` 将时间域与其他轴组合。 |
| `keys` | 是 | — | 每个轴对应一个值的完整元组。身份轴上的值必须是完整主键元组，即使主键只有一列也如此。重复元组只计一次。 |


```python
requested = mv.coordinates(
    by=(mv.identity(Orders),),
    keys=(((4,),), ((5,),), ((6,),), ((999,),)),
)
requested_count = session.observe({"members": requested.count()}).compute()
assert requested_count.to_pandas()["members"].tolist() == [4]
```

`requested` 包含订单 999，但教程数据中没有这条记录。字面 Population 记录所选键；来源中是否存在对应记录需另行确认。`keys=()` 表示空域；当 `by=()` 时，`keys=((),)` 表示有一个元素的零轴域。

来源驱动的 Population 遵循语义模型中声明的身份、关系基数和版本粒度。需要检查数据唯一性或关系基数等条件时，可运行[在线校验](/zh-cn/docs/latest/modeling/semantic-layer/#加载与检查)并明确指定检查项。标量查询找不到关联行时，`session.read` 和 `P.classify` 会保留请求的身份，缺失属性的值为 `NULL`。

这些声明以及实际集合/分组算子可以建立完整键唯一性，无需再做一次重复扫描。
普通 members、read、classify 和 Top 不承担来源质量审计。字面 Frame 数据和未知关系保留
入口键检查；NULL 身份及算子必要覆盖检查仍是独立义务。

## 身份分组：`mv.identity`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `target` | 是 | — | Entity 对应直接身份轴；`mv.path(...)` 对应买方、卖方等身份角色。 |

通过 `session.members(..., at=...)` 选择指定时刻的成员。同一 Entity 的直接身份轴
即使来自不同快照，也可参与集合运算。随后读取版本化属性时，在字段或 Path 上显式指定时刻。

## 来源成员：`session.members`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `entity` | 是 | — | 当前分析会话目录中已解析的 Entity。 |
| `at` | 否 | `None` | 版本化 Entity 的精确版本选择时刻；非版本化 Entity 可省略。此时刻应与观察时段分别选择。 |
| `where` | 否 | `None` | 可选的来源字段或 Population 成员筛选条件；省略时保留所选范围内来源已表示的全部身份。 |


```python
east_orders = session.members(Orders, where=region == "east")
east_count = session.observe({"members": east_orders.count()}).compute()
assert east_count.to_pandas()["members"].tolist() == [4]
```

这里的成员是跨两个月的订单 1、2、4、5。成员时间应与 `Metric` 的观察时段分别选择。快照或有效期 Entity 须显式提供 `at=session.instant(...)`。

对比版本化客户 Entity 的两个快照时，分别显式选择成员。交集保留两个快照均有的客户身份，
下例地区字段按 9 月快照读取。

```python title="Versioned customers model"
august_time = session.instant("2026-08-01")
september_time = session.instant("2026-09-01")
august_customers = session.members(Customers, at=august_time)
september_customers = session.members(Customers, at=september_time)
retained = august_customers.intersection(september_customers)
report_region = customer_region.at(september_time)
classified_customers = retained.classify(by=(report_region,))
```

## 输出域与贡献筛选

`by=P` 选择完整输出键。若还要将贡献限制在这些成员内，使用 `where=mv.in_population(P)`。筛选后，输出域必须包含所有必要的贡献键，否则求值会抛出覆盖错误。相关坐标轴应作为完整元组保留；分别列出各轴的值无法保留它们的组合关系。

### 成员谓词：`mv.in_population`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `population` | 是 | — | 用于判断成员关系的完整选定域。 |

来源谓词包含时间坐标时，按贡献时钟和普通坐标联合匹配。区间包含起点、排除终点。
含区间轴的 Population 用作报告域时，最多可有一个实际区间。若区间由来源或 Frame 键决定，Marivo 会先求值并检查输出域，再读取依赖它的 Metric。空域产生空报告。


### 笛卡尔积：`mv.product`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `factors` | 是 | — | 至少两个有序因子，类型为 `Population`、`TimeScope` 或 `CalendarAxis`；各因子轴须不同，已绑定的 `Population` 因子须属于同一分析会话。任一因子为空时，乘积为空。 |

```python
domain = mv.product(august, requested)
observed = session.observe(
    {"revenue": revenue}, by=domain, where=mv.in_population(requested)
).compute()
assert sorted(observed.to_pandas()["revenue"].tolist()) == [0, 100, 100, 600]
```

订单 999 因为没有贡献而保留收入零；若订单有记录但金额全部为 `NULL`，其求和结果则未知。`mv.product(*factors)` 会包含各因子的所有组合；仅当完整笛卡尔积符合预期输出范围时使用。

## 分类、投影与计数

### `P.classify`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | 要追加的单值字段或身份分组。已有坐标会被复用；`()` 保留原域。 |
| `on` | 否 | `None` | 指定读取主体的已有身份 Grouping。只有一个可用角色时可省略。 |

分类保留完整输入元组。缺失的标量属性为 NULL。追加身份角色时，每个输入元组
都必须具有完整的非空身份。

### `P.project`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `by` | 是 | — | Population 中已有的轴；可选择或调整顺序。投影元组会去重，需先用 `classify` 添加属性。 |


```python
all_orders = session.members(Orders)
classified = all_orders.classify(by=(region,))
selected = classified.where(region == "east")
order_keys = selected.project(by=(mv.identity(Orders),))
regions = selected.project(by=(region,))
counts = session.observe(
    {"orders": order_keys.count(), "regions": regions.count()}
).compute()
assert counts.to_pandas()["orders"].tolist() == [4]
assert counts.to_pandas()["regions"].tolist() == [1]
```

`P.count()` 返回延迟的 `Metric`，用于统计不同的完整元组，其中包括 `NULL` 字段类别和来源中没有记录的显式请求身份。上例选中的范围包含四笔订单和一个地区。`Entity.count()` 统计来源贡献，`mv.row_count()` 统计 Frame 中的行。`P.axes` 列出坐标规则；要保留选定成员集合，请传入 `P` 本身。Population 计数独立于报告时间。报告范围和窗口不重选其成员；缺少报告时间坐标时复用计数，已有兼容时间坐标时按键匹配。

## 集合选择与关系映射

### `P.where`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `predicate` | 是 | — | 作用于已有坐标的行谓词。可比较字段、使用 `isin` 或 `isnull`，并用 `&`、`\|` 和 `~` 组合 `mv.in_population(...)`。 |

仅保留结果为 True 的元组。需按尚未捕获的坐标筛选时，先用 `classify` 添加它。
`session.members(..., where=...)` 和 `session.observe(..., where=...)`
可读取各自来源域中的属性来求值。

### `P.union / P.intersection / P.difference`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `other` | 是 | — | 具有兼容完整绑定轴的 Population。结果保留左侧轴顺序。`union` 合并域，`intersection` 保留共有元组，`difference` 从当前域移除匹配元组。 |

### `P.image`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `via` | 是 | — | 由 `mv.path(...)` 构造的有向 `Path`。 |
| `on` | 否 | `None` | 已有起点身份 Grouping。只有一个可用角色时可省略。 |

### `P.preimage`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `targets` | 是 | — | 选定的直接目标身份域。 |
| `via` | 是 | — | 由 `mv.path(...)` 构造的有向 `Path`。 |
| `on` | 否 | `None` | 已有起点身份 Grouping。只有一个可用角色时可省略。 |


```python
present_requested = requested.intersection(all_orders)
missing_requested = requested.difference(all_orders)
set_counts = session.observe(
    {"present": present_requested.count(), "missing": missing_requested.count()}
).compute()
assert set_counts.to_pandas()["present"].tolist() == [3]
assert set_counts.to_pandas()["missing"].tolist() == [1]
```

`P.image` 返回去重后的直接目标身份。完整外键可以提供缺少目标记录的身份。
`P.preimage` 保留能到达至少一个目标的完整输入元组。如果一个元组可以到达
多个目标，对它再次取像可能得到原先未选中的其他目标。

通过 `mv.path(relationship, source_at=anchor)` 指定版本化起点的读取时刻。
当某一步需要读取其目标版本时，使用 `relationship.at(anchor)`。末端时刻要求实际
读取目标行。需要检查目标是否在某时刻存在时，用 `session.members(Target, at=anchor)`
构造目标域。

`P.identities(on=grouping)` 保留指定轴上的完整身份值，消去路径角色，并在直接
Entity 轴上去重。需要保留身份角色或其他选定轴时，使用 `P.project`。

## 从 Frame 选择继续：`session.population_from`

| 参数 | 必填 | 默认值 | 语义 |
| --- | --- | --- | --- |
| `frame` | 是 | — | 来自同一分析会话的 Frame；使用其中已表示的普通键构造选定域。 |
| `on` | 是 | — | 显式将 FrameAxis 映射到字段或 Entity，用来声明业务对应关系。投影后会对完整选定键去重。 |


```python
chosen = current.top(1, by=current["revenue"]).compute()
chosen_regions = session.population_from(chosen, on=((chosen.axes[1], region),))
chosen_count = session.observe({"regions": chosen_regions.count()}).compute()
assert chosen_count.to_pandas()["regions"].tolist() == [1]
```

由于 `current` 是已计算的 8 月结果，`population_from` 会记录选中的地区。后续观察可将 `chosen_regions` 传给 `where=mv.in_population(chosen_regions)`，这样仍选中 west，无需重新排名。用 `session.frame(P)` 计算 Population 的键。`session.read(P, fields, on=...)` 保留全部输入键，并添加命名标量值。多个角色均可提供这些字段时，请指定已有身份 Grouping。创建和使用 Population 时，应使用其所属的分析会话。精确参考：`analysis.population`、`analysis.coordinates`、`analysis.session.members`、`analysis.session.population_from`。

版本化字段的已有直接轴未设锚点时，可映射到同一未设锚点的字段并复用其值。建立新的版本化字段绑定时，请用 `field.at(session.instant(...))` 显式指定版本。

### 筛选已固定的坐标值

完成带分类坐标的键 Frame，然后将坐标轴映射到明确的业务绑定。下例沿用前面
classify 调用的轴顺序。最终筛选直接使用已捕获的地区值，可在来源离线时执行。

```python
fixed = session.frame(classified).compute()
captured = session.population_from(
    fixed, on=((fixed.axes[0], Orders), (fixed.axes[1], region))
)
east_keys = session.frame(captured.where(region == "east")).compute()
assert len(east_keys.to_pandas()) == 4
```
