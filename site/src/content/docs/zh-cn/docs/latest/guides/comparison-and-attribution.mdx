## 执行前构造比较

{/* example: compare-query */}

```python
change = current.compare(baseline, how="exact")
comparison = change.execute().to_pandas()
assert comparison[("value", "revenue.absolute")].tolist() == [-100, -100]
assert comparison[("value", "revenue.relative")].tolist() == [-1 / 3, -1 / 7]
outer = current.compare(baseline, how="outer")
```

compare 输出 `<name>.current`、`.baseline`、`.absolute`、`.relative`。相对变化为 `(current-baseline)/abs(baseline)`。两端共同非 NA 且基期为零时，默认仅新 relative 为 NA；`zero_denominator="error"` 拒绝该被需求的除法。输入子式政策继续有效，业务可比性仍由调用方判断。

exact 要求完整键唯一并完全对应。outer 保留键像之并及独立 current/baseline presence；值为 NA 不代表端点不存在，缺侧不会补零。仅需差额时用 align/select：

{/* example: aligned-absolute-only */}

```python
aligned = current.align(baseline)
difference = aligned.select({
    "difference": aligned["left.revenue"] - aligned["right.revenue"],
})
difference.execute().show()
```

## 回到端点追问

比较 Query 没有直接 drill 或专用归因方法。先选择原端点的相关坐标，通过 `drill(add=(field,))` 或新 observe 请求合法细分，再比较两端。教程中的普通地区选择为：

{/* example: comparison-endpoint-followup */}

```python
selected_current = current.where(current["revenue"] < 300)
selected_baseline = baseline.where(baseline["revenue"] < 400)
followup = selected_current.compare(selected_baseline)
followup.execute().show()
```

在身份轴上新增的声明字段必须单值。普通 customer_id 与 channel 只按贡献坐标像分组，不声明客户身份域。保存的比较可在 pandas 中检查、分组，不能回传为 Query。

## 运输完整参照

{/* example: broadcast-reference */}

```python
budget = session.values(
    by=(region,), columns={"budget": "CNY"},
    rows=((("east",), {"budget": 250}), (("west",), {"budget": 750})),
)
reference = mv.broadcast(budget["budget"], to=current)
vs_budget = current.select({
    "revenue": current["revenue"],
    "budget_variance": current["revenue"] - reference,
})
vs_budget.execute().show()
```

参照键须唯一且覆盖全部目标键；参照每个轴须有无歧义的完整目标投影，不能按同名或行位置猜映射。零轴参照必须恰有一行。broadcast 复制取值出现，不复制事实或可加性权威。

真正的贡献份额用 `current.share("revenue")`，分母来自同一份实际输入。share 后筛选保留原分母，先筛选再 share 改变总体。普通参照除法不证明贡献包含。

## 明确选择对应

不同日历使用 `match=mv.ordinal()` 或 `mv.previous_year()` 等无轴规则。ordinal 使用原完整桶序；previous_year 的日粒度闰日没有对应。`match=mv.corresponding(via=(relationship,))` 使用声明的一对一身份路径，普通同值字段不能代替。非恒等输出保存两端投影。见[时间与身份](/zh-cn/docs/latest/guides/time-and-cohorts/)。
