## 规约或选择当前行

{/* example: query-result-statistics */}

```python
summary = current.reduce({
    "sum": current["revenue"].sum(),
    "mean": current["revenue"].mean(),
    "rows": mv.row_count(),
}).compute()
summary.show()
ranked = current.top(1, by=current["revenue"], descending=True).compute()
ranked.show()
```

每项统计使用自己的有效非 NA 样本。空输入的 sum 为有类型的零，有输入但全 NA 的 sum 为 NA；没有有效样本的 mean 为 NA，
row_count 计算所有当前行。reduce 只能保留现有完整 Frame 轴，不能粗化日历。
sum/mean 保留当前表达式的单位；单位不认证原 Metric 的可加性，也不授予沿被移除轴上卷的能力。
每日库存之和仍可标为件，比率之和仍可无量纲，但这不使它们成为月库存或整体比率。
显式 Population 保留没有事实的成员，其来源 sum 为零；有事实但值全 NULL 的成员仍返回 NULL。
A/B/C 的收入分别为 100/无事实/无事实时，完成的成员值为 100/0/0，均值为 100/3。
若 C 改为有事实但收入未知，其值为 NULL；忽略 NA 的均值会跳过 C，不能称为全体成员均值。
未知成员必须阻断计算时，使用严格内部样本检查。对齐中缺少端点与成员存在但没有事实仍是两回事。
SQL SUM 在空输入时返回 NULL，pandas sum 默认将全 NA 变为零；两者均不完全等于 Marivo 的固定区分。
真正的 NaN/Infinity 是错误；来源读取失败不能作为空输入处理。

Top 是全局操作，使用精确输入的 Column，其确定行序在持久保存后保留；没有 partition_by。

完成后的成员值也不能重建所有原始求和：无事实成员与未知成员的单元格 [0, NA] 求和为 0，
但原始全 NULL 事实求和仍为 NULL。原总体问题需要重新显式来源观察。

当前行均值不是原 Metric 的整体均值。10 与 100 的行均值为 55；来源 91 次贡献合计
1000 时整体均值为 1000/91。去重计数 2+2=4 也可能只含 3 个不同身份。
原整体问题需要显式来源构造，不能以看似相近的 reduce 或已退役 rollup 替代。

## 导出后完成未支持的描述统计

{/* example: pandas-descriptive-statistics */}

```python
values = current.to_pandas()["value"].copy()
revenue_values = values["revenue"]
statistics = revenue_values.agg(["count", "sum", "mean", "median", "min", "max"])
print(statistics)
rank = revenue_values.rank(method="dense", ascending=False)
standard_deviation = revenue_values.std(ddof=1)
if standard_deviation > 0:
    standardized = (revenue_values - revenue_values.mean()) / standard_deviation
```

当前行 Pearson/Spearman 已由 `frame.correlate(x, y, method=...)` 支持，并返回配套计数；
参见[分析工作流](/zh-cn/docs/latest/concepts/analysis-workflow/)。适合该合同的问题应先完成类型化相关再导出。

外部排名、标准化、其它相关方法或预测需要说明样本、NA、并列、拟合范围与不确定性。
输出是普通数据，不继承类型化 Evidence；导出数据与 attrs 不能回灌为语义权威。
原 Frame 仍可继续受支持的类型化数据操作。

## 使用同一组有效端点行

{/* example: pandas-paired-statistics */}

```python
comparison = current.compare(
    {"reference": baseline},
    on={"reference": tuple(zip(current.axes, baseline.axes))},
    match={"reference": mv.ordinal()},
).compute().to_pandas()
present = comparison[("presence", "current.present")] & comparison[("presence", "reference.present")]
pairs = comparison.loc[present, "value"][["revenue", "reference.baseline.revenue"]].dropna()
paired_difference = pairs["revenue"] - pairs["reference.baseline.revenue"]
print(paired_difference.mean())
```

presence 与值有效性独立。保留完整键与共同存在、共同非 NA 的掩码，不按 RangeIndex
配对无关导出。需要时用 dropna=False 保留 Field Null 类别。算术变化不证明因果。

未完成统计量只公开只读 `unit`，由 `frame.reduce(...)` 消费。`mv.row_count()` 未绑定，
可复用于不同 Frame，消费不修改原请求。Column 的 sum/mean/corr/pair_count 绑定精确
Frame 与 Session；名称、结构或值相同的另一输入不能替换。
见 `marivo.help("analysis.value_statistic")`。
