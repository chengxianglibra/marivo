本指南已合并至[统计与相关性](/zh-cn/docs/latest/analysis/statistics/)。以下主题链接到新版指南中的对应章节。

## 规约或选择当前行

使用 `reduce()` 汇总当前 Frame 表示的行。`mv.row_count()` 统计所有行，包括值为 NULL 的行。空输入求和为 0，非空但数值全为 NULL 时求和为 NULL。`over()` 可将分区统计量广播回当前行。若要统计源 Entity 贡献数、选中的 Population 成员数（包括没有事实的成员），或计算原始 Metric 总额，应对相应范围进行显式观察；分组汇总无法还原这些结果。参阅[计数范围说明](/zh-cn/docs/latest/analysis/statistics/)。

## 广播分区统计与当前值归一化

`over()` 在各分区内计算统计量。使用 `share(along=...)` 时，所选轴参与求和，其余轴定义分区。`share()` 返回比例而非百分数；分区总和为 0 时结果为 NA，含负值时比例可能超出 `[0, 1]`。计算前筛选会改变分母，计算后筛选则保留原分母。参阅[分区统计与占比](/zh-cn/docs/latest/analysis/statistics/#汇总和归一化当前行)。

## 导出后完成未支持的描述统计

Frame 未提供所需统计方法时，可对已完成的 Frame 调用 `.to_pandas()`，再用返回的数据进行本地计算。应说明样本、缺失值策略、方法和假设；外部计算不会自动生成 Frame 方法事实。参阅[统计示例](/zh-cn/docs/latest/analysis/statistics/#汇总和归一化当前行)。

## 使用同一组有效端点行

使用同一确切 Frame 输入中的数值 Column 计算 Pearson 或 Spearman 相关性；Duration 不受支持，Spearman 对并列值取平均秩。任一端为 NULL 时整对排除；不足两对或某一端恒定时，系数为 NULL。`n_pairs` 统计非 NULL 配对，包括有效 NaN 或 Infinity，因此不等于有限值配对数；解释系数前应检查非有限值。相关性不会根据比较结果的 presence 标记筛选样本；若要只分析双方均存在的行，应先显式筛选。相关性是描述性统计，不能证明因果或支持统计推断；各组系数也不能平均后作为总体结果。参阅[配对样本规则](/zh-cn/docs/latest/analysis/statistics/#相关性使用共同样本)。

## 数值结果与溢出

统计量使用原生数值内核。本地 int64 `SUM` 保持 int64，可能回绕；来源端计算遵循后端的算术行为。接近数值边界时，应核对结果范围和精度。参阅[数值行为](/zh-cn/docs/latest/analysis/statistics/#数值行为)。
