本指南复用[本地教程](/zh-cn/docs/latest/guides/python-quick-start/)。
其中 `current` 与 `baseline` 已是固定的完整内存 Frame。

## 规约或选择当前行

{/* example: query-result-statistics */}

```python
summary = current.reduce({
    "sum": current["revenue"].sum(),
    "mean": current["revenue"].mean(),
    "rows": mv.row_count(),
}).compute()
summary.show()
ranked = current.top(1, by=current["revenue"], descending=True).compute()
ranked.show()
```

每项统计使用自己的有效非 NA 样本。空或全 NA 的 sum 是 NA，没有有效样本的 mean 是 NA，
row_count 计算所有当前行。reduce 只能保留现有完整 Frame 轴，不能粗化日历。
Top 是全局操作，使用精确输入的 Column，其确定行序在持久保存后保留；没有 partition_by。

当前行均值不是原 Metric 的整体均值。10 与 100 的行均值为 55；来源 91 次贡献合计
1000 时整体均值为 1000/91。去重计数 2+2=4 也可能只含 3 个不同身份。
原整体问题需要显式来源构造，不能以看似相近的 reduce 或已退役 rollup 替代。

## 导出后完成未支持的描述统计

{/* example: pandas-descriptive-statistics */}

```python
values = current.to_pandas()["value"].copy()
revenue_values = values["revenue"]
statistics = revenue_values.agg(["count", "sum", "mean", "median", "min", "max"])
print(statistics)
rank = revenue_values.rank(method="dense", ascending=False)
standard_deviation = revenue_values.std(ddof=1)
if standard_deviation > 0:
    standardized = (revenue_values - revenue_values.mean()) / standard_deviation
```

外部排名、标准化、相关或预测需要说明样本、NA、并列、拟合范围与不确定性。
输出是普通数据，不继承类型化 Evidence；导出数据与 attrs 不能回灌为语义权威。
原 Frame 仍可继续受支持的类型化数据操作。

## 使用同一组有效端点行

{/* example: pandas-paired-statistics */}

```python
comparison = current.compare(
    baseline, on=tuple(zip(current.axes, baseline.axes)), match=mv.ordinal(),
).compute().to_pandas()
present = comparison[("presence", "left_present")] & comparison[("presence", "right_present")]
pairs = comparison.loc[present, "value"][["left.revenue", "right.revenue"]].dropna()
paired_difference = pairs["left.revenue"] - pairs["right.revenue"]
print(paired_difference.mean())
```

presence 与值有效性独立。保留完整键与共同存在、共同非 NA 的掩码，不按 RangeIndex
配对无关导出。需要时用 dropna=False 保留 Field Null 类别。算术变化不证明因果。
