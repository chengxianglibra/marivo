物理 Entity/Field 构造器先捕获声明并返回类型化 Ref 查找键。依赖完整后调用 `ms.finalize()`，再从冻结结果解析所需值用于组合。命名声明与本地表达式共用同一张图；finalize 不重跑模块或 import effects。

语义对象不必始终绑定构造时的原定义版本，不因同路径定义已改变而单独拒绝输入；分析期间语义定义更新的后果由 agent 或用户承担。进行引用解析的消费者使用其完整作用域。不可变表达式保留存储的定义与事实，不做 live refresh。kind、贡献根、粒度、单位、时间角色、空值和权限检查仍然有效。指纹与缓存键描述实际消费的定义，持久化来源记录及其它记录仍遵循各自合同。

当前 R1.3 已支持构造。新的 Catalog Metric 收录、发布和公开发现属于 R1.4；新的分析执行属于 R2。下面的纯声明不会登记 Metric，也不能当作当前 Session 执行验收。

## 声明一个完整依赖切片

warehouse datasource 及示例列需已存在。保存为 models/semantic/sales/_domain.py。

{/* example: semantic-model-basics */}

用 `amount.show()` 或 `finalized.show()` 查看构造元数据。对应的精确合同可通过 `marivo.help(amount.show)` 和 `marivo.help("semantic.FinalizedDeclarations.show")` 解析；展示不会执行查询。

```python
import marivo.datasource as md
import marivo.semantic as ms

sales = ms.domain(name="sales", owner="Mina Zhang")
orders = ms.entity(name="orders", datasource=ms.ref.datasource("warehouse"),
                   source=md.table("orders"), primary_key=["order_id"])
region = ms.dimension_column(name="region", entity=orders, column="region")
paid_at = ms.time_dimension_column(name="paid_at", entity=orders, column="paid_at",
                                   granularity="day", is_default=True)
amount = ms.measure_column(name="amount", entity=orders, column="amount",
                           additivity=ms.additive_all(), unit="CNY")
cost = ms.measure_column(name="cost", entity=orders, column="cost",
                         additivity=ms.additive_all(), unit="CNY")

@ms.dimension(entity=orders)
def normalized_region(rows):
    return ms.bind(region, rows).upper()

finalized = ms.finalize()
orders = finalized.resolve(orders)
region = finalized.resolve(region)
normalized_region = finalized.resolve(normalized_region)
paid_at = finalized.resolve(paid_at)
amount = finalized.resolve(amount)
cost = finalized.resolve(cost)

@ms.measure()
def margin():
    return amount - cost

@ms.metric()
def revenue():
    return amount.sum(time=paid_at)

@ms.metric()
def average_order_value():
    return revenue / orders.count(time=paid_at)
```

## 名称、别名与计算

零参数函数名直接成为局部声明名，必须符合 [a-z][a-z0-9_]*。不接受 name/entity/entities 覆盖。后续别名不会改名，算术产生匿名新表达式。ai_context 只描述业务含义，不授予计算权限。纯声明不要求活动 loader 或 Session；物理来源构造器仍在模型加载上下文中使用。

```python
margin_alias = margin
trial_margin = amount - cost
paid_revenue = revenue.where(region == "US")
customer_average = revenue.per(region).mean()
missing_region_revenue = revenue.where(region.is_null())
```

where 只过滤单一来源规约或共同配对作用域。复合 Metric 应先改各来源子指标，再组合。per 返回内部样本，必须规约后才是 Metric。

原生字段共用 `marivo.help("semantic.Dimension.is_null")` 的空值谓词合同；也可用 `region.is_null` 或 `paid_at.is_null` 获取 callable Help。带路径的 TimeField 保留时间角色，只能用于 `time=`，选择求和许可坐标时也不能丢弃路径。

## 单位与显式求和授权

省略 unit/additivity 或传 None 会继承事实；不会清空单位或授予 additive_all。同行乘积不会自动可加。只有业务含义已获授权时，才声明新的 Measure：

```python
@ms.measure(additivity=ms.additive_all())
def order_amount():
    return quantity * unit_price
```

quantity 与 unit_price 必须预先声明且同根。未知单位保持未知；显式单位须与已知推导相容。新授权不能抹去状态时间轴或必要绑定。

## Ibis 字段体与纯声明体

Entity/Source、Dimension/TimeDimension 保留受限 Ibis 能力。上面的 normalized_region 在 finalize 前捕获，之后才解析。ms.bind 只用于原合同允许的 Ibis 字段体；已构造输入按 kind/path 在完整消费者作用域解析，不因原定义版本不同而拒绝；显式 lookup Ref 也保留前向依赖。Measure/Metric 体只构造封闭表达式，允许首段 docstring、无重绑定的局部变量和唯一最终 return；拒绝表参数、Ibis 返回值、ms.bind、任意调用及控制流。


## 旧声明的人工改写

旧 aggregate/count/where/ratio/weighted_mean/linear/cumulative 工厂、默认 fold、time_via、fanout_policy、approx_* 和全局值政策不再被接受。结构化错误保留原输入并指出改写位置。不能删除 empty=null 后宣称与新的空 sum=0 等价；重叠标签分桶也不能冒充存在筛选。

从 marivo.help("authoring") 进入，再查 semantic.measure、semantic.metric、semantic.expressions 和实际接收者的 focused Help。构造成功、物理叶子 load/readiness、Catalog 发布和真实执行是不同证据。
