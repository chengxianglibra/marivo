在 `models/datasources/` 中声明连接；加载声明时不会打开连接。环境变量凭据使用
`*_env` 引用声明。连接测试通过后，Marivo 可能将来自环境变量的凭据以明文
缓存到用户级 `~/.marivo/secrets.toml`。设置 `MARIVO_PERSIST_CREDENTIALS=0`
可关闭此缓存。

`md.inspect` 读取物理元数据。采集行样本时，需要指定列和显式范围，并设置正数
`max_rows` 与 `timeout_seconds`。若后端不支持超时请求，可能会跳过该请求；
`max_rows` 限制返回行数，不限制扫描字节数。元数据和样本可用于指导建模，
但不能代替业务定义。详见[数据源配置](/zh-cn/docs/latest/modeling/datasources/)。

## 采集有界行样本

通过 `marivo.help("datasource.inspection")` 选择范围和已检查到的列。调用
`md.inspect(...)` 后，可在返回的 `SourceInspection` 对象上调用 `.sample(...)`。
样本值默认只保留在内存中；显式设置 `persist_values=True` 会将有界样本值
以明文保存在项目状态中。

## 选择物理来源

用 `md.table(...)` 选择表或视图；Parquet、CSV 和 JSON 文件来源由 DuckDB 读取。
详见[物理来源](/zh-cn/docs/latest/modeling/datasources/#连接与物理来源)。

## 参数化 JSON

将具体的 GET 查询参数或 POST 请求体值直接写入语义源定义。把这些描述符作为
`ms.entity(...)` 的 `source=`，再正常定义字段和 Metric；对应的 Analysis Frame
使用普通的 `compute()` 或 `persist()`：

```python
import marivo.datasource as md

alerts = md.json(
    "https://api.example/alerts",
    query_params={"page_number": 1, "page_size": 100},
    records_path="$.data.vcdn_list",
    columns={"id": "id", "severity": "severity"},
)
changes = md.json(
    "https://api.example/changes",
    method="POST",
    body={"filter": {"apps": ["app-a", "app-b"]}, "page_num": 1},
    records_path="$.data.change_infos",
    columns={"id": "change_id", "app_id": "specificsource[].appid"},
)
```

加载、构造和元数据展示不发送请求。计算期间，HTTP 获取的响应同时用于类型推断和
后续计算；相同请求在多个消费者和投影之间复用一份响应。每次重新计算都会重新获取；
已完成或重新打开的 Frame 使用固定数据。单页不证明集合完整，Marivo 不自动遍历分页。

`md.source_param(...)` 占位符仍可用于显式数据源采样和语义预览。交给 Analysis 前，
请在源定义中填入具体值；任何待执行依赖存在缺失参数，都会在所有请求前报错。
参阅 `marivo.help("datasource.json")` 和 `marivo.help("datasource.source_param")`。

## 默认数据源与宿主凭据

内置 `default` 是全新的内存 DuckDB，无需凭据。若要持久保存数据，请声明
文件型 DuckDB，或使用底层存储可持久保存的数据源。宿主管理凭据请参阅
[运行环境配置](/zh-cn/docs/latest/reference/configuration/#集成宿主凭据)，并查询
`marivo.help("datasource.credential_scope")`。
