## 安装指令

将下面这一句话交给能执行终端命令的 Agent：

> 请在当前项目中使用 https://marivo.io/install.sh 安装 Marivo，按提示激活环境，运行 `marivo doctor`，并说明当前 Agent 是否发现了 `marivo-semantic` 和 `marivo-analysis` 技能。

安装脚本安装发布包并初始化项目。`marivo doctor` 检查本地环境和技能文件，但无法确认 Agent 工具是否已加载这些技能。若 Agent 未自动发现技能，请提供已安装技能的路径。远程数据源还需单独检查连接。本 latest 指南使用开发 API，运行这些示例请按[源码安装说明](/zh-cn/docs/latest/start/installation/)选择匹配环境。

## 提出问题

已有语义模型时，说明业务问题、指标、时间范围和比较基准：

> 使用本项目的 `sales.revenue` 比较 2026 年 8 月与 7 月，按地区查看差异，给出数值、依据和限制。

新项目中，提供数据位置和已确认的业务定义。使用真实数据源前，配置对应驱动并设置连接声明引用的环境变量；参阅[数据源配置](/zh-cn/docs/latest/modeling/datasources/)和[后端依赖与限制](/zh-cn/docs/latest/reference/backends-and-limits/)。退款、币种、时间口径等重要选择由你确认。没有生产数据时，让 Agent 在独立演示项目中运行[快速开始](/zh-cn/docs/latest/start/python/)。

## 检查回答

在[六笔订单的 DSL 示例](/zh-cn/docs/latest/analysis/dsl/#完整示例与后续输入)中，7 月收入为 1,000 CNY，8 月为 800 CNY。`east` 和 `west` 各变化 -100 CNY，合计为 -200 CNY。要求 Agent 说明这是算术分解，不能据此断定变化原因，并指出重要的数据缺失和方法限制。

追问时说明保持哪些范围不变。需要在另一进程中恢复同一结果时，让 Agent 保存结果并保留 `session_id` 和 `artifact_id`，详见[结果与证据](/zh-cn/docs/latest/analysis/results/)。只需一次性回答时不必保存。需要当前来源值时，要求 Agent 重新观测。例如：“保持 west 地区不变，按客户类型进一步比较。”
