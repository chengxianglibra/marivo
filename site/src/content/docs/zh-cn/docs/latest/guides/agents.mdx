## 安装指令

将下面这一句话交给能执行终端命令的 Agent：

> 请在当前项目中安装 Marivo（https://marivo.io/install.sh），运行环境检查，并确认已加载 marivo-semantic 和 marivo-analysis 技能。

安装脚本安装发布包；使用本 latest 指南的开发 API 时，请让 Agent 按[源码安装说明](/zh-cn/docs/latest/start/installation/)选择匹配环境。无法自动发现技能时，明确提供已安装技能文件的位置。

## 提出问题

已有语义模型时，说明业务问题、指标、时间和比较基准：

> 使用本项目的 sales.revenue 比较 2026 年 8 月与 7 月，按地区查看差异，给出数值、依据和限制。

新项目中，提供来源位置及已确认的业务定义。退款、币种、时间口径等重要选择由你确认。没有生产数据时，可让 Agent 执行[快速开始](/zh-cn/docs/latest/start/python/)。

## 检查回答

六笔订单示例应得到：7 月 1,000，8 月 800，下降 200；east 与 west 各下降 100。要求 Agent 区分计算分解与原因判断，说明缺失数据和方法限制。需要以后继续时保留会话与结果 ID。

追问时说明保持哪些范围、需要历史结果还是当前数据。例如：“保持 west 地区不变，按客户类型进一步比较。”
