明确来源日期或时间戳的解释方式、业务时间字段和观察范围。观察区间包含起点、
不包含终点。来源解析时区、日历边界时区和 `Session` 报告时区各有不同作用。
定义业务期间时，应使用合适的日历和边界时区；可能重叠的活动或节假日应建模为
命名活动期间。
统计工作日时，日程需覆盖所选范围内的每个日期，包括调休日；缺失状态表示未知。
严格样本规约仅在 `TimeDimension` 声明 `sample_interval` 且观察范围有限时检查
预期采样时刻。详见
[日期与时间定义](/zh-cn/docs/latest/modeling/dates/)和
[时间序列与窗口](/zh-cn/docs/latest/analysis/time-series/)。
