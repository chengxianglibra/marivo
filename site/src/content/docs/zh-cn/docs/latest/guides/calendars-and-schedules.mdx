业务日历由 harness 或业务数据服务维护。Marivo 使用普通业务字段和明确时间范围执行分析。

- 按财务月汇总：建模日期和财务月 key，并按业务维度聚合原始 Metric。
- 比较节假日：harness 确定每次假期的准确起止时刻和配对规则，再创建 `session.time_scope(...)`。
- 筛选工作日：使用普通日期数据和工作日状态；保留未知状态，显式选择不连续成员。
- 自然周期窗口：使用 `mv.grain(...)`、`scope.by(grain)` 和已支持的窗口规则。

日期编码和时区声明见[日期与时间](/zh-cn/docs/latest/modeling/dates/)。输出分桶和窗口见[时间序列](/zh-cn/docs/latest/analysis/time-series/)。
