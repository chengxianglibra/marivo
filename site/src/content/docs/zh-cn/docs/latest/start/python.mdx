从[安装](/zh-cn/docs/latest/start/installation/)中创建的独立项目开始。本例使用六笔已完成订单，金额为 CNY，不含退款或货币换算。

## 创建数据

保存为 `seed.py`，运行 `.venv/bin/python seed.py`。脚本会重建 `warehouse.duckdb` 中的 `orders` 表并替换其内容。
{/* example: demo-seed */}

```python title="seed.py"
from datetime import date
from pathlib import Path
import duckdb

Path("models/datasources").mkdir(parents=True, exist_ok=True)
Path("models/semantic/sales").mkdir(parents=True, exist_ok=True)
with duckdb.connect("warehouse.duckdb") as connection:
    connection.execute("""
        CREATE OR REPLACE TABLE orders (
            order_id BIGINT PRIMARY KEY,
            order_date DATE,
            region VARCHAR,
            amount BIGINT
        )
    """)
    connection.executemany(
        "INSERT INTO orders VALUES (?, ?, ?, ?)",
        [
            (1, date(2026, 7, 5), "east", 100),
            (2, date(2026, 7, 15), "east", 200),
            (3, date(2026, 7, 20), "west", 700),
            (4, date(2026, 8, 5), "east", 100),
            (5, date(2026, 8, 15), "east", 100),
            (6, date(2026, 8, 20), "west", 600),
        ],
    )
```

## 定义收入

保存为 `models/semantic/sales/_domain.py`。本例保留日期和地区，供后续分析使用。声明规则详见[语义层](/zh-cn/docs/latest/modeling/semantic-layer/)。

{/* example: demo-model */}

```python title="models/semantic/sales/_domain.py"
import marivo.datasource as md
import marivo.semantic as ms

ms.domain(name="sales", owner="Mina Zhang")
orders = ms.entity(
    name="orders",
    datasource=ms.ref.datasource("warehouse"),
    source=md.table("orders"),
    primary_key=["order_id"],
)
order_date = ms.time_dimension_column(
    name="order_date", entity=orders, column="order_date"
)
region = ms.dimension_column(name="region", entity=orders, column="region")
amount = ms.measure_column(
    name="amount",
    entity=orders,
    column="amount",
    additivity=ms.additive_all(),
    unit="CNY",
)


@ms.metric()
def revenue():
    return amount.sum(time=order_date)
```

## 计算收入

保存为 `quick.py`，运行 `.venv/bin/python quick.py`。

{/* example: quick-analysis */}

```python title="quick.py"
from uuid import uuid4

import marivo.analysis as mv

session = mv.session.get_or_create(
    f"first-analysis-{uuid4().hex[:8]}", timezone="UTC", domains=None
)
catalog = session.catalog
revenue_entry = catalog.get("metric:sales.revenue")
assert revenue_entry.kind == "metric"
revenue = revenue_entry
pending = session.observe({"revenue": revenue})
fixed = pending.compute()
fixed.show()
```

总额为 CNY 1,800，即六笔订单金额之和。每次运行都会创建一个新的项目内 Session。

`compute()` 返回包含完整结果的内存 Frame。在当前进程中继续从 `fixed` 计算，可使用这次观测的值。需要在另一个进程中恢复这些值时，持久化 `fixed` 并保留返回 Frame 的 `session_id` 和 `artifact_id`；详见[结果与方法事实](/zh-cn/docs/latest/analysis/results/)。

本例中的 `domains=None` 会加载这个独立演示项目的全部语义域目录。较大的项目应指定分析所需的全部领域；显式领域列表不会自动扩展其依赖。

下一步可运行[分析 DSL 完整示例](/zh-cn/docs/latest/analysis/dsl/#完整示例与后续输入)，按月和地区比较收入。在 Python 中先执行 `import marivo`，再调用 `marivo.help("analysis.session.observe")` 查看精确签名。
