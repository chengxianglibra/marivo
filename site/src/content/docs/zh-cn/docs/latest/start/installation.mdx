安装、查询 Help 和运行分析应使用同一个项目环境。需要 Python 3.10 或更高版本。以下命令使用 `.venv/bin/python`；Windows 下请替换为 `.venv/Scripts/python.exe`。

## 安装本指南对应的源码

`latest` 文档介绍开发版 API。获取源码，记录修订，然后在独立演示目录安装。下面的命令需要已安装 Git 和 uv。

```bash
git clone https://github.com/chengxianglibra/marivo.git marivo-source
git -C marivo-source rev-parse HEAD
mkdir marivo-demo
cd marivo-demo
uv venv --python 3.10 --seed
uv pip install --python .venv/bin/python -e "../marivo-source[duckdb]"
.venv/bin/python -m marivo --version
.venv/bin/python -m marivo doctor --project-root .
```

分享复现步骤时保留该修订。继续之前，核对 Doctor 显示的 Python、包路径与项目根目录。

连接 MySQL 或 MariaDB 时，选择 `../marivo-source[mysql]`。该 extra 会安装带 RSA
认证支持的 PyMySQL，无需本地 MySQL 客户端 C 库。`all` extra 也包含该驱动。

## 使用发布包

在已安装 `uv` 的环境中，请新建项目环境，按需安装后端 extra，并阅读对应发布版本的文档。DuckDB 教程的安装命令如下：

```bash
mkdir marivo-release-demo
cd marivo-release-demo
uv venv --python 3.10 --seed
uv pip install --python .venv/bin/python "marivo[duckdb]"
```

其他后端 extra 包括 `postgres`、`mysql`、`trino` 和 `clickhouse`；参阅[后端依赖](/zh-cn/docs/latest/reference/backends-and-limits/)。

可选安装器是 Bash 脚本，支持 macOS、Linux、WSL 和 Windows 的 Bash shell。运行 `curl -fsSL https://marivo.io/install.sh | bash` 后，它会在当前目录创建或复用 `.venv`、安装带有 `duckdb,trino,clickhouse` extra 的发布包，并初始化项目。默认 extra 不合适时，可通过 `curl -fsSL https://marivo.io/install.sh | bash -s -- --extras mysql` 指定其他后端。脚本会报告 Python 可执行文件和 Marivo 版本。若要使用最新开发 API，请按上文从源码安装。

## 按需初始化

```bash
.venv/bin/python -m marivo init
```

初始化会创建项目模板和目录；没有配置文件的空目录也可以直接使用。在已有项目中，`--force` 会先删除 `marivo.toml`、`models/`、`.marivo/`，以及 `.agents/`、`.claude/` 和 `.codex/` 下的 Marivo skill 路径，再重新创建脚手架。只有确实要替换这些文件和状态时才使用。

## 选择项目

已有项目中，请从项目根目录运行命令，在同一环境中安装项目依赖，并设置数据源声明引用的环境变量。新项目先在独立目录完成快速开始，再替换教程数据和定义。

检查解释器、包路径和项目根后，继续[快速开始](/zh-cn/docs/latest/start/python/)。
