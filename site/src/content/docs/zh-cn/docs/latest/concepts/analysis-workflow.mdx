从已确认口径的 Metric、成员 Entity 和针对当前问题的 Session 开始。
[Python 教程](/zh-cn/docs/latest/guides/python-quick-start/)提供完整本地项目。
本页示例使用另一套已加载的销售模型：包含客户、订单、收入以及订单到买家的已声明关系。

## 构造、执行、读取

`members()`保留 Entity 完整、有序的主键。观察绑定已治理 Metric 和明确窗口；比较方向是当前值减去基准值。

{/* example: customer-period-change */}

```python
import marivo
import marivo.analysis as mv
import marivo.semantic as ms

session = mv.session.get_or_create("revenue-review", report_timezone="UTC")
customers = session.members(ms.ref.entity("sales.customer"))
revenue = ms.ref.metric("sales.revenue")
buyer = ms.ref.relationship("sales.order_buyer")
current = customers.observe(
    revenue,
    during=mv.time_scope(start="2026-08-01", end="2026-09-01"),
    via=buyer,
    by=(ms.ref.entity("sales.customer"),),
)
baseline = customers.observe(
    revenue,
    during=mv.time_scope(start="2026-07-01", end="2026-08-01"),
    via=buyer,
    by=(ms.ref.entity("sales.customer"),),
)
change = current.compare(baseline).execute()
change.show()
```

构造返回 Logical relation，不读取业务行，也不分配 Run。
为确定键和值类型，schema-only preflight 可能连接数据源。
`execute()`完成准入和图执行，然后发布 Materialized 结果。
在 Materialized 接收者上调用方法，会构造使用保留输入的新 Logical 工作。

## 读取数据与合法后续操作

`show()`读取保存的数据。`contract()`在不读取业务行的情况下描述机械上可用的操作，并不替你决定下一项有价值的业务问题。

{/* example: bounded-result-display */}

```python
change.show(n=20)
change.show(n=0)
change.show(max_output_bytes=None)
```

默认输出预算为 8 KiB，不设默认行数上限。无法容纳时省略完整行，
Defined、Null、Undefined、Unknown 保留各自的标签与原因。
`to_pandas()`返回完整、隔离的副本，属于终端展示边界。
展示限制不会改变执行限制。

## 聚合原始含义

本例复用上面的 `session`、`mv`、`ms`。销售模型声明了可加的收入 Metric 及其买家路径。

{/* example: customer-original-rollup */}

```python
customers = session.members(ms.ref.entity("sales.customer"))
revenue = ms.ref.metric("sales.revenue")
buyer = ms.ref.relationship("sales.order_buyer")
august = mv.time_scope(start="2026-08-01", end="2026-09-01")
august_revenue = customers.observe(
    revenue, during=august, via=buyer, by=(ms.ref.entity("sales.customer"),)
)
total = customers.observe(revenue, during=august, via=buyer).execute()
total.show()
restored = session.artifact(total.state.artifact_ref)
restored.contract().show()
for action in restored.contract().actions:
    print(action.call, action.help_target)
saved_observation = august_revenue.execute()
recovered_observation = session.artifact(saved_observation.state.artifact_ref)
recovered_observation.summarize(method=mv.count()).execute().show()
```

`rollup()`合并充分的原始 Metric 组成状态，再完成已治理方程。
`summarize()`则对当前表示的行创建新统计量。
显示均值的平均值并不等于原始加权均值。
同一 Entity 根上的分组观察，不因分组而额外需要关系。

普通 `observe` 直接计算总体指标。成员范围决定纳入哪些贡献；`by=(member_entity,)` 保留成员完整身份，`by=(dimension,)` 直接计算分组指标。`groups` 指定逻辑目标域并保留空组。`during=grid` 始终保留全部时间桶，`by` 只选择空间粒度；端点读取与累计观测通过 `at=grid.before_end/end` 直接绑定网格。归因需要分区时，先观测分区再做原始归并。原有 `coordinates` 参数和分组域的 `observe` 入口已移除。

## 按同一实体分组

此销售模型使用 `sales.order` 和其已声明的类别维度 `channel`。

{/* example: same-entity-grouping */}

```python
orders = session.members(ms.ref.entity("sales.order"))
channel = ms.ref.dimension("sales.order.channel")
channel_revenue = orders.observe(
    ms.ref.metric("sales.revenue"),
    during=mv.time_scope(start="2026-08-01", end="2026-09-01"),
    by=(channel,),
).execute()
channel_revenue.show()
```

当 Metric 的根实体也是分析实体时，可直接使用该 Entity。
贡献根不同时，需要提供明确声明的关系路径。

## 明确来源与已保存结果边界

再次执行 live 定义会读取当前来源。使用 `session.artifact(ref)`恢复某个确切的历史结果。
fixed 后续操作消费保留状态，不重放来源。在 fixed 接收者上新增 live Metric、字段或 Event
依赖会形成 mixed 工作，并在读取任何业务输入之前拒绝。

继续阅读[时间与群体](/zh-cn/docs/latest/guides/time-and-cohorts/)、
[比较与归因](/zh-cn/docs/latest/guides/comparison-and-attribution/)、
[统计方法](/zh-cn/docs/latest/guides/statistics/)或[证据与恢复](/zh-cn/docs/latest/concepts/evidence/)。
不熟悉某项能力时从 `marivo.help("analysis")`开始；已有对象时跟随其 contract
和确切 Help 目标。结构化错误负责具体修复。

## 发现 Session

Session 发现只读取当前代 Store。尚未创建当前 Store 时，
`mv.session.current()` 返回 `None`，`mv.session.recent()` 返回空页，
这些读取不会创建 Store 状态。旧代目录可以保留在同一项目中，同时创建新的
Session；旧代 Session 不会被读取或迁移。当前 Store 无效或不可读时，
仍会抛出结构化错误。

{/* example: session-discovery */}

```python
import marivo.analysis as mv

current = mv.session.current()
history = mv.session.recent(limit=5)
session = mv.session.get_or_create("revenue-review", report_timezone="UTC")
```

## 保存语义范围

`mv.session.get_or_create("sales-review", domains="sales")` 保存准确的语义 domain
选择，也可传入非空序列。再次获取时省略参数会保留原范围，显式传入冲突范围会失败。
用 `session.domains` 读取它；固定结果依据保存的状态继续计算，无需当前模型。
Session 元数据使用 Store 第 9 代；旧代目录保持原样，不自动迁移。
