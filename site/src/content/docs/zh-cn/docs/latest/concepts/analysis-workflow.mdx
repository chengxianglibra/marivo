## 为下一项决策读取指导

marivo-analysis 技能负责问题范围、语义交接与完成判断。未知能力从
`marivo.help("analysis")` 开始，只沿下一步需要的路线发现，不要求读完目录。
Population/Frame.show 拥有已捕获结构，聚焦类型 Help 拥有调用，错误拥有修复。
Catalog 定义卡、readiness、真实来源求值与保存数据证明不同事实。

## 创建并恢复精确 Session

`mv.session.create(name, *, question=None, timezone=None, domains=None)` 创建项目内唯一的新名称；
同名错误给出现存真实 ID。规范化 domains 与 timezone 在创建时冻结；省略时区只在创建时解析
系统时区，显式非法时区失败。`session.timezone` 返回保存的名称。
`mv.session.resume(session_id)` 只恢复该精确已有身份；`recent()` 有界发现名称与 ID，
`inspect(session_id)` 只读元数据、不恢复。没有隐含 current Session。
纯 resume/inspect/compute 不刷新 updated_at。
`reconcile_run(session_id=..., run_id=...)` 核对原发布事务和资源，活动 writer 冲突会拒绝。

## 显式构造来源输入

所有数据入口返回不可变 AnalysisFrame。observe 绑定已解析 Metric 和 by/where；TimeScope 与 CalendarAxis 都放入 by；
read 将非空字段绑定到一个完整 Entity 身份域；values 声明字面量坐标与值；frame 绑定一般
Population 键域，包括零轴与无命名值。构造与检查不读业务行或 schema，不创建 Run。
未知身份按需浏览 Catalog，已知名称精确查找；没有顶层执行 Session 别名。

tuple by 按观察到的联合坐标分组；by=Population 只选择指定完整键并保留无事实坐标。
where=mv.in_population(P) 筛选事实贡献。P.count() 捕获完整去重元组域为整数惰性 Metric，
包含 Null 分类和无事实身份；P/Q 各自计数，不从 by 或 where 推断分母。

observe 与 members 也接受 `(status == "paid") | mv.in_population(P)` 这样的原生混合条件；
使用带括号的 `&`、`|`、`~`。字段 NA 保持未知直到最终只选 True，成员判断为非 nullable。
Population.where 只允许已有坐标上的成员叶子。Frame.where 接收该精确 Frame 的普通布尔
Column，包括直接布尔值或 presence 列，False 与 NA 不选中；源端条件不转换为结果 Column。
详见 `marivo.help("semantic.predicate")`。

空域计 0，零轴单元域计 1。分组坐标须已存在于 P；按新属性计成员须先显式 classify 并保留身份，
直接投影到属性后计数则数去重类别。
Field Null 是合法类别，Entity 身份保留全部非空主键分量。
classify/image/preimage 使用显式受治理依赖，字段保留 via/at 绑定。
同路径定义变化本身不拒绝旧输入；kind/root/grain/unit/time/null 正确性仍要检查。

## 下一项决策前固定值

```python
import marivo
import marivo.analysis as mv

# Reuse the local tutorial's resolved inputs and Session.
pending = session.observe({'revenue': revenue}, by=(august, region))
pending.show()  # Captured facts only.
fixed = pending.compute()
fixed.show(n=10)
saved = fixed.persist()
reopened = session.persisted_frame(saved.artifact.id)
selected = reopened.where(reopened["revenue"] > 300).compute()
selected.show()
marivo.help("analysis.analysis_frame")
```

compute 返回完整内存数据，persist 发布已经完成的结果。继续使用返回的固定 Frame 才保留
精确值与键；派生操作仍惰性。原来源表达式再次求值可能读取变化后的数据，不代表历史复用。
完整数据没有生产图、语义对象、连接或聚合组件。恢复需要精确 Session 身份和
`frame.artifact.id`，不能由“最新答案”代替。

Frame 在所有载体上支持当前行 where/select、全局 top、按已有完整轴 reduce、全轴
align/compare 与受支持冻结日历 match。Column/FrameAxis 绑定精确输入。
普通轴需要完整显式 on，零轴与各自唯一日历轴只有规定的推导。生成值路径按全名精确查询，
不按后缀猜角色；presence 独立于 NA。

## 显式请求新来源事实

```python
parents = session.population_from(selected, on=((selected.axes[1], region),))
new_source = session.observe({'revenue': revenue}, by=(july, region), where=mv.in_population(parents)).compute()
new_source.show()
```

桥接投影普通轴完整联合键，并显式提供 Field/Entity 绑定。on 必填，也可为空。
它不重建语义历史、不把字段升级为身份；固定父键不重新排名，新读事实仍可能变化。
interval 轴、日历轴、配对轴与任意值列不能桥接。by=Population 选择完整输出键；in_population 选择事实贡献。
原整体均值/去重、新属性、窗口或粒度需要显式来源构造，当前行 reduce 不等于原量 rollup。

## 保持来源贡献与时间含义

Metric.per 先在每个样本完成完整子公式再规约。显式样本 Population 按子政策保留空样本；
内部样本域与外部指定输出域各自独立。归属规则单独通过
`observe(..., memberships=(rule,))` 或 `metric.per(samples, memberships=(rule,))` 传入，
只映射本层 by/samples 已声明的坐标，外层/内层规则互相独立。Population 只保存键和依赖。
membership 保留关联元组与分配因子，重复链接不重复同次贡献，
等值但不同身份的贡献仍分别计算。多根公式先各自规约，再对齐完整域。

Metric.window 绑定显式来源窗口，每个端点完成自己的 W(t)，显示起点不截断回看。
经过时间与民用期间不同，Session/parser/calendar 时区权威分离；by 提供唯一 interval/calendar 时间轴与窗口端点，
已绑定快照的 Grain 必须匹配 Session 冻结权威。完整 Frame 解释不重载模型或时区规则。

## 按边界读取数据与审计

Frame.show(n=0) 仅元数据，正 n 读取有序前缀与所需冻结标签、边界、配对端点。
完整 compute/export 验证全部必要消费数据。Artifact.show/findings/evidence_digest 只读审计，
Artifact 没有 n 或 to_pandas。来源读取、求值与提交时间不同；Run 是求值完成后对已有
result ID 的发布，compute 失败不创建 Run。未知提交通过 reconciliation 解决，不重新计算。

恢复后仍可继续类型化数据操作；未支持的外部方法需要固定输入、假设与可复算算术。
导出 attrs 不能回灌为计算合同；新的原来源问题保持显式。
参见[统计](/zh-cn/docs/latest/guides/statistics/)、
[时间与人群](/zh-cn/docs/latest/guides/time-and-cohorts/)及
[证据](/zh-cn/docs/latest/concepts/evidence/)。


分组规则使用 `by=(field_or_grouping, ...)`。`mv.identity(entity)` 声明完整身份分组，
`scope.by(grain)` 声明时间分桶；`mv.membership(...)` 只传入消费端 memberships 参数。
`population.axes` 复用坐标定义；`by=population` 选择完整输出键，包含空桶，不要求覆盖域外来源坐标。
`mv.coordinates(...)` 统一构造有限字段/身份域及相关多轴元组，每个身份值始终是完整主键元组；
`mv.identity(entity, at=...)` 可指定版本锚点。
Population.where 接受 `mv.in_population(...)` 谓词，字段条件通过 members/read/Frame 筛选。

使用 `show()` 检查已捕获的人群，并通过 `axes` 复用其有序坐标：

```python
domain = mv.coordinates(
    by=(mv.identity(entity),), keys=((("C1",),), (("C2",),)),
)
domain.show()
axes = domain.axes
```

Population.show 打印捕获定义，不求值键；Python 真值判断不用于检查 Population 是否为空。
