某个术语影响计算含义时使用此对照。确切类型与调用契约由 native Help 提供。

## 术语

| 术语 | 含义 |
| --- | --- |
| Semantic Ref | 已治理声明的稳定 typed identity |
| Entity / Subject | 业务实例及其完整有序身份 |
| Member domain | 显式选择的实例；版本不替代实例键 |
| Coordinate / grain | 保留输出位置与观察单位 |
| Quantity | 方程、单位、贡献身份与状态策略 |
| Population / AnalysisFrame / Column | 有限完整域 / 三种载体的不可变数据 / 精确输入上的值 |
| Nullable value / presence | 普通 NA / 独立端点存在性 |
| 显式来源观察 / 行统计 | 求值受治理来源 / 规约当前行 |
| Artifact | 精确已提交结果身份与审计视图 |
| Evidence / Finding | 记录的计算事实 / typed 提取事实 |
| 覆盖 | 来源范围允许观察确定什么 |
