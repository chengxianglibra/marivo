title: 证据
description: 读取已提交的 Dataset Finding，分别检查完整性与语义权威事实。
---

证据记录已提交 Dataset 的确定性事实。Agent 负责跨结果综合、业务判断和因果解释。

```python
artifact = current.compare(baseline).execute()
artifact.show()
print(artifact.evidence_digest.finding_count)
page = artifact.findings(limit=20)
if page.items:
    artifact.finding(page.items[0].finding_id).show()
```

示例要求同一 Session 中两个兼容的 Metric Dataset。Logical Dataset 在执行前没有持久化证据读取。v3 ArtifactDigest 保存确切的 Artifact、提取器身份、质量与问题摘要、Evidence 和 Finding 集合摘要及 Finding 数量；它不是生成的叙事。

FindingPage 包含不可变 items、limit、has_more 和不透明 next_cursor。通过所属 Artifact 继续翻页。缺失或损坏的状态会明确失败，空页不能掩盖不可用的 Store。

## 冷恢复

```python
run = session.get_run(run_id)
if isinstance(run, mv.SucceededRun):
    artifact = session.artifact(run.output_artifact_ref)
    artifact.show()
```

Run 历史和图仅反映已提交事实。恢复不查询当前数据源，也不重放原始计算。`session.revalidate(artifact.state.artifact_ref)` 分别检查 Artifact、语义权威和 Evidence 完整性；它不能证明数据源新鲜度或业务适用性。

Delta 与 Attribution 是代数结果，Association 是描述性结果，Forecast 是模型输出，Candidate 是经过评估的线索。最终解释需保留它们的范围、选择条件、质量和完整性限制。

从 `marivo.help("analysis.evidence")` 发现当前入口。终端自定义 DataFrame 或原始 SQL 结果不能重新进入受治理的 Dataset 分析。
