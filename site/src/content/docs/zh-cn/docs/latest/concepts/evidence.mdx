已提交的图 Artifact 拥有保留行、必要部件与已验证的续算契约，生产 Run 记录执行身份。
跨结果综合、业务判断与因果解释由 Agent 负责。

```python
artifact = current.compare(baseline).execute()
artifact.show()
artifact.contract().show()
run = session.get_run(artifact.state.producing_run_ref)
run.show()
```

示例假设同一 Session 内有两个兼容的数值观察。`show()` 提供有界检查，
`contract()` 校验精确 Artifact 并披露当前续算操作。必要部件缺失或损坏时明确拒绝；
Logical relation 在执行前没有保留行。

旧 Dataset Findings 与 ArtifactDigest 不是 Store 7 relation 的检查协议；
更完整的方法家族等待 R6–R9 迁移。

## 冷恢复

```python
run = session.get_run(run_id)
if isinstance(run, mv.SucceededRun):
    artifact = session.artifact(run.output_artifact_ref)
    artifact.show()
```

Run 历史与图展示已提交事实。精确恢复验证冻结 snapshot、主表及部件 receipt，
不查询当前来源、不加载当前 Semantic 定义，也不重放来源构造。
旧 Store 代际在不迁移的情况下拒绝读取。这些检查不证明来源新鲜度或业务适用性。
重复执行来源定义会创建新求值；使用 `session.artifact(ref)` 恢复指定的成功结果。

Difference 是代数比较，Spearman association 是描述性关联。解释结果时保留其域、
单位、Cell 状态与方法限制。终端自定义 DataFrame 或 raw SQL 结果不能重新进入受管分析。

从 `marivo.help("analysis")` 开始，跟随结果 contract 提供的精确 Help 目标执行已准入的下一步。
