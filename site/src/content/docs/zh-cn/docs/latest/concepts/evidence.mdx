---
title: 证据链
description: 通过 Artifact 自有的 Finding 读取保持可审计，同时区分语义权威与数据源新鲜度。
---

Marivo 的证据层记录确定性分析事实，但不替智能体组合 Finding、判断因果或业务有效性。

## 读取当前 Artifact

```python
artifact = session.compare(current, baseline)
artifact.show()
print(artifact.evidence_status, artifact.finding_count)
```

`evidence_status` 为 `complete`、`partial` 或 `unavailable`。内嵌
`evidence_digest` 是有界的即时摘要；遗漏项通过同一 Artifact 审计：

```python
page = artifact.findings(limit=20)
finding = artifact.finding(page.items[0].finding_id)
```

`FindingPage` 不可变，`has_more` 为真时把 `next_cursor` 传回同一方法。
Finding 保留完整 derivation、来源 Artifact、字段、引用以及被摘要保留的 item 引用，
因此不再提供独立 derivation trace API。

## 冷启动恢复

```python
runs = session.runs(limit=20)
run = session.get_run(runs.items[0].run_id)
artifact = session.artifact(run.output_artifact_ref)
graph = session.graph(artifact_ref=artifact.ref, direction="ancestors")
```

Run 与 Graph 只投影持久化的运行事实。它们不检查当前语义权威，也不检查数据源新鲜度。

## 当前权威

```python
check = session.revalidate(artifact.ref)
check.show()
```

revalidation 检查持久化身份、当前作用域语义权威和证据完整性，但仍不查询数据源健康状态，
也不证明新鲜度。`admissible` 不能被解读为业务有效、推荐行动或数据源当前。

## 失败边界

- ledger 不可读会抛出 `EvidenceStoreUnavailableError`，不会伪装为空页面；
- 不属于该 Artifact 的 id 会抛出 `FindingNotFoundError`；
- 不兼容 Store、Run 或 Artifact schema 会在投影前失败，旧目录保持不变；
- 不提供 Session Evidence namespace、digest page、Finding selection compatibility 或兼容别名。

从 `marivo.help("analysis.evidence")` 获取当前唯一入口。
