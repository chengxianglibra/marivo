description: 不依赖当前来源的产物阅读与已保存 Evidence。

Store 11 将最终输出保存在 `.marivo/analysis/generations/v11/`。
Parquet 文件持久化后，通过一个 SQLite 事务共同发布 manifest、receipt、Finding、
Evidence 和 Run 成功状态。失败调用不会发布部分 Artifact；恢复只协调原 Run 及其确切
资源 journal，不重放计算。

## 执行并检查 Run

已有解析完成的 `revenue` Metric 和 Session：

```python
query = session.observe({"revenue": revenue})
artifact = query.execute()
print(artifact.id)
print(artifact)
for run in session.runs(limit=5).items:
    run.show()
```

每次 execute 重新求值，创建新的 Run 和 Artifact。Artifact 只持已提交身份与元数据，
没有 `contract()` 或 DSL 续算能力。无来源常量也使用同一发布路径。

## 保存事实与阅读边界

普通观察不产生 Finding。Evidence 只记录实际来源读取与实际检查，包括读取范围；
省略期间明确表示未追加时间约束。这些记录不认证来源完整性、跨来源快照、新鲜度或因果结论。

保存的 schema 描述完整键、命名 nullable 值、独立 presence、类型和单位；
必要输出附件保存 UTC 日历边界，主表及附件的 schema 同时保留所选日历时区；读取范围摘要保留布尔条件的嵌套分组。不保存语义定义、图、公式、隐藏规约组件、计算指纹或 continuation。

新产物和重开产物使用同一已提交输出 reader。打开与 repr 只读元数据；
预览最多解码请求行数，但 receipt 摘要仍可能读取整个已消费 part。
导出返回完整隔离 DataFrame，采用 RangeIndex、kind/name 两层列及纯数据 `attrs["marivo"]`。
日历坐标来自已保存的真实桶起点，同时保留时区与实际边界。

```python
import marivo

saved = session.artifact(artifact.id)
saved.show(n=20)
frame = saved.to_pandas()
page = saved.findings(limit=20)
digest = saved.evidence_digest()
print(digest.items)  # all actual saved Evidence; no limit or cursor
if digest.items:
    marivo.help(type(digest.items[0]))  # static saved-fact type
```

Finding 分页与完整 Evidence 摘要不依赖 Parquet 或当前模型。
`digest.show()` 保持有界，`.items` 包含全部已保存事实。
当前模型的改名、删除或变化不影响历史值。Session 图只展示 Run/输出关系和已保存摘要，不包含定义指纹。

`session.graph()` 只包含同一 Session 的 Run→Artifact `produces` 边；失败与未完成
Run 是独立节点。Run 的 `dataset_input` 保留为执行标记，不再提供消费 Artifact 引用。
所有选中 Run 都是 root，所有选中 Artifact 都是 head；head 不代表“最新答案”。
Session 摘要将所有 Artifact 计为 head，最多展示三个引用。

```python
graph = session.graph(artifact_ref=artifact.id, direction="ancestors", max_nodes=100)
graph.show()  # Artifact and its producer
session.graph(artifact_ref=artifact.id, direction="descendants").show()  # Artifact alone
```

`max_nodes` 范围仍为 1–500。boundary 字段标识存在未选中请求邻居的已选节点，
`truncated` 表示选择不完整。未指定 Artifact 时使用 `direction="ancestors"`。

Store 10 及更早 Store 和图/continuation 格式明确拒绝，不改写或迁移。更换 Session 名称不能绕过代际限制；
请在新项目创建新格式 Store 并重新运行分析脚本。同代际 Session resume 保留身份和 Run 历史。
Store 11 的终端输出 v1 编码与 Parquet 规格保持不变。

从 `marivo.help("analysis")` 开始发现。
