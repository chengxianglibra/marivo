title: 证据与恢复
description: 无需当前来源读取精确固定数据与审计。
---

Store 13 在 `.marivo/analysis/generations/v13/` 保存 Frame 数据。数据持久后，一个
SQLite 发布事务同时提交 manifest、收据、Findings、Evidence 与 Run 成功。
compute 不创建 Run；persist 在准入前完成求值，再发布已有 result ID。
内存 persist 不重新求值，存储根 persist 验证提交元数据并返回自身。

## 读取数据与审计

已有已解析 revenue Metric 和 Session 时：

```python
saved = session.observe({"revenue": revenue}).persist()
print(session.id, saved.artifact.id)
saved.show(n=20)
saved.artifact.show()
reopened = session.persisted_frame(saved.artifact.id)
complete = reopened.compute()
page = reopened.artifact.findings(limit=20)
digest = reopened.artifact.evidence_digest()
print(digest.items)
for run in session.runs(limit=5).items:
    run.show()
```

普通 observe 没有 Findings。一份审计保留继承的实际来源事实与本次求值，不累计中间操作历史。
仅完全相同的事实去重，不同范围与读取时间保留。来源读取、求值与提交时间不同；保存旧数据
不会刷新它。保存输入身份不构成可执行血缘依赖。

## 预览与完整数据

打开/repr、show(n=0)、Artifact.show/findings/evidence_digest 只读元数据或审计，不消费载荷。
正 n show 解码有序前缀和所选冻结坐标记录；收据散列或解压可能读取更多字节，预览成功不证明
未读部分完整。完整 compute/to_pandas 验证必要值、键、presence 与日历/映射附件，不加载
Catalog、来源 schema、连接、模型或时区规则。

导出返回隔离 RangeIndex 数据，列为原始键 `(kind, name)` MultiIndex；隔离的类型化 attrs
包含 axes、units 与 frozen_coordinates 表。日历标签/边界和配对端点自包含，最简单的解释入口
是 show。没有新增可见投影列、endpoint API 或 attrs 导入器。
恢复后的 Frame 可继续数据操作，新来源事实需要显式构造。

## 区分发布图与数据历史

使用 runs/get_run 与输出引用查询发布历史；Session 不提供 graph/roots/heads。
也不承诺完整数据血缘。本次求值记录实际直接消费的存储输入；载体复制不伪造读取或血缘边。
reconciliation 解决原事务，不重新求值。完整内存结果在旧文件删除后仍独立可用；旧存储句柄
若再次读取已删除数据仍会失败。

## 旧数据与证据限度

Store 13 拒绝旧 generation 的 Session/result/Findings/Evidence 访问，不改写旧字节，
不迁移或双读。缺少当前 generation 的发现可返回 None/空而不暴露旧数据；create
不能在仅有旧 Store 的项目初始化旁路。切换前用原版本导出，或保留兼容读取环境。
参见[故障排查](/zh-cn/docs/latest/reference/troubleshooting/)。

保存事实不认证来源完整、当前语义权威、跨源快照、新鲜度或因果。
RawSqlResult 保持独立 datasource reader，不进入 Frame Store。
从 `marivo.help("analysis")` 发现；类型 Help 拥有调用，show 拥有已捕获事实。
