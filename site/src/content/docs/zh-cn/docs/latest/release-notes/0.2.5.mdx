Marivo 0.2.5 是 v0.2 系列的补丁版本发布，聚焦面向智能体语义
编写、目录浏览和本地运行时可观测性。这个版本收紧了围绕
项目本地文件的语义接口，让目录 traversal 更直接，并从公共
契约中移除了旧的 decision ledger。

## 重点

- 语义 projects 现在可以从 `layer_paths` 加载多个 layer 根，因此 teams 可以把
  数据源、领域和指标声明拆到多个文件，而不必压平成单个 module。
- 语义决策账本已从公共接口移除。就绪检查和验证现在聚焦
  已声明的语义对象与来源证据，而不是额外的 internal decision log。
- 目录浏览模型引入了类型优先 API，提供有界输出、明确的
  drill-down 键，以及指向下一步具体调用的面向智能体帮助。
- **迁移说明：** 类型优先 browsing API 后续已被类型化目录集合
  （`catalog.domains`、`catalog.metrics` 等）和 concrete 目录对象取代。请使用
  `catalog.domains.show()` 和 `sales.entities.get("orders")` 进行类型化 navigation，
  替代早期的类型-范围 matrix。
- 本地使用遥测现在记录在项目本地状态中，因此 CLI 和运行时 usage
  可以被检查，而不会发送到外部服务。

## 变更

- 目录发现结果现在围绕数据源、领域、实体、维度、
  度量、指标和关系等 kinds 组织。
- 语义 loader 和 reader 行为现在把 configured layer 根作为项目契约，并在
  ambiguous 名称上失败即停止。
- 智能体帮助与内置语义/分析技能现在引导作者使用当前的帮助、发现、
  验证和目录-browsing surfaces。

## 修复

- 标量行-count 质量检查不再为有效的单行 aggregate 输出产生噪音警告。
- 分析错误 rendering 与 frame 指引围绕当前语义输入契约进一步收紧。

## 文档

- 增加多根目录语义 projects 与类型优先目录浏览的设计说明。
- 更新 `latest` 与 `v0.2` 安装、快速开始、语义层和就绪检查
  文档，使其匹配当前语义项目模型。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.5 需要 Python 3.12 或更高版本。
