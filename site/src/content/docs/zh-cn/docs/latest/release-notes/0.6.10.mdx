发布于 2026 年 11 月 18 日。Marivo 0.6.10 提升了冷启动语义加载和 Trino schema
绑定的速度，未变更公共 API。

## 亮点

- 加载项目时一次性构建精确的 Catalog 索引，并将定义与搜索投影推迟到实际需要时
  再生成。已解析的模型源码、已解析的引用和规范项目根目录在各自原有作用域内复用，
  不再为每个定义重复构造。
- Trino 列元数据无需分布式排序即可保持序号顺序：schema 绑定时获取列序号，并在
  本地恢复顺序。

## 修复

- 模块执行和语义编译改为读取当前编写的源码，多行字符串字面量保持原有行为。
- 带筛选的加载在字段所属 Entity 缺失时，会明确指出该字段，而不是无提示地失败。

## 内部

- 补充了 schema 读取在执行日志中的边界说明，并将 Trino schema 读取纳入 SQL
  归属审计。
- 本地 CI 默认改用 `make check-fast`；推送前仍须通过完整 `make check` 门禁。
