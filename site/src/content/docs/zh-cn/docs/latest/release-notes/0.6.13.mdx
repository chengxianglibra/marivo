发布于 2026 年 11 月 24 日。Marivo 0.6.13 改进分析执行性能并加强正确性检查。

## 亮点

- 使用 `MARIVO_CREDENTIAL_RESOLVER` 为 Python、CLI 和服务配置进程级宿主凭据解析器；显式的 `md.credential_scope` 优先。详见[宿主凭据配置](/zh-cn/docs/latest/reference/configuration/#集成宿主凭据)。
- 需要认证的数据源属性 HTTP 接口现在通过 `env_refs` 返回已声明的凭据引用名，不解析凭据值。
- 符合条件的分析查询可共享来源读取和条件聚合，减少重复分组及成员关系计算，并将合格的键限制下推到原生读取。
- 符合条件的 Frame 筛选、投影和终端操作可以合并；合格的民用日期窗口可共享原生分组状态。这些优化保留原有检查和结果语义。

## 变更

- 引用旧 `marivo.refs` 模块的 Python pickle 需要旧版包结构才能反序列化。升级前请使用旧版本读取并转换此类数据。

## 修复

- 分析归因的分支取值域判断考虑原生标量行为；当数据源无法证明键的精确唯一性时，保留必要的键检查。

## 文档

- 扩充分析代数和执行契约，说明改写条件、覆盖范围与保留的检查。

## 内部改进

- 为分析改写、结果发布恢复和跨引擎行为增加形式化及差分验证，并加强架构和静态检查。
