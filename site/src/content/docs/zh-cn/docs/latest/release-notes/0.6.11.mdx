发布于 2026 年 11 月 19 日。Marivo 0.6.11 为项目读取服务增加了语义对象搜索。

## 亮点

- 通过 HTTP 浏览和搜索语义对象，按类型或 Domain 筛选，并查看定义、关系及数据源属性。
- 搜索结合多语言 Granite 向量索引与精确 ID、路径匹配。重新加载时复用未变更的向量，并一起发布新的 Catalog 和索引。
- 可选的项目级向量缓存支持跨进程重启复用未变更的向量。服务启动时准备固定版本的模型，也可提供本地模型用于离线部署。

## 变更

- 安装 `marivo[api]` 以使用读取服务及其向量搜索依赖。启动、模型准备和搜索详情参见[读取服务指南](/zh-cn/docs/latest/reference/read-service/)。
