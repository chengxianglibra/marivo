Marivo 0.5.3 改进了运行时可观测性、空项目启动体验和日历窗口比较。

## 重点

- Terminal `Run` 现在会持久化有序的 backend query executions。
  `run.queries` 可以读取实际执行的 SQL，以及对应的数据源、方言、digest、
  行数、耗时、时间戳和成功或失败状态；失败的 execution 也会被记录。
- Marivo 可以直接从空的当前目录运行，不要求存在 `marivo.toml`、`models/` 或预先
  创建的 `.marivo/` 状态目录。首次需要时才会延迟创建声明目录和运行时目录；
  `marivo init` 仍然是可选操作。
- `session.compare(...)` 会在 frame 的 report timezone 中保留与部分窗口相交的日历桶，
  覆盖 time-series、panel 和 driver-axis replay comparison。

## 变更

- Run card 只展示有界的 query summary；需要查看确切 SQL 时，显式读取
  `run.queries`。
- Project discovery 和 Doctor 现在会报告零初始化项目的 effective defaults；显式配置
  无效时仍会拒绝，并提供类型化修复指引。
- 空的 calendar alignment 仍会以类型化 alignment error 失败，不会变成无法解释的空结果。

## 修复

- 当 exclusive window end 落在日历桶内部时，window-bucket comparison 不再丢失当天或尾部
  的部分桶。
- time-series、panel 和 driver-axis replay 路径现在一致使用修正后的 bucket spine。

## 文档

- 更新 analysis 和 evidence 指引，说明如何读取持久化 query。
- 更新 installation、quick-start、deployment 和 project-configuration 指引，说明如何从
  空目录开始使用 Marivo。

## 安装

国内网络建议运行：

~~~bash
curl -fsSL https://marivo.io/install-marivo-cn.sh | bash
~~~

也可以使用标准安装器：

~~~bash
curl -fsSL https://marivo.io/install.sh | bash
~~~

手动安装：

~~~bash
pip install marivo
~~~

Marivo 0.5.3 要求 Python 3.10 或更高版本。
