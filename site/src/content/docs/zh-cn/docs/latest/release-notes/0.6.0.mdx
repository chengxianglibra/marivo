Marivo 0.6.0 以 AnalysisFrame、Session 和 Artifact 身份组织分析。

## 主要变化

- `compute()` 返回完整固定内存数据；`persist()` 返回已提交的 Frame。
- 保留 Session ID 与 `saved.artifact_id`，恢复 Session 后通过
  `session.persisted_frame(artifact_id)` 精确打开数据，已保存 Frame 直接提供审计。
- `mv.session.inspect(session_id)` 返回 SessionSummary，不执行恢复。
- 公开 API 删除 Run 类型、历史、定向协调和错误中的 Run 身份；原子提交和受保护的恢复保留内部实现。
- Artifact ID 丢失时，先恢复 Session，再用 `session.persisted_frames()` 查看描述和结构，选择精确 ID。
  `persist(description=None)` 可选地将调用者用途保存在提交中。
- 结构化错误直接给出失败阶段和具体修复。提交结果未知时，先恢复 Session，再发现已提交 Frame。

这是破坏性切换，不保留兼容别名或提供 Store 迁移。Store 22 读取要求当前格式；
旧数据应保留兼容读取环境，或使用原版本预先导出。
