Marivo 0.6.0 一次性公开 Run-first 的 Session runtime 读取界面。

## 重点

- `session.runs()` 与 `session.get_run()` 公开闭合、不可变的生命周期：
  `IncompleteRun`、`SucceededRun` 或 `FailedRun`。
- `session.artifact(ref)` 恢复一项精确 Artifact；`session.graph()` 有界投影
  producer、consumer、reuse、head、失败与未完成状态。
- 每个 Artifact 提供 `finding_count`、`findings()` 和 `finding(id)`，并保留完整
  derivation 审计信息。
- `mv.session.inspect()` 只返回 Session summary 与有界 Run page。
- Runtime 与 Graph 读取不检查当前语义权威或数据源新鲜度；权威与 Evidence 完整性
  使用 `session.revalidate(ref)` 检查。

这是原子切换。旧 Frame/job 读取、Session Evidence namespace、digest page、
derivation trace、Finding selection compatibility 与对应 Help route 均无别名或迁移路径。
