Marivo 0.2.7 是 v0.2 系列的补丁版本发布，聚焦关系就绪检查
和打包分析指引。它修复了使用 `ms.join_on(...)` 编写的关系
在就绪检查 expansion 中的依赖展开，并让打包 `marivo-analysis` 技能专注于
Marivo 证据，而不是外部报告交付详情。

## 重点

- 关系就绪检查现在会通过 `JoinKey` 值对象契约展开依赖。对
  关系运行就绪检查时，会包含来源实体、目标实体以及两侧
  已编写连接-键维度。
- `marivo-analysis` 的打包 final-报告指引现在只描述默认 Markdown 报告
  边界，不再内置由 Marivo package 外部维护的 HTML 报告 style 或 publishing
  instructions。

## 修复

- 修复使用 `ms.join_on(...)` 编写关系时的就绪检查依赖 expansion。
  Marivo 不再把连接键当作原始 tuples 读取，从而避免就绪检查检查漏掉有效的
  连接维度。

## 文档

- 从打包 `marivo-analysis` final-报告引用中移除 HTML-报告交付和
  publishing 指引。智能体只有在用户明确请求对应交付接口时，才应使用这些
  交付-specific instructions。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.7 需要 Python 3.12 或更高版本。
