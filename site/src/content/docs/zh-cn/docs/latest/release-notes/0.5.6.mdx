Marivo 0.5.6 增加表达式 Entity，并进一步对齐公开检查结果与 Help 合约。

## 重点

- `ms.entity(...)` 现在支持直接声明和装饰器两种形式。装饰器函数必须基于注入的
  source 返回一个确定性的 Ibis `Table` 表达式；返回表的输出 schema 与 primary key
  共同决定后续语义执行。
- 表达式 Entity 通过统一的输出边界参与 observation、分组、Metric 过滤、关系、事件
  journey 和生命周期计算；其 body 与输出依赖会纳入语义 fingerprint。
- Entity 校验与 source health evidence 会区分物理连接或 schema 失败、表达式无效、输出
  字段缺失以及输出 primary key 缺失。
- Semantic 与 analysis Help 现在提供可执行示例、具体结果与分页字段、参数语义以及结构化
  修复指引，并保持既有 disclosure budget。

## 变更

- Entity body 现在按封闭且确定性的 Ibis 表达式校验。SQL 或执行逃逸入口、外部捕获值、时钟
  与随机值、赋值、推导式及其他不支持的形态会被拒绝，并给出结构化修复指引。
- Semantic definition display 会保留作者写入的字面量值与规范化表达式结构；定义载荷现在
  使用 `marivo.semantic_definition/v2` schema。
- Frame 检查会在不四舍五入数值的前提下渲染有界预览与 evidence summary，同时保留稳定的
  contract、finding 和 data 出口。
- 中英文 semantic-layer、analysis-workflow、Help 与随包 Agent 指引现已与可执行合约对齐。

## 兼容性

- 直接声明的 Entity 保持原有 source schema 行为。表达式形式是可选能力，并将返回 Table 的
  schema 视为 Entity 的权威输出。
- 持久化或检查 semantic definition JSON 的调用方应处理
  `marivo.semantic_definition/v2` schema 及其中保留的作者字面量值。

## 安装

~~~bash
curl -fsSL https://marivo.io/install-marivo-cn.sh | bash
~~~

也可以使用标准安装器：

~~~bash
curl -fsSL https://marivo.io/install.sh | bash
~~~

手动安装：

~~~bash
pip install marivo
~~~

Marivo 0.5.6 要求 Python 3.10 或更高版本。
