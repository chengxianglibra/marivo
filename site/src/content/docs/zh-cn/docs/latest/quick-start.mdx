本页的环境准备和教程现分别归入[安装与项目](/zh-cn/docs/latest/start/installation/)和 [Python 快速开始](/zh-cn/docs/latest/start/python/)。请按项目的当前状态选择下面的入口。

## 复用已有项目

打开包含 `models/` 的目录，安装项目依赖，并设置数据源声明引用的环境变量。详见[选择项目](/zh-cn/docs/latest/start/installation/#选择项目)。

## 建立新的业务项目

先按[安装与项目指南](/zh-cn/docs/latest/start/installation/)安装开发源码并准备环境，再在独立目录完成 [Python 快速开始](/zh-cn/docs/latest/start/python/)，随后将演示数据和定义替换为自己的业务内容。

## 不接入生产数据体验库

在独立演示目录运行 [Python 快速开始](/zh-cn/docs/latest/start/python/)。它会创建六笔本地订单并计算出 CNY 1,800 的收入。种子脚本会替换演示用的 `orders` 表。
