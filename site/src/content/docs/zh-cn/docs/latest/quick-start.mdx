---
title: 选择项目路径
description: 复用已有语义项目，或只编写缺失业务定义。
---

空目录是合法项目。已有已治理项目通常是得到有效分析的最短路径。`marivo init`是可选的。

## 复用已有项目

克隆项目、安装依赖并在本地配置 datasource 环境引用。请 Agent 检查配置和已有定义：

> 使用本项目现有 Marivo 语义层分析已完成订单收入。报告配置问题及必要的缺失或有争议定义。
> 复用已经符合问题的定义。

模型符合时继续[首次 Agent 分析](/zh-cn/docs/latest/first-analysis/)。
读取已有定义不需要 preview 或重新执行 authoring 认证，仅检查当前问题所需事实。

## 建立新的业务项目

完成[安装](/zh-cn/docs/latest/installation/)，向 `marivo-semantic`提供 datasource、决策和
已经确定的业务规则：

> 构建分析已完成订单收入所需的最小可复用语义组。以本需求和已确认项目定义为依据。
> 只有重要的可复用业务选择仍未解决时才询问，然后回到分析。

明确群体、取消与退款、报告时间、币种、聚合、允许拆分和归属。
元数据与样本帮助来源建模，不能建立业务含义。
跟随[语义建模](/zh-cn/docs/latest/guides/semantic-modeling/)和范围内[Readiness](/zh-cn/docs/latest/concepts/readiness/)。

## 不接入生产数据体验库

运行[六笔订单 Python 教程](/zh-cn/docs/latest/guides/python-quick-start/)。教程提供所有文件、数据和确切预期结果。将合成 demo 含义与生产定义保持区分。
