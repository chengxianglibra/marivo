Marivo 是用于业务数据分析的 Python 库，提供语义层和分析 DSL。语义层保存指标、实体、维度和关系等业务定义；分析 DSL 用这些定义计算、比较和拆分结果，并保留分析依据。

例如，订单表有金额、地区和日期。你可以定义收入，再按地区查看每月收入、比较两个时期，或计算滚动窗口和相关性。分析结果可以保存，之后从同一份数据继续计算。

## 可以做什么

| 任务 | 用法与结果 |
| --- | --- |
| 接入数据 | 声明数据库或文件来源，检查结构和样本 |
| 定义业务口径 | 定义收入、客单价等指标，复用单位、时间和关系规则 |
| 查询与分组 | 按地区、客户和时期计算指标，选择所需记录 |
| 比较与拆分 | 比较两个时期或目标值，按维度调查变化 |
| 时间与统计 | 按日历聚合、计算滚动窗口、占比和相关性 |
| 保存与检查 | 保存固定结果，读取数据和方法说明 |
