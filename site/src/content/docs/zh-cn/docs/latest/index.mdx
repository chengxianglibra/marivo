Marivo 是面向 AI Agent 的 Python 分析 harness。可复用语义定义绑定业务含义，
typed analysis 计算明确结果并记录 Evidence。问题选择与结果解释由你或 Agent 完成。

本 `latest`指南跟随当前开发实现。版本化文档描述各自历史发布，
安装已发布包不意味着所有开发 API 都可用。

| 继续已有结果 | [证据与恢复](/zh-cn/docs/latest/concepts/evidence/) |

## 沿一条可审阅流程前进

1. 确定业务决策、已确认 Metric 含义与范围。
2. 复用已治理对象；按需编写缺失的可复用语义组。
3. 构造明确 Logical 分析，需要结果时执行。
4. 在结果与 Evidence 的范围内读取 Materialized 输出。
5. 审阅结论、限制和仍缺少的证据。

从[核心概念](/zh-cn/docs/latest/concepts/)和[分析流程](/zh-cn/docs/latest/concepts/analysis-workflow/)开始。
高级专题覆盖时间与群体、比较、统计、Event、生命周期、留存与日历。
确切签名由 native Help 与[Python API 参考](/api/)提供。
