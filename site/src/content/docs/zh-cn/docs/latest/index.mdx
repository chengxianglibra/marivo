Marivo 是用于业务数据分析的 Python 库。语义层记录可复用的业务定义，包括指标、实体、维度和关系。分析 DSL 按这些定义计算和比较结果。保存结果后，可查看记录的数据来源和评估信息。

例如，订单表包含金额、地区和日期。定义收入后，可按地区计算每月收入、比较不同期间，或用滚动窗口观察趋势。保存已完成结果后，可重新读取当时保存的值。

## 可以做什么

| 想完成的任务 | 从这里开始 |
| --- | --- |
| 连接数据库或文件，并检查结构和限定范围的样本 | [数据源配置](/zh-cn/docs/latest/modeling/datasources/) |
| 定义可复用指标及其实体、时间字段和关系 | [语义层](/zh-cn/docs/latest/modeling/semantic-layer/) |
| 按期间或维度计算指标，并筛选或检查所选记录 | [分析 DSL](/zh-cn/docs/latest/analysis/dsl/) |
| 与基准结果比较，并按群体检查差异 | [比较基准](/zh-cn/docs/latest/analysis/dsl/#比较与对齐) · [调查变化](/zh-cn/docs/latest/analysis/dsl/#调查变化) |
| 按日历期间分组，计算窗口、份额或成对相关性 | [时间序列与窗口](/zh-cn/docs/latest/analysis/time-series/) · [统计与相关性](/zh-cn/docs/latest/analysis/statistics/) |
| 重新打开已保存的值，并查看来源与审计记录 | [结果与方法事实](/zh-cn/docs/latest/analysis/results/) |
