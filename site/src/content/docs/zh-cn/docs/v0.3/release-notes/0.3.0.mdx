Marivo 0.3.0 是一个小版本发布，重点收紧面向智能体的公共编写
和分析接口。它引入累计指标建模、更清晰的流程-首个
分析可用操作、通过帮助与结果契约暴露的公共语义指引，以及
用于数据源行为的共享 engine-profile 层。

## 重点

- 累计指标现在是一等语义对象。作者可以声明累计窗口，
  通过语义层物化，并在分析流程中 observe 累计 frames。
- 分析指引现在会引导智能体走流程-首个发现。帮助、结果展示
  和会话运行时输出会暴露更窄的后续步骤，而不是让智能体从宽泛 API 中推断
  流程状态。
- 语义编写现在通过公共帮助和结果可用操作覆盖常见编写流程，
  更容易发现有效构造器、必填字段、就绪检查问题和具体后续操作。
- 数据源行为现在通过 DuckDB、MySQL、PostgreSQL、Trino 和 ClickHouse 的共享
  引擎配置表达，减少重复后端逻辑，并更明确地呈现引擎特定能力。

## 变更

- 分析执行内部实现被拆分为专门的分桶、窗口处理、字符串-时间和
  指标-投影组件。
- 数据源元数据、运行时和编写代码现在通过 engine-profile 值处理 SQL
  行为、连接选项和后端特定约束。
- Bundled `marivo-analysis` 与 `marivo-semantic` 技能现在描述累计指标流程
  和更新后的公共指引接口。

## 修复

- 指标-pruning 步骤后会保留派生维度。
- DuckDB 数据源连接现在会转发已编写 extra keyword arguments。
- 语义层数据源解析、就绪检查、时间解析和目录详情
  在多个边界情况上更严格。
- 分析帮助、观测规划、变换输出和时区-感知执行路径
  收到兼容性修复。

## 文档

- 新增累计指标 v2、引擎配置、公共语义编写指引和分析
  智能体接口的设计规范。
- 更新最新英文和中文站点中的安装、快速开始、语义层概念和
  分析流程概念。
- 新增 `v0.3` 版本化文档快照。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.3.0 需要 Python 3.12 或更高版本。
