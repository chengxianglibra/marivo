Marivo 0.3.3 在数据源、语义与分析工作流之间统一了显式的语义身份和指标组合
模型，同时加入一等 SQLite 支持，并修复若干 frame 形状与证据报告问题。

## 重点

- 语义对象现在跨数据源、语义、分析、持久化与帮助接面共用一套类型化
  `Ref[kind]` 模型。使用 `ms.ref.metric("sales.revenue")` 等精确工厂构造引用；目录条目
  与声明通过 `.ref` 显式暴露其引用。
- 指标组合现在表示为规范类型化图。目录指标与闭合的
  `mv.runtime_metric.*` 表达式共用规划、执行、持久化、回放、证据血缘、单位传播和
  就绪检查规则。
- `ms.weighted_mean(...)` 成为一等已编写指标，用于同一实体上的值与权重
  度量；运行时表达式接面提供对应的 `mv.runtime_metric.weighted_mean(...)` 操作。
- SQLite 通过 `md.sqlite(...)` 成为一等数据源，支持类型化表声明、元数据
  检查、主键与索引发现、查询-仅只读模式、原始 SQL 和语义物化。
- 语义就绪检查接受闭合的运行时指标表达式；当其完整依赖闭包就绪时，会通过
  `analysis_ready_inputs` 返回。

## 破坏性变更

- 引用构造与表达式绑定被拆分为两个操作。`ms.ref.<kind>(path)` 只构造精确的类型化身份；在
  bound 语义表达式函数体内，维度、时间维度和度量引用必须使用
  `ms.bind(ref, entity_alias)`。
- 生命周期与分析输入改为仅引用。在支持的位置传入精确 `.ref` 或闭合的运行时
  指标表达式；loaded 目录对象、通用引用与裸字符串不再隐式转换，而是直接拒绝。
- 持久化语义身份使用封闭的 `marivo.semantic_ref/v1` 负载；旧引用形状写入的状态不会自动迁移。

## 变更

- Composed 指标可以共同 observe，包括带筛选条件的分支，同时保留确定性的图身份以及
  查询/证据血缘。
- Mean 指标会持久化精确的 sum 与 non-null count 组件；加权 mean 会为下游分析
  保留 numerator 与权重组件。
- MetricFrame 的公共值列在单指标和多指标 observe 中保持一致；单轴维度
  列也会跨分析操作保留。

## 修复

- 运行时指标就绪检查现在验证完整表达式森林，并返回感知阻塞项的分析-就绪输入。
- 被省略的证据摘要会指向完整行，不再暗示有界摘要包含完整分布。
- Composed 指标预览可跨 filtered branches 工作，不再丢失所需依赖。

## 文档

- 更新中英文语义层、就绪检查和分析流程指南，覆盖类型化引用、运行时
  表达式、加权 means 与 SQLite。
- 新增类型化指标组合、语义引用身份和表达式绑定的实现与设计
  规范。

## 安装

```bash
pip install marivo
pip install "marivo[sqlite]"
```

其他数据源请安装对应后端扩展。Marivo 0.3.3 要求 Python 3.12 或更高版本。
