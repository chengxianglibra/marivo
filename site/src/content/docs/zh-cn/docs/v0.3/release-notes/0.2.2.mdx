Marivo 0.2.2 是 v0.2 系列的补丁版本发布。这个版本完成了 v0.2 系列中面向
智能体的数据源、语义与分析接口清理，增加更丰富的
数据源发现证据，收紧语义编写契约，并让分析
结果通过明确的产物和展示契约交付。

## 重点

- 增加公共数据源发现接口，覆盖表、列、维度、
  度量、时间与关系证据，并提供 `md.raw_sql(...)` 用于诊断。
- 围绕显式引用和更清晰的帮助输出收紧语义编写，让智能体
  只沿着一条发现-to-编写路径工作，不再混用 prepare 时代 API。
- 围绕产物契约、`show(...)` 与 compact frame summaries 统一
  分析结果展示。
- 将 `derive_metric_frame(...)` 重新定位为元数据-attachment 辅助函数，并保留
  unbound 列供后续分析使用。
- 用更小的真实项目示例和流程-仅指引更新打包的 Marivo
  语义与分析技能。

## 变更

- 数据源连接现在可以作为上下文 managers 使用。
- 数据源元数据与 scanning 会收集更丰富的 profile、连接-键、分区
  和警告证据。
- 语义目录浏览、帮助 text、就绪检查报告与 richness 检查
  现在暴露更窄的面向智能体契约。
- 分析 frames 现在携带内容 hashes 和显式展示 protocols，便于稳定
  产物交接。
- 本地质量工具链现在通过仓库入口与统一的 pre-commit 配置执行。

## 修复

- `md.raw_sql(...)` 不再要求 Trino 为 SELECT 诊断开启只读
  transaction。
- 数据源原始 SQL 诊断现在会可靠地执行只读检查并释放
  检查 handles。
- 发现结果在请求时可以返回完整证据负载。
- Trino comment 元数据警告与硬元数据错误现在会清晰分离。
- 目录 browse hints、unreadable 度量-列 classification、分位数
  聚合帮助与分位数 folding 更清晰。
- Empty observe 维度 selections 现在可以被接受。
- 产物契约输出使用修正后的结构字段名称。
- 类型化语义引用现在会在验证和 hour-prefix 辅助函数中一致要求。

## 文档

- 刷新 `latest` 与 `v0.2` 的快速开始、语义层、分析流程、
  就绪检查与证据页面，以匹配新的发现和分析契约。
- 增加数据源发现、语义技能 layering、frame 结果
  simplification 与分析指引 layering 的设计说明。
- 围绕小型可运行真实项目 fixtures 重写打包技能示例。

## 破坏性变更

- 语义 prepare 编写 stage 与旧版 prepare-oriented 公共 API 已从
  面向智能体接口移除。
- 语义编写与验证现在要求类型化引用，不再接受裸字符串
  locators。
- Concrete 数据源发现结果 types 现在隐藏在公共发现辅助函数
  之后。
- 分析 frame/结果 exits 简化为围绕 `show(...)`、产物契约与当前
  core 操作工作；旧的结果-摘要路径已移除或重命名。

## 安装

```bash
pip install marivo
```

按数据源选择对应后端扩展：

```bash
pip install "marivo[duckdb]"
pip install "marivo[mysql]"
pip install "marivo[trino]"
pip install "marivo[postgres]"
pip install "marivo[clickhouse]"
pip install "marivo[all]"
```

Marivo 0.2.2 需要 Python 3.12 或更高版本。
