Marivo 将人类定义的数据语义，与智能体执行的分析流程分开。

- [语义层](/zh-cn/docs/v0.3/concepts/semantic-layer/) 解释数据源、领域、实体、维度、指标和语义引用。
- [分析流程](/zh-cn/docs/v0.3/concepts/analysis-workflow/) 解释会话、操作和类型化 frames。
- [就绪检查](/zh-cn/docs/v0.3/concepts/readiness/) 解释为什么未完成的语义对象会在分析前被阻止。
- [证据链](/zh-cn/docs/v0.3/concepts/evidence/) 解释操作输出如何通过证据项、命题和评估被追踪。
