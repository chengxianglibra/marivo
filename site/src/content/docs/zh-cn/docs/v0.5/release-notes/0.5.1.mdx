Marivo 0.5.1 一次性公开 Run-first 的 Session runtime 读取界面，并强化其背后的持久化与恢复路径。

## 重点

- `session.runs()` 与 `session.get_run()` 公开闭合、不可变的生命周期：
  `IncompleteRun`、`SucceededRun` 或 `FailedRun`。
- `session.artifact(ref)` 恢复一项精确的已提交 Artifact；`session.graph()` 有界投影
  producer、consumer、reuse、head、失败与未完成状态。
- 每个 Artifact 提供 `finding_count`、`findings()` 和 `finding(id)`，Finding 审计归属于
  Artifact，并保留完整 derivation 信息。
- `mv.session.inspect()` 现在只返回 Session summary 与有界 Run page。Runtime 与 Graph
  读取不检查当前语义权威或数据源新鲜度；权威与 Evidence 完整性使用
  `session.revalidate(ref)` 检查。

## 变更

- Canonical Session runtime truth 会先持久化，再投影为 Run、Artifact、Finding 和 Graph 读取。
  Nullable metric presence markers 保留“值不存在”和“值存在但为 null”之间的区别。
- Runtime 读取完成一次原子切换。旧 Frame/job 读取、Session Evidence namespace、digest page、
  derivation trace、Finding selection compatibility 及对应 Help route 均无别名或迁移路径。
- 打包的 `marivo-analysis` skill 与 analysis Help 路由现在遵循同一精简的 Run-first ownership model。

## 修复

- 中断和未完成的 Run 会从持久化状态恢复，不会伪造终态成功，也不会丢失有界的失败上下文。
- Session 读取辅助函数在恢复、replay 和 graph projection 过程中保留正确的 runtime 与 Session 身份。

## 文档

- 更新中英文 Session runtime、evidence、analysis workflow、API 及打包 skill 指引，对齐新的读取契约。
- 增加 canonical runtime truth 与有界 Session graph 读取的设计文档。

## 安装

国内网络建议运行：

~~~bash
curl -fsSL https://marivo.io/install-marivo-cn.sh | bash
~~~

也可以使用标准安装器：

~~~bash
curl -fsSL https://marivo.io/install.sh | bash
~~~

手动安装：

~~~bash
pip install marivo
~~~

Marivo 0.5.1 要求 Python 3.10 或更高版本。
