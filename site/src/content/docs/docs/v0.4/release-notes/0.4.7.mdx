Marivo 0.4.7 is a focused hotfix for ClickHouse `DateTime64` metadata handling.

## Fixed

- Datasource inspection now recognizes ClickHouse `DateTime64` columns,
  including precision, timezone, and nullable forms, as temporal columns. These
  columns can again be used with bounded `md.time_range(...)` acquisition.
- Projected table validation now canonicalizes ClickHouse-native temporal type
  spellings before comparing them with declared `md.source_column(...)` types,
  avoiding false type-mismatch errors for compatible timestamp declarations.

## Installation

```bash
curl -fsSL https://marivo.io/install.sh | bash
```

In mainland China, use:

```bash
curl -fsSL https://marivo.io/install-marivo-cn.sh | bash
```

For manual installation:

```bash
pip install marivo
```

Install the backend extra for each datasource you plan to use. Marivo 0.4.7
requires Python 3.10 or newer.
