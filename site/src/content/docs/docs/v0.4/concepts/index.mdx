The primary user journey lives under **Get started** and **Work with an agent**:
begin at [Get started](/docs/v0.4/), then continue with
[First agent-guided analysis](/docs/latest/first-analysis/) and the
[business-question guide](/docs/latest/guides/business-question/). Use this section
as an integration and reference map when you need to inspect the contracts behind
that journey.

- [Semantic Layer](/docs/v0.4/concepts/semantic-layer/) — semantic object and
  authoring contracts.
- [Analysis Workflow](/docs/v0.4/concepts/analysis-workflow/) — analysis
  operators, typed frames, artifacts, and recovery behavior.
- [Readiness](/docs/v0.4/concepts/readiness/) — report fields and explicit
  certification for semantic changes.
- [Evidence](/docs/v0.4/concepts/evidence/) — typed findings, bounded artifact
  digests, inference boundaries, and audit traces.
- [Python API Reference](/api/) — exact public modules, classes, functions, and
  signatures for implementation work.
