title: Your first Agent analysis
description: Give an agent the decision and scope, then review its evidence-backed answer.
---

Use a project whose relevant semantic definitions are approved and loadable. You do not need to prescribe Python operators or a fixed sequence of checks.

## Give the agent a bounded question

> Use `marivo-analysis` to explain the change in approved `sales.revenue`
> between July and August 2026. Compare the same completed-order scope, inspect
> region first, and report the conclusion, key evidence and limitations.

Specify the decision, meaningful baseline, included/excluded population and
initial focus. If the definition is missing, ask for the smallest semantic gap
to be resolved rather than a silently substituted Metric.

## Understand the agent’s work

The agent verifies its selected environment, reads existing catalog objects,
constructs explicit analysis in one Session and executes when the next decision
needs results. It reads `.show()` for committed rows, follows `.contract()` for
legal continuations and uses focused Help for unfamiliar calls.

For a missing reusable definition, it hands off to `marivo-semantic`, certifies
the changed roots and returns to the original question. Terminal raw SQL may
answer a disclosed temporary question; those rows cannot enter typed analysis.
Readiness, connectivity and successful execution prove different things.

## Review the answer

Confirm the Metric meaning, population, periods, comparison direction and
breakdowns. Check that material claims have results or Evidence, and that
coverage, missingness, censoring and method limits are visible. Algebraic
allocation and association do not by themselves prove cause.

Continue only for a remaining material question. Reuse an exact saved result
when the question is historical; execute current sources when freshness matters.
