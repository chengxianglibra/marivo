Marivo 0.6.0 centers analysis on AnalysisFrame, Session and Artifact identities.

## Highlights

- `compute()` returns complete fixed memory data; `persist()` returns a committed Frame.
- Retain the Session ID and `saved.artifact_id`. Resume the Session and use
  `session.persisted_frame(artifact_id)` for exact data; the saved Frame exposes its audit directly.
- `mv.session.inspect(session_id)` returns a SessionSummary without recovery.
- Run types, history, targeted reconciliation and error Run identities are removed
  from the public API. Atomic publication and guarded recovery remain internal.
- If an Artifact ID is lost, recover the Session and call `session.persisted_frames()`
  to inspect descriptions and captured schemas before selecting an exact ID.
  `persist(description=None)` optionally records the caller's purpose in the commit.
- Structured errors provide the failed phase and concrete repair. Unknown publication
  outcomes require Session recovery before committed Frame discovery.

This is a breaking cutover without compatibility aliases or Store migration.
Store 22 reads require the current format; preserve older data with a compatible
reading environment or an export made with its original version.
