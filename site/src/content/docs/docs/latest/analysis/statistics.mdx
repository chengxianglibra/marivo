## Summarize and normalize rows

Single statistics and nonempty tuples can omit names for direct single-segment
value sum/mean and row_count. Their fixed names are `<name>_sum`, `<name>_mean`
and `row_count`. Use an explicit Mapping for business names, expression or pair
statistics and multi-segment value paths. Duplicate candidates reject at capture;
names and order remain stable through evaluation and persistence.

x = current["revenue"]

    {
        "revenue": x,
        "total": current.over(x.sum()),

    }

## Use a common sample for correlation

For native Pearson or Spearman use `frame.correlate(x, y, method="pearson")` or `method="spearman"`, with numeric Columns from the same exact Frame. The result includes `coefficient` and `n_pairs`. Unknown pairs are excluded together. Constant endpoints or fewer than two pairs give an unknown coefficient, with the actual count retained. Spearman uses average ranks for ties.

The pandas example uses a common present/non-null mask for both endpoints. Never pair unrelated exports by their row index. A grouped coefficient cannot be averaged to obtain pooled correlation.

Normalization returns shares 0.25 and 0.75, total 800 and count 2 on both rows. Filtering before calculating changes the denominator; filtering afterwards preserves it. Empty sums are zero, all-unknown nonempty sums are unknown; presence and unknown numeric values remain distinct.

External statistics do not automatically acquire typed Evidence. State the sample, missing-value policy, method and assumptions. [Export results](/docs/latest/analysis/results/) when an external method is needed.

## Check a complete paired sample

Save as `paired_sample.py` and run it. All five pairs satisfy y = 2x, so Pearson correlation is 1. Duplicate values still count as separate samples.

```python
from analysis import session, region

sample = session.values(
    by=(region,),
    columns={"x": "1", "y": "1"},
    rows=(
        (("a",), {"x": 1, "y": 2}),
        (("b",), {"x": 2, "y": 4}),
        (("c",), {"x": 2, "y": 4}),
        (("d",), {"x": 3, "y": 6}),
        (("e",), {"x": 4, "y": 8}),
    ),
).compute()
correlation = sample.correlate(sample["x"], sample["y"], method="pearson").compute()
paired = correlation.to_pandas()
assert paired[("value", "n_pairs")].tolist() == [5]
assert abs(paired[("value", "coefficient")].iloc[0] - 1.0) < 1e-12
```
