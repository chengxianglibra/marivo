Complete the [analysis DSL example](/docs/latest/analysis/dsl/#complete-example-and-shared-inputs). Save the identifiers while you still have the returned result; use those exact identifiers to reopen it.

## Keep exact identifiers

Append this to `analysis.py` **before** running the producing script. It records
the returned result's identities before the process exits; no `show()` is required.
Do not import or rerun `analysis.py` in a later process just to discover IDs:
that would execute its source observations again.

```python
from pathlib import Path
import json

Path("saved-result.json").write_text(
    json.dumps(
        {
            "session": saved.session_id,
            "result": saved.artifact_id,
        }
    )
)
```

You can output the same small JSON object instead of writing a file. Retain it
outside the producer's variables. Include the data needed for the current
decision in that first script too, so saving does not add a separate inspection round.
An already retained exact reference needs no new publication.

## Reopen in another process

Save as `reopen.py` and run `.venv/bin/python reopen.py` from the same project. This script loads neither `analysis.py` nor the semantic model and does not query the source.

```python
import json
from pathlib import Path
import marivo.analysis as mv

ids = json.loads(Path("saved-result.json").read_text())
session = mv.session.resume(ids["session"])
reopened = session.persisted_frame(ids["result"])
rows = reopened.to_pandas()
assert rows["reference.absolute.revenue"].tolist() == [-100, -100]
reopened.show(n=0)
rows.to_csv("comparison.csv", index=False)
```

The two changes remain -100. Supported Frame operations can continue on these saved rows. A new original-source question requires explicit source inputs; saved data does not reconstruct its original metric definitions.

The export is an isolated pandas copy with readable coordinates and ordinary string columns. CSV is a convenience for sharing values, not a lossless Marivo reimport format: typed attributes and frozen time interpretation need the original Frame. Inspect units and keys before joining exports.

A new computation from the original source expression can observe changed data; [troubleshooting](/docs/latest/reference/troubleshooting/) covers missing files and incompatible old state.

## Evidence and conclusions

A result contains values; a conclusion interprets those values in a business context. Marivo records facts that help you inspect that interpretation.

### Know what you are reading

An AnalysisFrame can describe a pending calculation, completed memory data, or exact saved data. `compute` obtains completed values and `persist` saves a completed result. A bounded display is not a complete export.

The saved Frame exposes `session_id` and `artifact_id` directly. `show()` combines metadata, audit summaries and a bounded data preview; `show(n=0)` omits data reads. Read committed Findings through `findings()` and full evidence through `evidence_digest()`. Plain observation does not necessarily produce Findings. Supported contribution methods retain complete explanations through `method_facts`.

By default `show()` requests up to 20 rows within 8 KiB and reports how many rows were displayed and omitted. Use `show(n=26, max_output_bytes=None)` to display a complete 26-row prefix without a byte limit. The row limit still applies; use `to_pandas()` for the complete fixed data.

If both limits remove rows, the display reports both reasons. Empty results and `n=0` retain their row counts even when other metadata is omitted. If the required summary cannot fit, retry with the minimum byte budget reported in the error.

### Keep time and meaning explicit

Source read time, evaluation time and save time differ. Saving yesterday's data today does not make the values current. A later source query can return a different answer; exact saved data remains the record of what was committed.

A contribution of -100 says how an approved formula allocates a change. It does not prove a campaign caused the decline. Evidence also does not establish source completeness, a cross-source snapshot, or approval of business policy.
