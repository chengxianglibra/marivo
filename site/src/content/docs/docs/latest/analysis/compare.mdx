Use `AnalysisFrame.compare` to compare the current result with one or more baselines from the same Session. The result keeps current values and adds baseline values, absolute and relative changes for each baseline, and row-presence indicators. Missing rows and NA values are not treated as zero; a zero baseline produces an NA relative change.

See [Compare baselines in the Analysis DSL](/docs/latest/analysis/dsl/#compare-and-align) for an executable example and guidance on matching axes and time periods.
