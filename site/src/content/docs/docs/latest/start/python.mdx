Complete [installation](/docs/latest/start/installation/) in a separate directory. Create six completed orders in CNY, without refunds or currency conversion.

## Create the data

Save as `seed.py` and run `.venv/bin/python seed.py`. This replaces the demo orders table.
{/* example: demo-seed */}

```python title="seed.py"
from datetime import date
from pathlib import Path
import duckdb

Path("models/datasources").mkdir(parents=True, exist_ok=True)
Path("models/semantic/sales").mkdir(parents=True, exist_ok=True)
with duckdb.connect("warehouse.duckdb") as connection:
    connection.execute("""
        CREATE OR REPLACE TABLE orders (
            order_id BIGINT PRIMARY KEY,
            order_date DATE,
            region VARCHAR,
            amount BIGINT
        )
    """)
    connection.executemany(
        "INSERT INTO orders VALUES (?, ?, ?, ?)",
        [
            (1, date(2026, 7, 5), "east", 100),
            (2, date(2026, 7, 15), "east", 200),
            (3, date(2026, 7, 20), "west", 700),
            (4, date(2026, 8, 5), "east", 100),
            (5, date(2026, 8, 15), "east", 100),
            (6, date(2026, 8, 20), "west", 600),
        ],
    )
```

## Define revenue

Save as `models/semantic/sales/_domain.py`. Date and region support the later examples. See the [semantic layer](/docs/latest/modeling/semantic-layer/) for declaration rules.

{/* example: demo-model */}

```python title="models/semantic/sales/_domain.py"
import marivo.datasource as md
import marivo.semantic as ms

ms.domain(name="sales", owner="Mina Zhang")
orders = ms.entity(
    name="orders",
    datasource=ms.ref.datasource("warehouse"),
    source=md.table("orders"),
    primary_key=["order_id"],
)
order_date = ms.time_dimension_column(
    name="order_date", entity=orders, column="order_date"
)
region = ms.dimension_column(name="region", entity=orders, column="region")
amount = ms.measure_column(
    name="amount",
    entity=orders,
    column="amount",
    additivity=ms.additive_all(),
    unit="CNY",
)



@ms.metric()
def revenue():
    return amount.sum(time=order_date)
```

## Calculate revenue

Save as `quick.py` and run `.venv/bin/python quick.py`.

{/* example: quick-analysis */}

```python title="quick.py"
from uuid import uuid4

import marivo.analysis as mv

session = mv.session.get_or_create(
    f"first-analysis-{uuid4().hex[:8]}", timezone="UTC", domains=None
)
catalog = session.catalog
revenue_entry = catalog.get("metric:sales.revenue")
assert revenue_entry.kind == "metric"
revenue = revenue_entry.value
pending = session.observe({"revenue": revenue})
fixed = pending.compute()
fixed.show()
```

The result is 1,800, the sum of all six amounts. Each run creates a fresh project-local Session. Use `mv.session.resume(session_id)` only when intentionally continuing an exact saved Session.

`compute()` returns complete memory data. Continue calculations from `fixed` to retain that observation. When a saved Artifact is needed, call `saved = fixed.persist()` and `saved.artifact.show()`; this saves those values without reevaluating the source. In an existing project, the runnable entry's `--list-metrics` mode discovers unknown Metric paths. Choose an exact displayed path and resume the printed Session ID for observation. Use `--list-fields` in that Session only when a requested grouping path is unknown; `--full-output` explicitly expands a bounded list.

`domains=None` loads all authoring domain directories and freezes that scope in the Session. Explicit names select only those directories, without dependency expansion; include every required domain before creation. To widen a frozen scope, create a new Session with `domains=None` or the complete required sequence. Catalog loading reads metadata, so this default needs no extra source-data audit.

The [neutral runnable entry](https://github.com/chengxianglibra/marivo/tree/main/examples/analysis) documents discovery, exact Metric selection, optional grouping and intervals, persistence, and continuation by Session ID, with a separate synthetic fixture. Use the [axis examples](https://github.com/chengxianglibra/marivo/blob/main/examples/analysis/AXES.md) when the task needs shared source conditions, complete-axis comparison or paired association. They retain the null, absence, zero and repeated-time distinctions. After `import marivo`, use focused exact Help such as `marivo.help("analysis.session.observe")` or the public bound callable `marivo.help(session.observe)`; follow printed targets when discovering other syntax.

The [analysis DSL](/docs/latest/analysis/dsl/) supplies a complete `analysis.py` for monthly and regional comparisons.
