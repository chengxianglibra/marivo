---
title: Datasource configuration
description: Configure DuckDB, PostgreSQL, MySQL, ClickHouse and Trino, one parameter at a time.
---

Marivo supports five datasource constructors. Save each declaration under `models/datasources/`; the loader collects it without opening a connection. Pick the constructor for the actual backend, then refer to its name from an Entity. Remote examples are configuration templates: replace their hosts/database names and set the named environment variables before testing access.

Each row documents one constructor parameter. “Default” is the Marivo Python default. For optional connection fields, `None` omits the override and leaves backend/driver behavior in effect; it does not promise a fixed port or an anonymous login. Credentials may still be required by your server even when a parameter is optional. `name`, `ai_context`, and `extra` are repeated for each constructor so each table is complete.

| Backend | Constructor | Typical use |
| --- | --- | --- |
| DuckDB | `md.duckdb` | Local database; file sources |
| PostgreSQL | `md.postgres` | PostgreSQL |
| MySQL | `md.mysql` | MySQL |
| ClickHouse | `md.clickhouse` | ClickHouse |
| Trino | `md.trino` | Distributed catalogs |

## DuckDB — `md.duckdb`

| Parameter | Required | Default | Meaning |
| --- | --- | --- | --- |
| `name` | Yes | — | Project-wide lowercase snake_case name; referenced by `ms.ref.datasource(name)`. |
| `path` | No | `':memory:'` | DuckDB file path, or `":memory:"` for a process-local database. Use a file for the tutorial. |
| `read_only` | No | `False` | Open the database in read-only mode when true. |
| `http_scope` | No | `None` | HTTP(S) URL prefix bounding remote JSON authentication; required when an HTTP auth mode is supplied. |
| `http_bearer_token_env` | No | `None` | Environment variable name for a bearer token; mutually exclusive with header authentication. |
| `http_headers_env` | No | `None` | Mapping from HTTP header names to environment variable names containing their secret values; mutually exclusive with bearer authentication. |
| `ai_context` | No | `None` | Optional `ms.ai_context(...)` with business meaning and guardrails; no context is attached when omitted. |
| `extra` | No | `None` | Additional JSON-compatible Ibis connection arguments not modeled above; use the typed arguments for modeled settings and never include plaintext credentials. `None` adds none. |


```python
# models/datasources/warehouse.py
import marivo.datasource as md

md.duckdb(name="warehouse", path="warehouse.duckdb", read_only=False)
```

Exact reference: `marivo.help("datasource.duckdb")`.

## PostgreSQL — `md.postgres`

| Parameter | Required | Default | Meaning |
| --- | --- | --- | --- |
| `name` | Yes | — | Project-wide lowercase snake_case name; referenced by `ms.ref.datasource(name)`. |
| `host` | Yes | — | Database server host name or IP address. |
| `database` | Yes | — | Database to connect to. |
| `port` | No | `None` | Connection port; `None` leaves it to the backend driver. Set explicitly for a non-default endpoint. |
| `schema` | No | `None` | Default schema for table resolution; `None` supplies no Marivo schema override. |
| `autocommit` | No | `None` | Override driver autocommit behavior; `None` leaves the driver default. |
| `user_env` | No | `None` | Name of the environment variable holding the user, not the user value. `None` declares no user reference. |
| `password_env` | No | `None` | Name of the environment variable holding the password. `None` declares no password reference. |
| `ai_context` | No | `None` | Optional `ms.ai_context(...)` with business meaning and guardrails; no context is attached when omitted. |
| `extra` | No | `None` | Additional JSON-compatible Ibis connection arguments not modeled above; use the typed arguments for modeled settings and never include plaintext credentials. `None` adds none. |


```python
# models/datasources/reporting.py
import marivo.datasource as md

md.postgres(
    name="reporting", host="postgres.example.internal", database="sales",
    port=5432, schema="public",
    user_env="PG_USER", password_env="PG_PASSWORD",
)
```

Exact reference: `marivo.help("datasource.postgres")`.

## Trino — `md.trino`

| Parameter | Required | Default | Meaning |
| --- | --- | --- | --- |
| `name` | Yes | — | Project-wide lowercase snake_case name; referenced by `ms.ref.datasource(name)`. |
| `host` | Yes | — | Database server host name or IP address. |
| `catalog` | Yes | — | Trino catalog, mapped to the Ibis database connection argument. |
| `user_env` | Yes | — | Required environment variable name for the Trino user; no implicit backend user fallback. |
| `port` | No | `None` | Connection port; `None` leaves it to the backend driver. Set explicitly for a non-default endpoint. |
| `schema` | No | `None` | Default schema for table resolution; `None` supplies no Marivo schema override. |
| `source` | No | `None` | Client application/source tag sent to Trino; `None` does not override it. |
| `timezone` | No | `None` | Engine session timezone; separate from the Analysis Session report timezone. `None` supplies no engine override. |
| `http_scheme` | No | `None` | HTTP transport scheme; set `"https"` for TLS. `None` uses driver behavior. |
| `client_tags` | No | `None` | Tuple of client tags, forwarded to the backend as a list; `None` adds none. |
| `session_properties` | No | `None` | Trino session property mapping; `None` adds none. |
| `auth_env` | No | `None` | Environment variable name for backend authentication material; `None` declares none, suitable only when the server permits it. |
| `ai_context` | No | `None` | Optional `ms.ai_context(...)` with business meaning and guardrails; no context is attached when omitted. |
| `extra` | No | `None` | Additional JSON-compatible Ibis connection arguments not modeled above; use the typed arguments for modeled settings and never include plaintext credentials. `None` adds none. |


```python
# models/datasources/lake.py
import marivo.datasource as md

md.trino(
    name="lake", host="trino.example.internal", catalog="hive", schema="sales",
    user_env="TRINO_USER", auth_env="TRINO_AUTH", http_scheme="https",
    client_tags=("marivo", "reporting"),
)
```

Exact reference: `marivo.help("datasource.trino")`.

## Credentials and connection checks

Author credentials only as `*_env` references. Set those variables before running the check. After a validated round-trip, default credential resolution may cache resolved values in plaintext in `~/.marivo/secrets.toml`; set `MARIVO_PERSIST_CREDENTIALS=0` to disable this. Do not put credentials in `extra` or model source.

After creating the [tutorial database](/docs/latest/start/python/), run this from its project root:

```python
import marivo.datasource as md
import marivo.semantic as ms

warehouse = ms.ref.datasource("warehouse")
md.load().test(warehouse).show()
md.inspect(warehouse, md.table("orders"), workspace_dir=".").show()
```

## Connections and physical sources

`md.table(...)` selects a table/view in a datasource. `md.parquet(...)`, `md.csv(...)`, and `md.json(...)` describe DuckDB file/HTTP sources; they are not additional datasource types. Inspection support does not automatically establish numerical analysis support, and parameterized JSON is not admitted as a numerical Session source. A returned-row limit does not limit scanned bytes. See [backend and method limits](/docs/latest/reference/backends-and-limits/), then [define Entities](/docs/latest/modeling/semantic-layer/).
