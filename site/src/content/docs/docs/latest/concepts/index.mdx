Use this map when a term changes the meaning of a calculation. Exact type and callable contracts remain in native Help.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Semantic Ref | Stable typed identity of a governed declaration |
| Entity / Subject | Business instance and its complete ordered identity |
| Member domain | Explicit selected instances; versions do not replace instance keys |
| Coordinate / grain | Retained output position and observational unit |
| Quantity | Equation, unit, contribution identity and state policy |
| Cell | Defined, Null, Undefined or Unknown; missing correspondence is separate |
| Logical / Materialized | Planned computation / committed retained result |
| Original rollup / row statistic | Merge original sufficient components / derive a new quantity from current rows |
| Run / Artifact | Execution record / exact committed output |
| Evidence / Finding | Recorded computation facts / typed extracted facts |
| Coverage / censoring | What observation can establish / limits of follow-up |
