## Vocabulary

| Term | Meaning |
| --- | --- |
| Semantic Ref | Stable typed identity of a governed declaration |
| Entity / Subject | Business instance and its complete ordered identity |
| Member domain | Explicit selected instances; versions do not replace instance keys |
| Coordinate / grain | Retained output position and observational unit |
| Quantity | Equation, unit, contribution identity and state policy |
| Population / AnalysisFrame / Column | Finite complete domain / immutable data across three carriers / value on one exact input |
| Nullable value / presence | Ordinary NA / independent fact that a correspondence endpoint exists |
| Artifact | Committed submission and audit view; Frame owns data |
| Explicit source observation / row statistic | Evaluate governed source inputs / reduce current represented rows |
| Run / Artifact | Publishing record / exact committed audit view |
| Evidence / Finding | Recorded computation facts / typed extracted facts |
| Coverage | What the source scope permits an observation to establish |
