## Compose a Metric-first Query

Resolve governed expressions from an authored model. Constructing a Query does
not read schemas or business rows and does not create a Run.

Population, Query, Column and terminal Artifact are the analysis objects. Earlier
Logical/Materialized receivers and `mv.runtime_metric` factories are retired;
compose resolved semantic expressions before observing them.

```python
import marivo
import marivo.analysis as mv
import marivo.semantic as ms

session = mv.session.get_or_create("metric-review", report_timezone="UTC")
revenue = session.catalog.metrics.get("sales.revenue")
aov = session.catalog.metrics.get("sales.aov")
region = session.catalog.fields.get("sales.customers.region")
scope = session.time_scope(start="2026-01-01", end="2026-02-01")
query = session.observe(
    {"revenue": revenue, "aov": aov},
    during=scope.by(mv.grain("day")),
    by=(region,),
    where=region == "APAC",
)
contract = query.contract()
contract.show()
contract.actions[0].show()
result = query.execute()
result.show(n=20)
```

`Query.contract()` and `Population.contract()` return an `AnalysisContract` with
`kind`, `domain`, `quantity` and `actions`. Its card shows captured logical facts
and valid next calls without reading schemas or business rows or creating a Run.
Each action exposes `call` and `help_target`; `action.show()` prints both.
Terminal Artifacts expose their own result cards and have no contract.

Each contribution root needs a valid scalar path to an ordinary grouping field.
Use `field.via((relationship,))` to capture an explicit scalar role and
`field.at(session.instant(...))` for a versioned attribute. Both bindings are
immutable. Common conditions bind separately to each contribution occurrence.
Omitting `during` adds no time filter to ordinary reductions; time sampling and
window dependencies still require their explicit period or endpoint.

## Choose observed or complete coordinates

An ordinary `by=(region,)` groups observed coordinates. A Population specifies a
complete finite output domain, including requested empty coordinates:

```python
regions = mv.coordinates(by=(region,), keys=(("APAC",), ("EMEA",)))
regions.contract().show()
query = session.observe({"revenue": revenue}, during=scope, by=regions)
keys_only = session.query(regions)
keys_only.execute().show()
```

A complete output domain must cover every observed contribution coordinate.
An empty total follows the reducer's declared policy, such as NA for default sum or zero for explicit `empty="zero"`. Source Null categories remain distinct from absent coordinates.

`session.members(ms.ref.entity("sales.customers"))` selects existing complete
Entity identities. `mv.identities(session.catalog.entities.get("sales.customers"), keys=(("C1",),))` captures explicit
identity references, which do not prove source presence. Composite primary keys
remain one identity axis with all components in declared order. `identities`
requires the resolved Entity; resolve a bare Ref through the catalog first.
`session.members` requires an Entity Ref and reports a typed repair when passed
a resolved Entity instead.

`query.coord(axis)` locates a scalar coordinate Column. Construction does not read
sources; preparation rejects a composite identity as one quantity before admitting
a Run or compiling/reading business data. Keep complete identity keys in the output
and use `query.population()` with `mv.in_population(...)` for tuple selection.
Use an existing single-field axis when a scalar coordinate value is needed.

Populations support `project(by=...)`, `union`, `intersection`, `difference`, and
`where(mv.in_population(other))`; predicates combine with `&`, `|`, and `~`.
`classify(by=(field,))` explicitly reads an identity Entity's attributes.
`image(via=(relationship,))` follows the declared direction to target identities;
`preimage(targets, via=(relationship,))` retains only matching receiver identities.
Required missing attribute or relationship mappings fail; complete foreign keys
can retain target references even when target profiles are absent.

`mv.product(regions, calendar)` forms a complete Cartesian coordinate domain in
factor order. Calendar coordinate binding and the observation period must remain compatible;
window endpoints still require the explicit observation time binding.

`query.population()` captures that Query's coordinate selection, period,
conditions, declaration closure and Session. It remains lazy. Another observation
cannot overwrite the captured selection context. Use `session.query(population)`
to publish keys; Population has no `execute()` method.

## Read attributes through the Session

`session.read(population, {"region": region})` returns a lazy Query with complete input identity keys and named attribute values. The explicit Session owns the read; no Population.read alias or ambient Session lookup exists. Bind versioned fields with field.at(anchor); scalar paths use field.via((relationship,)). Required missing/duplicate mappings fail at consumption. Computed Measures belong in observe.

## Allocate overlapping memberships explicitly

A membership descriptor binds the member bucket fields and the contribution
allocation paths. Multiple fields in one descriptor are correlated.
Resolve each Relationship through `session.catalog.relationships.get(...)`
before placing it in `via`; bare Relationship Refs are lookup keys:

```python
tag = session.catalog.fields.get("sales.tags.label")
order_links = session.catalog.relationships.get("sales.order_links")
link_tags = session.catalog.relationships.get("sales.link_tags")
tags = mv.membership(
    tag, via=((order_links, link_tags),), unmatched="exclude"
)
query = session.observe({"revenue": revenue}, during=scope, by=(tags,))
```

Repeated mappings of the same complete contribution identity to the same bucket
count once. Distinct contributions with equal values remain distinct. Separate
membership descriptors form independent allocation factors. Choose
`unmatched="null"` to retain unassigned contributions in a Null bucket.
Classifying a member identity domain with the same descriptor reads its member
fields directly and preserves the allocation definition for later observation.

## Reduce complete internal Metric samples

`per` first evaluates the entire Metric formula at each sample coordinate, then
reduces those values. This keeps a mean of per-customer ratios different from an
overall ratio:

```python
customer = session.catalog.fields.get("sales.orders.customer")
customers = mv.coordinates(by=(customer,), keys=((1,), (2,), (3,)))
query = session.observe({"mean_customer_revenue": revenue.per(customers).mean()})
```

A field or membership descriptor uses observed samples. An explicit Population
selects complete internal samples, including empty samples according to their
reducers' policies. Internal samples may select a subset; external output domains
must cover the observed output. Exact coordinate types and Session ownership are
preserved throughout composition.

## Attach endpoint windows to Metrics

Window rules live on the Metric; the observation supplies endpoints:

```python
from datetime import timedelta

rolling = revenue.window(mv.trailing_duration(duration=timedelta(days=7)))
query = session.observe(
    {"rolling_revenue": rolling},
    during=scope.by(mv.grain("day")),
    by=(region,),
)
```

`all_history()` has no lower bound, `trailing_duration` uses elapsed time,
`trailing_periods(count=...)` requires calendar periods, `since(start=...)` keeps
an exact fixed start, and `to_date(grain=...)` resets at a civil or semantic period
boundary. All windows are half-open before each endpoint. Actual clipped output
endpoints stay distinct from nominal calendar boundaries.

## Execute and read committed output

Execution prepares real source schemas and fixes the plan before admitting a
Run. Each invocation evaluates its inputs and atomically publishes an Artifact.
Pure finite key programs execute locally after their required type preparation;
source-driven domains and Metrics use qualified datasource reads.

Artifacts are terminal: use `show(n=20)`, `to_pandas()`, `findings()` and
`evidence_digest()`. Complete pandas export is an isolated copy. Reopen an exact
saved ID with `session.artifact(result.id)` without restoring computation or
reading current sources. Artifacts cannot become semantic expression inputs.

Preparation failures create no Run. For failures after admission, inspect the
reported `run_ref` with `session.get_run(run_ref).show()`. A retry is a new
invocation. Preview limits do not truncate execution or complete exports.

Use `marivo.help("analysis.Population")`,
`marivo.help("analysis.membership")`, `marivo.help("analysis.Query.population")`
and `marivo.help("analysis.windows")` for focused current contracts.
