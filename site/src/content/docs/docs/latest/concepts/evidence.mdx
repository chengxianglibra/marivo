---
title: Evidence and recovery
description: Read exact fixed data and audit without current sources.
---

Store 12 saves Frame data under `.marivo/analysis/generations/v12/`. One
SQLite publication transaction commits manifest, receipts, Findings, Evidence
and Run success after durable data. Compute creates no Run; persist evaluates
before admission, then publishes an existing result ID. Memory persist never
reevaluates; stored persist validates commit metadata and returns itself.

## Read data and audit

Given a resolved revenue Metric and Session:

```python
saved = session.observe({"revenue": revenue}).persist()
print(session.id, saved.artifact.id)
saved.show(n=20)
saved.artifact.show()
reopened = session.persisted_frame(saved.artifact.id)
complete = reopened.compute()
page = reopened.artifact.findings(limit=20)
digest = reopened.artifact.evidence_digest()
print(digest.items)
for run in session.runs(limit=5).items:
    run.show()
```

Ordinary observe produces no Findings. One audit retains actual inherited
source facts and the current evaluation, not accumulated intermediate history.
Only exactly equal facts deduplicate; different scope/read times stay distinct.
Source-read, evaluation and commit times differ. Committing old data does not
refresh it. A saved input identity is not an executable lineage dependency.

## Preview and complete data

Opening/repr, show(n=0), Artifact.show/findings/evidence_digest consume metadata
or audit, not data payload. Positive show decodes the ordered prefix and selected
frozen coordinate records; receipt hashing/decompression may read more bytes.
Preview success does not certify unread data. Full compute/to_pandas validates
required values/keys/presence and calendar/map attachments, without Catalog,
source schema, connection, model or timezone-rule reconstruction.

Export returns isolated RangeIndex data with raw-key `(kind, name)` MultiIndex
columns and isolated typed attrs: axes, units and frozen_coordinates tables.
Calendar labels/bounds and paired endpoints remain self-contained; show is the
simplest interpretation path. No new visible projection columns/endpoint API or
attrs importer exists. Supported data operations continue on the recovered Frame;
new source facts require explicit construction.

## Keep publication and data history distinct

SessionGraph has same-Session Run-to-Artifact publishing edges. Roots/heads do not
choose a latest answer or promise complete data lineage. Current evaluation
records direct stored inputs actually consumed; carrier copying adds no fake
read or lineage edge. Reconciliation resolves the original transaction rather
than evaluating again. A full memory result stays independent after old files
are removed; reading the old stored handle still fails if its data is gone.

## Older data and evidence limits

Store 12 refuses older-generation Session/result/Findings/Evidence access without
changing bytes or migrating/dual-reading. Absent-current discovery may return
None/empty without exposing old data; create/get_or_create cannot initialize a
bypass around an old-only project. Export with the original version before
switching, or retain a compatible reading environment. See
[troubleshooting](/docs/latest/reference/troubleshooting/).

Saved facts do not certify source completeness, current semantic authority,
cross-source snapshots, freshness or causal conclusions. RawSqlResult remains
an independent datasource reader and never enters Frame Store. Start discovery
with `marivo.help("analysis")`; type Help owns calls and show owns captured facts.
