A committed graph Artifact owns its retained rows, required parts and verified
continuation contract. Its producing Run records execution identity. The agent
owns cross-result synthesis, business judgment and causal interpretation.

```python
artifact = current.compare(baseline).execute()
artifact.show()
artifact.contract().show()
run = session.get_run(artifact.state.producing_run_ref)
run.show()
```

This example assumes two compatible numeric observations in one Session.
`show()` provides bounded inspection; `contract()` verifies the exact Artifact
and exposes its current continuations. Missing or corrupt required parts fail
explicitly. A Logical relation has no retained rows before execution.

Legacy Dataset Findings and ArtifactDigest are not the inspection protocol for
Store 7 relations. Their broader method families await R6–R9 migration.

## Cold recovery

```python
run = session.get_run(run_id)
if isinstance(run, mv.SucceededRun):
    artifact = session.artifact(run.output_artifact_ref)
    artifact.show()
```

Run history and graphs project committed facts. Exact recovery verifies the frozen
snapshot and primary/part receipts; it does not query current sources, load current
Semantic definitions or replay an origin recipe. Old Store generations are
rejected without migration. This does not prove datasource freshness or business
suitability. Repeating a live source definition creates a new evaluation; use
`session.artifact(ref)` to recover a specific successful result.

Difference is algebraic and Spearman association is descriptive. Preserve the
retained domain, units, Cell states and method limits in the final interpretation.
A terminal custom DataFrame or raw SQL result cannot re-enter governed analysis.

Start at `marivo.help("analysis")` and follow the exact Help targets supplied by
the result's contract for its admitted next actions.
