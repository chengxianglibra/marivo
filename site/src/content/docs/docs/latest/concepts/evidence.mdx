Evidence records deterministic facts about a committed Dataset. The agent owns
cross-result synthesis, business judgment and causal interpretation.

```python
artifact = current.compare(baseline).execute()
artifact.show()
print(artifact.evidence_digest.finding_count)
page = artifact.findings(limit=20)
if page.items:
    artifact.finding(page.items[0].finding_id).show()
```

This continuation assumes two compatible Metric Datasets in one Session. A Logical
Dataset has no retained Evidence reads before execution. ArtifactDigest versionv3
retains exact Artifact/extractor identity and quality, issue, Evidence and
Finding-set digests plus the Finding count. It is not a generated narrative.

FindingPage has immutable items, limit, has_more and an opaque next_cursor. Follow
the cursor through the same owning Artifact. Missing/corrupt state fails explicitly;
an empty page does not hide an unavailable Store.

## Cold recovery

```python
run = session.get_run(run_id)
if isinstance(run, mv.SucceededRun):
    artifact = session.artifact(run.output_artifact_ref)
    artifact.show()
```

Run history and graphs project committed facts. Recovery does not query current
sources or replay an origin recipe. `session.revalidate(artifact.state.artifact_ref)`
reports separate Artifact, storage-authority and Evidence integrity assessments.
It does not prove datasource freshness or business suitability.

Delta and Attribution are algebraic; Association is descriptive; Forecast is a
model result; Candidate rows are evaluated leads. Preserve their retained scope,
selection, quality and completeness limitations in the final interpretation.

Start at `marivo.help("analysis.evidence")` for current focused routes. A terminal
custom DataFrame or raw SQL result cannot re-enter governed Dataset analysis.
