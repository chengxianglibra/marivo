---
title: Evidence and recovery
description: Inspect committed facts and recover exact Store 8 results.
---

Artifacts own saved rows, retained parts and execution evidence. Runs record
execution identity and success or failure. The agent owns cross-result synthesis,
business judgment and causal interpretation.

## Read the producing Run

`current` and `baseline` are compatible logical numeric observations in the same Session.

{/* example: evidence-producing-run */}

```python
artifact = current.compare(baseline).execute()
artifact.show()
artifact.contract().show()
run = session.get_run(artifact.state.producing_run_ref)
run.show()
```

`contract()` describes retained state and admitted continuations; it does not certify unchanged file bytes. Logical values have no committed Evidence before execution.

## Read bounded Findings

`artifact` is a committed result from the preceding example.

{/* example: evidence-findings */}

```python
digest = artifact.evidence_digest()
print(digest.finding_count)
findings = artifact.findings(limit=20)
for finding in findings.items:
    finding.show()
run = session.get_run(artifact.state.producing_run_ref)
run.show()
```

Evidence/Findings publish with the result. A finding cursor belongs to its exact
owning Artifact; use `has_more` and `next_cursor` for pagination. Empty Findings
mean an empty committed set. Findings report deterministic computation facts,
not a generated narrative or causal explanation.

## Recover an exact successful result

`session`, `mv` and a recorded `run_id` are available. Check the Run variant before reading success-only fields.

{/* example: evidence-recovery */}

```python
run = session.get_run(run_id)
if isinstance(run, mv.SucceededRun):
    artifact = session.artifact(run.output_artifact_ref)
    artifact.show()
```

Store 8 keeps project-local Parquet and SQLite metadata under
`.marivo/analysis/generations/v8/`. Committed local results, Evidence and Findings
are trusted: reads decode required typed data without content-hash comparison,
producer replay or re-extracting Findings. Missing/unreadable parts, incompatible
formats and foreign Session/cursor ownership still fail explicitly.

Store 7 and earlier reject without migration or modification. Preserve old
bytes and use a fresh project root for the current generation. There is no
revalidation or automatic reconstruction path. A new live execution creates a
new result; recovery preserves the prior result’s exact scope and time authority.

## Interpret evidence within its scope

Observation describes its retained scope. Comparison/attribution are algebraic;
association is descriptive; a forecast is a model output. Screening and Journey/
History summaries retain fit, assignment, coverage and censoring limits. None
establishes business authority, freshness or causal conclusions by itself.

Follow `marivo.help("analysis.evidence")`, or run [the local recovery tutorial](/docs/latest/guides/python-quick-start/).

Saved Artifacts use compact Cell bindings internally; `show()` and `to_pandas()`
keep their existing value, tag and reason fields. Older Artifact formats cannot
be recovered or continued. Preserve the history and files, then re-execute the
producing source analysis to save a current Artifact. Store 8 needs no migration.
