---
title: Choose a project path
description: Reuse an existing semantic project or author only the missing business definitions.
---

An empty directory is a valid project. An existing governed project is usually the shortest path to a useful analysis. `marivo init` is optional.

## Reuse an existing project

Clone the project, install its dependencies and configure datasource environment
references locally. Ask the agent to inspect configuration and existing definitions:

> Use this project’s existing Marivo semantic layer for completed-order revenue
> analysis. Report configuration problems and any required missing or disputed
> definitions. Reuse definitions that already fit the question.

If the model fits, continue to [first Agent analysis](/docs/latest/first-analysis/).
Reading an existing definition does not require preview or a fresh authoring
certification. Check only what the current question needs.

## Start a new business project

Complete [installation](/docs/latest/installation/), then give the datasource,
decision and established business rules to `marivo-semantic`:

> Build the smallest reusable semantic slice for completed-order revenue.
> Use this request and approved project definitions as authority. Ask only when
> a material reusable business choice remains unresolved; then return to analysis.

Settle population, cancellations/refunds, reporting time, currency, aggregation,
permitted breakdowns and ownership. Metadata and samples help model the source;
they cannot establish business meaning. Follow [semantic modeling](/docs/latest/guides/semantic-modeling/)
and scoped [Readiness](/docs/latest/concepts/readiness/).

## Try the library without production data

Run [the six-order Python tutorial](/docs/latest/guides/python-quick-start/). It provides every file, the data and exact expected results. Keep the synthetic demo meaning separate from production definitions.
