The setup and tutorial from this page now live in [Installation and projects](/docs/latest/start/installation/) and the [Python quick start](/docs/latest/start/python/). Choose the path below that matches your project.

## Reuse an existing project

Open the directory containing `models/`, install the project's dependencies, and set the environment variables referenced by its datasource declarations. See [Select a project](/docs/latest/start/installation/#select-a-project).

## Start a new business project

Follow [Installation and projects](/docs/latest/start/installation/) to install the development checkout and prepare the environment. Run the [Python quick start](/docs/latest/start/python/) in a separate directory, then replace its demo data and definitions with your own.

## Try the library without production data

Run the [Python quick start](/docs/latest/start/python/) in a separate demo directory. It creates six local orders and calculates revenue of CNY 1,800. Its seed script replaces the demo `orders` table.
