A backend extra installs its driver; a connection proves access. Neither grants
all analysis methods. Admission depends on the actual backend, source form,
ordered physical types, domain, time authority, retained state and method.
The current relation contract and focused Help are the operational guide.

## Install only the selected driver

| Backend | Extra | Setup facts |
| --- | --- | --- |
| DuckDB | <code style="white-space: nowrap">duckdb</code> | Local tables and admitted file sources; tutorial requires no server |
| PostgreSQL | <code style="white-space: nowrap">postgres</code> | Read-only account and native libpq prerequisite |
| MySQL | <code style="white-space: nowrap">mysql</code> | Native client/build prerequisites and native query settings |
| Trino | <code style="white-space: nowrap">trino</code> | Explicit catalog/schema, read-only access and native query settings |
| ClickHouse | <code style="white-space: nowrap">clickhouse</code> | Qualified scalar types and effective `join_use_nulls=1` for admitted analysis |

Analysis stores metadata in project-local SQLite independently of datasource support.

The base package includes Arrow for local results. Discovery of an unselected
provider does not import its driver. Missing selected dependencies produce a
typed repair naming the required extra.

## Qualify a numerical source route

Numerical source routes qualify the selected backend, source form, actual schema and method. Templates compile with that backend before Run admission; instantiated dependencies are checked again before consumption. Datasource access alone does not establish numerical Runtime qualification.

{/* example: csv-semantic-model */}

```python
import marivo.datasource as md
import marivo.semantic as ms

facts = ms.entity(name="facts", datasource=ms.ref.datasource("warehouse"),
                  source=md.csv("data/facts.csv"),
                  primary_key=["tenant", "id", "revision"])
amount = ms.measure_column(name="amount", entity=facts, column="amount",
                           additivity=ms.additive_all())
happened = ms.time_dimension_column(name="happened", entity=facts,
                                    column="happened", granularity="second",
                                    parse=ms.timestamp(timezone="UTC"), is_default=True)
finalized = ms.finalize()
facts = finalized.resolve(facts)
amount = finalized.resolve(amount)
happened = finalized.resolve(happened)

@ms.metric()
def total():
    return amount.sum(time=happened)
```

This declares fields and a named Metric. A declaration or successful preview does not qualify every CSV/JSON/HTTP analysis shape; unsupported routes reject before their business reads. Runtime source templates are prevalidated before Run admission and actual instantiated inputs are checked again.

## Source and local execution

Source Ibis executes through the selected declared datasource and returns pandas. Literal/reference and local domain/value stages use pandas. PyArrow encodes and reads terminal output. Fixed complete Frame inputs and local data operations use the same scheduler. Artifact is audit only; no Artifact operand, fixed-data remote upload or hidden local SQL engine exists.

Source computation accepts native Ibis/provider numerical precision loss. Ibis lowering adds no casts solely to standardize backend result types or preserve transport precision; business-required conversions remain. The pandas handoff resolves the effective numerical types of direct fields, reductions and internal components for subsequent local operations and publication, retaining complete keys, null policies, units and time semantics. Casting cannot recover lost source precision; saved-output fidelity concerns the values actually committed.

DuckDB reads use Ibis Arrow results to construct pandas integer columns with nullable Arrow extension dtypes. Large integers remain exact beside null values without an intermediate float64 conversion. Local computation still uses pandas; this conversion guarantee does not extend to other backends.

Time preparation and temporal rewrites use the actual selected engine. Remote source blocks use the unfused route until their own equivalence is established. Local execution is eager and may retain full required vectors in memory. Failure never switches route or truncates input.

DuckDB native INTERVAL is admitted in microseconds only after a source-native check rejects year, month and day components. It cannot become elapsed time merely by casting and does not supply nanosecond precision. Arrow Duration on a qualified file route preserves the file's declared tick unit.

Ordinary PostgreSQL, MySQL, Trino and ClickHouse templates admit count, count_distinct, sum, min, max, mean and weighted_mean subject to actual type and expression qualification. Exact source median/quantile currently admit only DuckDB and PostgreSQL. MySQL, Trino and ClickHouse reject those methods before Run admission; ClickHouse's Ibis Quantile lowering is approximate and cannot satisfy an exact request. Exact/approximate reductions retain their definition-owned algorithm. Typed missing mappings, nonfinite values, overflow and required coverage failures prevent publication.

ClickHouse Distributed admits qualified ordinary grouped aggregation. Source routes requiring a Distributed IN/JOIN, including keyed `Session.read`, reject before Run admission because that join route is not qualified under `distributed_product_mode`. MergeTree joins have separate qualification; views and other engine topologies are not implicitly admitted. Marivo does not change server settings or substitute local tables.

## Resource and saved-output boundaries

Datasource native timeouts retain their backend meanings. There is no default graph deadline or automatic alternative executor. Cancellation and close remain driver-owned; unknown remote termination stays unknown. Atomic publication and journal reconciliation preserve committed success and exactly owned resources.

Older-generation data refuses unchanged, with no migration or dual read. Complete export preserves int64/Decimal, NA, presence, keys, order and frozen calendar/paired interpretation.
