## Check source form and method

Table, file and HTTP discovery have different execution conditions. Parameterized HTTP JSON can be declared and previewed but is not an admitted numerical Frame source. Exact source median/quantile currently use DuckDB or PostgreSQL. Ordinary count, distinct count, sum, min, max, mean and weighted mean still depend on actual types and expressions.

Contribution currently requires qualified native DuckDB physical tables and retained source declarations. A successful remote observation does not qualify remote contribution. Use explicit observe and compare to investigate unsupported contribution targets without claiming a decomposition.

## Account for resource and numeric limits

Local data operations can retain full required vectors in memory. A display limit is not a computation or scan limit. Timeouts retain the driver's native meaning and may be unsupported; there is no whole-graph deadline or silent switch to another executor.

Source precision and overflow follow the qualified backend. Conversion cannot repair precision already lost or a value already wrapped by the source. Local arithmetic has its own checked rules. No universal Decimal precision guarantee applies across all sources.

The local tutorial demonstrates its DuckDB route only. [Connect data](/docs/latest/modeling/semantic-layer/) for setup and [troubleshoot](/docs/latest/reference/troubleshooting/) for concrete failures.
