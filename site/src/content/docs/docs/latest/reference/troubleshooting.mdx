Start with the error's expected input, received facts and concrete repair.
Keep the business question unchanged while repairing that boundary.

## Environment and semantic scope

Use the selected environment's `marivo doctor --project-root <project>` and
requested datasource extra. Unknown identities require Catalog discovery;
credentials remain environment references. Readiness, preview, source health
and actual method evaluation are distinct evidence. Same-path definition changes
alone do not reject existing inputs; keep kind/root/grain/unit/time/null checks.
Business versioned identity anchors remain a separate contract.

## Complete keys and exact Frame handles

Column/FrameAxis belong to an exact input; reacquire them from the receiver or
explicitly align complete axes. Matching names/fingerprints or exported attrs
cannot rebind them. Continuing the [tutorial](/docs/latest/guides/python-quick-start/):

{/* example: repair-query-domain */}

```python
aligned = current.align(
    baseline, on=((current.axes[0], baseline.axes[0]),), how="outer",
)
difference = aligned.select({"difference": aligned["left.revenue"] - aligned["right.revenue"]})
difference.show()
```

Exact requires unique complete joint matching keys. Outer keeps missing sides
with independent presence, without zero fill. Field Null is a valid category.
read requires a complete Entity identity domain, nonempty fields and valid
single-valued routes/version anchors. A later filter cannot hide required errors.
For new source facts, explicitly supply the governed input and ordinary-axis
population_from mapping; on is required, including legal on=().

## Time and numerical policies

Use Session instant/time_scope and supply exactly one integer keyword to
`mv.offset(years=...)` or `mv.offset(periods=...)`. CalendarAxis.shift accepts
unit-step builtin week/month/year full buckets or bucket-start prefixes; partial
day/quarter, middle slices and ambiguous nonzero target clocks require an explicit
supported domain. Missing ISO week/civil cutoff is a legal absent target, not a
clamped date. Ordinal still needs complete buckets and keeps original positions.

Named compare needs a nonempty alias-to-Frame mapping and complete per-alias on
bindings when ordinary axes exist. A frozen direct relation must match the whole
current domain; use matching original endpoints or an explicit consistent rule.
Do not repair a wrong anchor/conflicting rule by changing how. Actual baseline
time rows outside the current declared domain require explicit baseline filtering
or align's general time union. Outer does not repair missing/corrupt frozen data
or turn NA into zero. Inspect `current.present` / `<alias>.present` separately from
value NA and inherited `<alias>.presence.*`. See
`marivo.help("analysis.calendar_axis.shift")` and
`marivo.help("analysis.analysis_frame.compare")`.



Division policies apply to that new operation, not strict children. Nonfinite,
overflow and required coverage failures block completion. An unavailable route
is not permission to change algorithm, source or requested precision.

## Explicit Attribute and full explanation reads

Use `AttributeEndpoint` with resolved source Metrics and explicit scopes; a
Frame/Column/Artifact cannot recover source authority. Complete ordinary parent
axes need dual `parent_on` bindings from the exact receiver; `by` must add a
business classification. `contribution` is a strict boolean, not a truthy flag.

`unsupported_expression` means the requested exact decomposition has no admitted
rule; `missing_component_proof` means its required sample/partition/components
were not proved. `unqualified_contribution_route` identifies a source route
outside the qualified physical DuckDB table boundary. Keep original source and
numeric failures under their own repair. Do not change precision, invent proof
or silently downgrade. If the original observation is valid, explicitly request
`contribution=False` for investigation. Exact calls are at
`marivo.help("analysis.session.attribute")`.

Pending `method_facts` requires compute/persist first. On stored data the getter
validates complete owned method files, without primary rows or source reads.
Cards/open/preview and `to_pandas()` do not validate method payloads; stored compute
and evaluated derivatives do. A damaged method file can therefore leave current
row export usable but block full consumption. Preserve the original files and
repair the reported owned payload; do not reconstruct it from current sources.
See `marivo.help("analysis.analysis_frame.method_facts")`.

## Exact data recovery and resubmission

Keep Session ID and frame.artifact.id. Resume that Session and call
`session.persisted_frame(id)` with the string ID. Frame owns data operations;
`.artifact` owns audit. Artifact/ID objects and RawSqlResult are not operands.
Publishing errors provide the failed phase and a concrete repair. If the commit
outcome is unknown, resume the owning Session before explicitly resubmitting;
the original may already have succeeded, so resubmission may create duplicates.
If the returned Artifact ID was lost, explicitly resubmit. Complete memory data
can be saved again without reevaluation; rebuilding source inputs may read changed data.
Missing/corrupt consumed data is not a cache miss and must not trigger replay.

Store 15 refuses every older generation's data unchanged, without migration or
dual reads. Absent-current discovery may return None/empty without exposing old
state; create cannot initialize around an old-only project.
Before switching, export required results with the original version or retain a
compatible environment. Preview limits affect display, not complete execution.
Preserve the old Store and create a new named Session in a fresh project for
current work. Store15 uses generation15/output-v4 for every Frame; this is not
automatic export/import migration or a same-project bypass.
The [AnalysisFrame cutover note](https://github.com/chengxianglibra/marivo/blob/main/docs/architecture/analysis/analysis-frame-cutover.md)
explains breaking APIs, value names, postponed capabilities and recovery choices.
