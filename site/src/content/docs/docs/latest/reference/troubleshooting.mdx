## Environment and semantic scope

Use the selected environment's `marivo doctor --project-root <project>` and install the requested datasource extra there. Invalid configuration and missing roots need their explicit repair. Credentials stay in environment references. Unknown names require Catalog discovery; connectivity, readiness, bounded preview and execution are different evidence.

## Complete keys and Query ownership

Columns belong to their exact Query input. Compose with that input's columns or explicitly align/broadcast before combining independent inputs. Continuing the [local tutorial](/docs/latest/guides/python-quick-start/):

{/* example: repair-query-domain */}

```python
aligned = current.align(baseline, how="outer")
difference = aligned.select({"difference": aligned["left.revenue"] - aligned["right.revenue"]})
difference.contract().show()
```

Exact alignment requires unique complete matching keys; outer preserves missing sides with independent presence. Missing values do not supply keys or a zero-fill policy. Field Null is a valid category. Complete tuple membership predicates preserve every component and use null-safe AND/OR semantics; they do not independently test each column's membership.

Attributes use `session.read(population, {"name": field})`. The domain must have one complete Entity identity axis and a compatible Session owner. Supply a single-valued directed field.via((relationship,)) path and exact field.at(anchor) where required. Missing required mappings fail before consumption; a later filter cannot hide that failure. There is no Population.read or implicit Session lookup. Use observe for a computed Measure expression.

## Time and numerical policies

Use session.instant/time_scope for exact boundaries. Naive Python datetimes, ambiguous/nonexistent wall clocks and conflicting calendar authority require explicit repair. Ordinal needs equal Grain, compatible timezone/authority and complete nominal buckets; outer cannot repair a partial bucket. Daily leap-day previous_year has no counterpart: choose outer or adjust the requested period/grain, without clamping the date.

Division defaults zero_denominator to null. Use error only when the new demanded division should fail; that choice does not override input subexpressions. Nonfinite values, overflow and required coverage errors block publication. An unavailable physical route is a capability error, not permission to switch algorithm, source or engine.

## Terminal output and failed Runs

Keep the exact Session and Artifact IDs and project-local state. `session.artifact(id)` opens committed metadata; its output cannot be passed to compare/observe or converted back to Query. Analyze those rows with to_pandas, or construct a fresh source Query.

An admitted error's run_ref identifies the exact Run for `session.get_run(run_ref).show()`. A corrected execute creates a new invocation. Reconciliation resolves the original journal without replay; incomplete or failed Runs may be abandoned through the owning Session lifecycle API, preserving history.

Old Stores reject unchanged. Missing/corrupt consumed output cannot be repaired by replaying a source recipe during recovery. Preserve original state and use a fresh current-format project where required. Preview limits affect display, not complete execution or export.
