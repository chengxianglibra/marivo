## Query the installed version

Python and the CLI share Help targets. For example, call
`marivo.help("analysis")` in Python or run `python -m marivo help analysis` in
the CLI. See the [installed-version section](/docs/latest/reference/troubleshooting/#query-the-installed-version)
for global and focused Help examples.

## Ask for help effectively

When reporting a problem, share the Python executable, Marivo version and
package path, and project root shown by Doctor. Include the smallest relevant
declaration and code, the full structured error, and the expected and actual
results. Remove credentials and private data. See
[the reporting guidance](/docs/latest/reference/troubleshooting/#ask-for-help-effectively).
