Marivo is a Python library for business data analysis. Its semantic layer records reusable business definitions, including metrics, entities, dimensions, and relationships. The analysis DSL applies those definitions to calculate and compare results. Saved results retain source and evaluation records for review.

For example, define revenue from an orders table with amounts, regions, and dates. Calculate monthly revenue by region, compare periods, or explore trends with rolling windows. Persist a completed result to reopen its captured values later.
