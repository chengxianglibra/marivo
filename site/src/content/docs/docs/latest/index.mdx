Marivo is a Python analysis harness for AI agents. Reusable semantic definitions
bind business meaning; typed analysis computes explicit results and records
Evidence. You or the agent choose the question and interpret the outcome.

This `latest` guide follows the current development implementation. Versioned
docs describe their historical releases; installing a released package does not
imply every development API is available.

## Follow one reviewable loop

1. Establish the decision, approved Metric meaning and scope.
2. Reuse governed objects; author a missing reusable slice when needed.
3. Construct explicit logical analysis, then execute when results are needed.
4. Read the materialized result and its Evidence within their scope.
5. Review the conclusion, limits and any remaining evidence gap.

Start with [core concepts](/docs/latest/concepts/) and [analysis workflow](/docs/latest/concepts/analysis-workflow/).
Advanced topics cover time/cohorts, comparisons, statistics, Events, lifecycle,
retention and calendars. Exact signatures remain in native Help and the
[Python API reference](/api/).
