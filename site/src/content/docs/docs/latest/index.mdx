Marivo is a Python library for business data analysis. Its semantic layer defines metrics, entities, dimensions, and relationships. Its analysis DSL uses those definitions to calculate, compare, and break down results while retaining the basis for the calculation.

For example, an orders table contains amounts, regions, and dates. Define revenue once, then query monthly revenue by region, compare periods, calculate rolling windows, or measure correlation. Save results to continue working with the same data later.

## What you can do

| Task | Operations and results |
| --- | --- |
| Connect data | Declare databases or files and inspect schemas and samples |
| Define business meaning | Reuse revenue, average order value, units, time, and relationships |
| Query and group | Calculate by region, customer, or period; select records |
| Compare and investigate | Compare periods or targets and investigate changes by dimension |
| Time and statistics | Calendar grouping, rolling windows, shares, and correlation |
| Save and inspect | Save fixed results and read their data and method explanations |
