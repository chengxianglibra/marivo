## Create the source and datasource

Save the following code as seed.py and models/datasources/warehouse.py respectively. Run .venv/bin/python seed.py in the selected environment to create the demo database.

{/* example: demo-seed */}

```python
from datetime import date
from pathlib import Path
import duckdb

Path("models/datasources").mkdir(parents=True, exist_ok=True)
Path("models/semantic/sales").mkdir(parents=True, exist_ok=True)
with duckdb.connect("warehouse.duckdb") as connection:
    connection.execute("""
        CREATE OR REPLACE TABLE orders (
            order_id BIGINT PRIMARY KEY,
            order_date DATE,
            region VARCHAR,
            amount BIGINT
        )
    """)
    connection.executemany(
        "INSERT INTO orders VALUES (?, ?, ?, ?)",
        [
            (1, date(2026, 7, 5), "east", 100),
            (2, date(2026, 7, 15), "east", 200),
            (3, date(2026, 7, 20), "west", 700),
            (4, date(2026, 8, 5), "east", 100),
            (5, date(2026, 8, 15), "east", 100),
            (6, date(2026, 8, 20), "west", 600),
        ],
    )
```

The approved demo meaning is revenue from exactly these six completed orders,
in CNY, without refund or currency conversion. July totals 1,000 and August 800.
East changes from 300 to 200; west from 700 to 600. This synthetic definition is
not a template for deciding production revenue meaning.

## Declare the datasource

Save as `models/datasources/warehouse.py`. The database exists before the read-only connection is loaded.

{/* example: demo-datasource */}

```python
import marivo.datasource as md

md.duckdb(name="warehouse", path="warehouse.duckdb", read_only=True)
```


## Author source fields and a local Metric

{/* example: demo-model */}

```python
import marivo.datasource as md
import marivo.semantic as ms

ms.domain(name="sales", owner="Mina Zhang")
orders = ms.entity(name="orders", datasource=ms.ref.datasource("warehouse"),
                   source=md.table("orders"), primary_key=["order_id"])
order_date = ms.time_dimension_column(name="order_date", entity=orders,
    column="order_date", granularity="day", is_default=True)
region = ms.dimension_column(name="region", entity=orders, column="region")
amount = ms.measure_column(name="amount", entity=orders, column="amount",
    additivity=ms.additive_all(), unit="CNY")

finalized = ms.finalize()
orders = finalized.resolve(orders)
order_date = finalized.resolve(order_date)
region = finalized.resolve(region)
amount = finalized.resolve(amount)

@ms.metric(ai_context=ms.ai_context(
    business_definition="Completed-order revenue in CNY for the six demo orders",
    guardrails=["Use only these demo orders; no refunds or currency conversion"],
))
def revenue():
    return amount.sum(time=order_date)
```

Save as models/semantic/sales/_domain.py. Model loading can validate the physical Entity/Field declarations; this slice does not publish local revenue into catalog.metrics.

{/* example: demo-readiness */}

```python
import marivo.semantic as ms
catalog = ms.load(workspace_dir=".")
amount_entry = catalog.require(ms.ref.measure("sales.orders.amount"))
amount_entry.show()
report = catalog.readiness(refs=[amount_entry])
report.show()
```

This check does not compute revenue. The independent seed-data expectation is 1000 in July and 800 in August; those values are not Runtime acceptance for the new expression path. A local revenue declaration or leaf readiness is not an observable Catalog Metric. Execution requires the later publication and execution path and its live Help.
