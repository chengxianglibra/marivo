## Reduce or select current cells

{/* example: query-result-statistics */}

```python
summary = current.reduce({
    "sum": current["revenue"].sum(),
    "mean": current["revenue"].mean(),
    "rows": mv.row_count(),
})
summary.execute().show()
ranked = current.top(1, by=current["revenue"], descending=True)
ranked.execute().show()
```

Query.reduce provides sum, mean and row_count. Sum ignores ordinary NA and returns NA for empty/all-NA input; mean is NA with no effective sample. row_count counts coordinate rows even when their value is NA. `by` uses existing complete axes or a lawful coarsened calendar. Top-N uses a Column from this exact input, optional partition_by, and deterministic complete-key tie breaking. Its display order survives reopening.

An average of regional revenue cells is a current-cell statistic. It does not replace an original overall Metric, whose formula and contribution permissions belong to rollup or a new observe.

## Export for descriptive analysis

{/* example: pandas-descriptive-statistics */}

```python
values = current.execute().to_pandas()["value"].copy()
revenue_values = values["revenue"]
statistics = revenue_values.agg(["count", "sum", "mean", "median", "min", "max"])
print(statistics)
rank = revenue_values.rank(method="dense", ascending=False)
standard_deviation = revenue_values.std(ddof=1)
if standard_deviation > 0:
    standardized = (revenue_values - revenue_values.mean()) / standard_deviation
```

Pandas owns ordinary ranking, standardization, classification, correlation, forecasting and cell-level rolling statistics. State the chosen sample, NA handling, tie method, fit scope and uncertainty. These operations return ordinary data and do not produce a Marivo Query or Artifact. A high standardized value is not automatically a business anomaly.

## Pair one shared set of endpoint rows

{/* example: pandas-paired-statistics */}

```python
comparison = current.compare(baseline).execute().to_pandas()
present = comparison[("presence", ("current",))] & comparison[("presence", ("baseline",))]
pairs = comparison.loc[present, "value"][["revenue.current", "revenue.baseline"]].dropna()
paired_difference = pairs["revenue.current"] - pairs["revenue.baseline"]
print(paired_difference.mean())
```

Presence and value validity are separate. Pair the common present, non-NA rows and retain their complete business keys; do not join independent outputs by RangeIndex. With Field Null categories, use dropna=False for a grouping that must preserve them. The sample and selection determine the meaning of a descriptive result; arithmetic agreement does not establish causality.
