# Marivo 分析代数

观察一个指标，就是为每个输出键计算一个值。**输出键决定报表粒度，进入归约的对象决定统计单位。** 一张按月出数的报表，既可以对订单金额求均值，也可以先算每位客户的消费总额，再对客户求均值。两者都是每月一个数，分母却不同。

## 核心对象与求值

固定一次分析所用的数据实例 `I`。Metric 表达式 `m` 定义量的含义、来源分支、贡献时钟、归约次序和单位。上下文 `Γ` 绑定本次筛选、所用总体、分组、报告期间和输出域规则。`Eval(I, m, Γ)` 仅在类型、绑定、覆盖和方法前提满足时有结果。一次观察中的所有指标共用输出域规则。以下三个对象描述一次成功的求值。

| 对象 | 含义 |
| --- | --- |
| 输出键集 `K` | 实际输出的有限个完整坐标元组，每个键占一行。零轴标量的键集是 `{()}`，零行结果的键集是 `∅`。 |
| 贡献出现 `Cₖ` | 当前分支在键 `k` 下接纳的各次贡献。一次贡献可以是一笔订单、一个客户、一个带权样本，或一个已经完成的子结果。 |
| 结果列 `(V, x)` | `V ⊆ K` 是该列有有效值的键，`x:V→T` 给出这些值，`T` 是值类型。每列有自己的 `V`，Frame 另有行序、端点存在性及冻结坐标等事实。 |

令 `v(k,c)` 是一次贡献提供的可空输入，`ρ` 是该层的归约。把结果列记作 `q:K→T∪{NA}`，在 `V` 上取 `x(k)`，其余输出键取 NA。一个分支的基本式为

$$
q(k)=\rho\bigl(\{\!\{\,v(k,c)\mid c\in C_k\,\}\!\}\bigr),\qquad k\in K .
$$

双花括号表示有限多重集。两笔 10 元的订单贡献两个 10。把各组的出现标为 `(k,c)` 再取不交并，就得到总贡献集 `C` 和归属映射 `a:C→K`，各组正是 `a⁻¹(k)`。一笔事实可以通过不同的出现归入多个键。多来源指标的每个分支有自己的 `Cₖ`，各分支在共同输出键上完成后才组合。绑定身份、值、重数和输出域描述的是问题的含义，执行器可选择符合这些条件的物理计划。[来源贡献与内部样本](populations-and-observation.md#contribution-occurrences-and-internal-samples)

数学等式在同一 `I` 上比较。实际的两次来源读取各有自己的读取状态，相同的 Metric 和报告期本身不能建立共同快照。来源绑定信任已声明的身份、基数和版本粒度，具体操作仍须完成其所要求的检查。[来源声明与检查](populations-and-observation.md#population-identity-and-set-semantics) · [Session 与求值归属](session-state-and-runtime.md#session-and-invocation-ownership)

## 输出键和贡献从哪里来

<a id="8-可选身份域绑定"></a>

Population 表示带类型、按完整元组去重的有限键集。客户的复合主键是一个完整身份，收货城市与开票城市是不同角色。显式给出的客户键表示请求该身份，来源成员选择表示实际命中的身份。普通指标可以直接绑定订单等事实。显式使用同一个 Population `P` 时，它的位置决定其作用。

| 使用位置 | 对计算的约束 |
| --- | --- |
| `where=mv.in_population(P)` | 按完整键判断事实是否命中 `P`。同一事实有多个合格匹配也只保留一次。 |
| `by=P` | 输出 `P` 的全部键，包括没有事实的键。显式贡献条件生效后，`P` 必须覆盖来源所需的完整外层键。漏键在内部样本选择或结果裁剪前报错。 |
| `m.per(P)` 后接归约 | 为每个输出键选择与其共享轴相容的样本。`P` 可以选取子集，也可以包含没有贡献的样本。每个被选样本都按子指标的规则完成。 |

普通字段或日历分组使用各分支实际支持的**完整联合键的并集**。支持由贡献或声明的坐标输入建立，先于各值的缺失处理和公式运算。因此，同一次观察中的 `a+b` 自动在公共域上完成两侧。某一侧没有贡献时，金额 sum 可以在另一侧建立的键上得到 0。一旦两张表已分别完成，再做外对齐，缺侧按端点存在性处理。[观察域与覆盖](populations-and-observation.md#observation-domain-contributions-and-counts) · [来源公式的键并集与补值](../../../marivo/analysis/compiler/native_formula.py#L66)

例如 A 仅在 1 日消费 40 元，B 仅在 3 日消费 100 元，`a`、`b` 分别是两人的金额 sum。在相同的普通按日设置下单独观察 `a`，结果只有 `(1日, 40)`。单独观察 `a + 0*b`，结果有 `(1日, 40)` 和 `(3日, 0)`。对结果行求均值分别得到 40 和 20。消去 `0*b` 会一并删去它提供的键。[稀疏公式与支持域测试](../../../tests/analysis/materialization/test_deferred_windows.py#L1159)

**时间。** 报告 CalendarAxis 给出候选期间。有归期的分支用自己的贡献时钟解释范围和桶。普通桶使用名义半开区间与报告范围的交集，窗口在每个端点使用声明的贡献区间 `W(t)`，可以读到显示范围之前的贡献。相同客户连续两天出现，日去重人数各为 1，覆盖这两天的窗口去重人数仍为 1。[时间窗口](../temporal-semantics.md#metric-windows)

普通 `by=(calendar,)` 只输出实际支持的键，三个月的目录可以只有两行结果。要保留全部所选月份，用显式输出 Population。没有归期的分支在已有条件下计算，再沿缺少的报告时间轴广播到已建立的键。只有这类分支且没有其他兼容时间键来源时，按时间出数也需要显式输出 Population。[日历目录与实际结果行](../../../tests/analysis/materialization/test_deferred_windows.py#L1244)

**多值关系。** 对事实 `f` 和标签键 `k`，存在性筛选问“是否有匹配”。按 `membership` 分桶则对每个不同的 `(f,k)` 产生一次贡献，重复路径命中的同一对只计一次。一笔 100 元订单属于两个标签，两个标签各得 100 元。若量度的是两次独立的关联事件，需保留事件身份。若要按权重分摊金额，还要给出权重及其业务条件。同一描述内的多个字段使用实际匹配的联合元组。只有独立的分桶描述才对各自的匹配集合取乘积。[分桶、重数与关联规则](populations-and-observation.md#contribution-occurrences-and-internal-samples)

## 一套空值语义

一次成功求值中，`k ∉ K` 表示没有结果行，`k ∈ K∖V` 表示有行而本列为 `NA`，`k ∈ V` 时读取 `x(k)`。数据库 NULL 和列中的普通缺值使用同一值级语义。数值 0、空字符串和带有效位的浮点 NaN 各按其类型解释。绑定不合法、请求域漏键、读取失败或严格断言失败属于求值错误。已读范围内没有贡献，只说明本次问题的贡献集为空。[数值与有效性合同](operators-and-frames.md#null-empty-and-arithmetic-policies)

对一个已经存在的输出键，记 `n` 为真实贡献次数，`h` 为其中值有效的次数。显式名单带来的结果行可以有 `n=0`。以订单金额为例，默认规则如下。

| 实际订单金额 | 订单数 `n` | 有金额的笔数 `h` | 金额 sum | 订单 mean |
| --- | ---: | ---: | ---: | ---: |
| 无订单 | 0 | 0 | 0 | NA |
| `[NA, NA]` | 2 | 0 | NA | NA |
| `[0]` | 1 | 1 | 0 | 0 |
| `[10, NA, 30]` | 3 | 2 | 40 | 20 |

sum 在 `n=0` 时取有类型的零，在 `n>0, h=0` 时取 NA，其余情况累加有效值。mean、min、max、分位数在没有有效样本时取 NA。字段 count 和去重计数只计有效值。Entity 计数、Population 计数、Frame 的 `row_count` 分别计贡献出现、不同的完整成员键和当前结果行。[空贡献、全 NULL 与有效零](../../../tests/analysis/materialization/test_sum_null_contract.py#L17)

表中 40 是已知金额的合计。要求每笔金额齐全时，可在支持的来源或内部归约上使用 `nulls="error"`。空贡献集通过这项断言，后续选择或零乘子仍须保留对原需求范围的检查。[来源归约实现](../../../marivo/semantic/_numeric_lowering.py#L240)

普通数值算术传播所需操作数的 NA。`/` 固定将零分母映为 NA，包括 `0/0`。加权均值的分子、分母使用同一批值与权重都有效的样本，支持有符号权重，有效权重和为零时取 NA。相关系数也使用共同有效的配对，样本不足或一端为常量时取 NA。[除法实现](../../../marivo/semantic/_numeric_lowering.py#L86) · [算子与样本合同](operators-and-frames.md#null-empty-and-arithmetic-policies)

可空布尔谓词按三值逻辑组合，`where` 只保留 True。允许空值的普通分类键把 NULL 当作可匹配的类别，比较完整键时两个对应的 NULL 分量视为相等。Entity 身份则要求每个主键分量都非空。[Population 的键与集合语义](populations-and-observation.md#population-identity-and-set-semantics)

有效键集 `V` 是数学记法，列可直接复用原生有效性位图。sum 在可空累加值之外，只需记住是否见过真实贡献，缺失处理的额外状态每组为常量。现有来源实现用同一聚合中的行数与有效值数作判断。分析需要披露这两个数时，可把它们作为指标输出。[来源聚合的空组判断](../../../marivo/semantic/_numeric_lowering.py#L248)

外对齐后，从输出键 `j` 到每个端点各有一个部分映射。该侧有对应的结果行时，`present=true`，取该行的值，即使它是 NA。该侧没有对应行时，`present=false`，值列取 NA。名单上的客户没有订单，仍然可以有一行 `present=true`、金额 sum 为 0 的结果。[Frame 的值与 presence](analysis-frame.md#名称与-presence)

## 三种计算

| 动作 | 定义 | 典型用途 |
| --- | --- | --- |
| 按键取值 | 对 `r:J→K`，新列在 `j` 上取 `q(r(j))`，新有效域为 `r⁻¹(V)`。 | 切片、沿已声明的对应取数、把组统计映回原行 |
| 逐键运算 | 在共同 `K` 上按算子规则计算 `g(q₁(k),…,qₙ(k))`。类型、单位、缺值和算子定义域在这一层生效。 | 来源分支完成后求比率、对应后的两期求差 |
| 按键归约 | 选择目标键及其贡献出现 `Cₖ`，对每个键按基本式应用 `ρ`。 | 对事实聚合、对内部样本求均值、对当前 Frame 行作统计 |

**嵌套归约。** 设 `Jₖ` 是键 `k` 下的样本键集，内层域是所有实际的 `(k,j)`，其中 `j∈Jₖ`。`m.per(P).mean()` 先对每个 `(k,j)` 完成整个 `m`，再在 `k` 内对这些值求均值。同一客户可以在多个地区分别成为样本。字段推导的样本来自实际联合键，显式样本域还可以包含零贡献客户。[样本归约与完成顺序](populations-and-observation.md#contribution-occurrences-and-internal-samples)

同一个月里，A 有两笔 10、30 元的订单，B 有一笔 100 元订单，名单中还有未下单的 C。下面四个问题有相同的输出键。

| 问题 | 进入最外层均值的样本 | 结果 |
| --- | --- | ---: |
| 每笔订单平均多少钱 | 三笔订单的金额 10、30、100 | `140/3` |
| 每位购买客户平均消费多少 | A、B 的消费总额 40、100 | 70 |
| 购买客户各自的订单均价，等权平均是多少 | A、B 的订单均价 20、100 | 60 |
| 名单内每位客户平均消费多少 | A、B、C 的消费总额 40、100、0 | `140/3` |

若给 A 加一笔 20 元订单，订单均价变为 40，名单内客户的平均消费变为 `160/3`。若原数据唯一的变化是给 C 加一笔金额为 NA 的订单，C 的小计从 0 变为 NA。名单仍有三人，默认均值的有效分母变为 2，结果为 70。

<a id="53-参照与共同有效样本"></a>

**当前行与参照。** `Frame.reduce` 以当前行作为贡献。若 `h:K→J` 是完整分组键的投影，`Frame.over` 先在每组统计，再沿 `h` 把组值映回原行。空 `K` 映回后仍为空。`Column.share` 用当前值除以映回的分组 sum。先为 `(1,3)` 算份额再保留第一行得 `1/4`，先保留第一行再算得 1。业务构成比要求分子与参照使用同一贡献口径。若各分子是同一可加量在完整不交分区上的小计，参照是非零总额，且各份额均有定义，则在精确算术下它们之和为 1。[分区统计、广播与份额](operators-and-frames.md#partition-statistics-and-current-value-shares)

**对齐与比较。** 两个已完成结果的轴要建立完整对应。普通轴可显式给出 `on`，也可接受唯一同名、相容完整键的默认约定。调用方声明业务对应，系统验证 Session、轴角色、完整键结构和时间解释。结构相容且源自不同 Entity 的普通轴也可以显式对应。数学上的精确对齐还要求对应后的实际联合键域相等。公开 `align` 和 `compare` 固定使用 outer，缺侧给出 NA 与独立 presence。`align` 可保留双端时间并集。`compare` 保留本期时间轴，各实际基期时间行须先映入本期声明域，映入后仅基期有行的联合键也保留，无法映入则报错。相对变化取 `(本期−基期)/abs(基期)`。[Frame 对应与比较](analysis-frame.md#correspondence-and-comparison) · [基期时间检查](../../../marivo/analysis/methods/frame_comparison.py#L698)

**重新绑定。** 对 Metric 改换期间、条件或样本，是在新上下文中重新求值。固定 Frame 的选择和归约使用捕获的键与值。`session.population_from(frame, on=...)` 投影并去重所选普通轴的完整联合键，按显式 Field 或 Entity 目标建立新的语义绑定。版本化目标字段省略锚点时，须能确认沿用同一个未锚定的直接字段。换绑到另一个版本化字段须给出目标时间锚点。[固定键的来源桥接](populations-and-observation.md#fixed-data-bridge-to-a-new-source-question) · [版本化字段的准入检查](../../../marivo/analysis/dsl/frame_population.py#L155)

取得更细分类或新事实需要新的显式来源输入。独立恢复的 Frame 使用已存数据，`source_reads` 供审计。持有合格来源声明的进程内 Frame 可用 `attribute` 固定当前父键并发起新读，此时旧观察值与本次来源总额各有自己的读取状态。[Frame 载体](analysis-frame.md#数据结构与载体)

## 等式在什么条件下成立

两个程序可以互换，首先要求**可成功求值的输入域相同**。先固定业务问题的贡献身份与重数、有效样本、来源时钟与版本、单位和参照。两边的完整输出键应当一一对应并保留绑定，每个键的行存在性、值及其有效性须相同。方法可观察的顺序和必要失败也是结果的一部分。后续 `top(0)` 或只选一个结果列，仍须保留原先必做的检查。[检查范围的执行测试](../../../tests/formal/verify_query_rewrites.py#L378)

下述摘要等式采用精确算术。在实际后端改写求和顺序、浮点均值或 Decimal 运算，还要满足原生精度、舍入、溢出和完成边界。近似计算另须遵守所选算法及参数的约定。[物理数值合同](operators-and-frames.md#physical-numeric-and-temporal-carriers)

在固定键和共同有效的实数样本上，精确求和对加法具有线性。若两列为 `x=(1, NA)`、`y=(NA, 2)`，逐行相加得到 `(NA, NA)`，因此 `sum(x+y)` 为 NA，而 `sum(x)+sum(y)` 为 3。两条计算路径使用了不同的有效样本。

### L6 摘要分区与上卷

设摘要状态集为 `S`，合并运算 `⊕` 满足结合律和交换律，空状态 `e` 是其单位元。`η` 把单次输入编码成状态，`φ` 从状态算出最终值。若对每个允许的多重集 `B` 都满足下式，就可以先分别归约再合并摘要。

$$
s(B)=\bigoplus_{u\in B}\eta(u),\qquad s(\varnothing)=e,\qquad \rho(B)=\varphi(s(B)).
$$

要求分解前后有相同的定义域和结果。若 `B` 按**贡献出现**不交分为各个 `Bᵢ`，则 `s(B)=⊕ᵢ s(Bᵢ)`。用 `a:C→K`、`h:K→J` 表示两次归属，沿 `h∘a` 直接合并和分两次合并会收到同一批出现，空组贡献单位元。原程序若要求完成并检查细组，改写也须保留这些检查。粗化若改变了成员选择、窗口或内部样本，必须按新问题重新确定贡献。

| 目标 | 足够的状态（精确算术） | 合并后如何完成 |
| --- | --- | --- |
| 有效值均值 | 分组有效值之和与有效数 | 分量分别相加，再除以总有效数，零个有效值取 NA |
| 精确去重人数 | 各组有效用户身份集合 | 先取并集，再数不同身份 |
| 精确分位数 | 各组的有效值多重集 | 按重数合并，再按同一方法取分位数 |
| 默认金额 sum | 空、全 NA、或含有效值且和为 `s` | 有有效组时累加各有效组的和，否则按是否见过贡献取 NA 或 0 |

业务上还须允许沿所移除的轴合并该量。两天的期末库存都是 10 件，当前两行求和得 20 件，第二天的期末库存仍为 10 件。重叠标签也会重复订单。若同一客户横跨两个地区，求整体客户均值需先用原贡献或充分摘要算出每位客户跨地区的值，再对不同客户等权求均值。[当前行与原始指标](operators-and-frames.md#current-cells-original-metrics-and-windows)

### T1 后续计算的信息充分性

在约定的输入空间上，`R(X)` 是可复用的信息，`T(X)` 是下一步想求的答案。存在良定义的 `H` 使 `T=H∘R`，当且仅当

$$
\forall X,Y,\quad R(X)=R(Y)\ \Longrightarrow\ T(X)=T(Y).
$$

正向来自函数性。反向对每个保留值选一个产生它的输入，将该输入的答案作为 `H` 的值，上式保证选择哪个输入都相同。它判断信息充分性，算法成本要另外分析。若目标包含必要失败，要将可求值性一并纳入判定。

固定输出名单 A、B。第一份数据只有 B 的一笔 NA 订单，第二份另加 A 的一笔 0 元订单。两份数据的分组 sum 都显示 `(0, NA)`，对这两行再求和都得到 0。可原始订单 sum 分别为 NA 和 0。按 T1，只保留分组键与完成值，无法回答这两份数据的原始总额。类似地，地区总额无法还原客户名单，日去重人数也无法还原周去重人数。[默认 sum 与当前行统计](operators-and-frames.md#current-cells-original-metrics-and-windows)

### T2 仅用最终值并组的判据

对全定义的 `ρ`（输出可含 NA），只用各组最终值就能处理**任意并组，包括空组**，当且仅当在 `ρ` 的像上存在结合、交换的运算 `⊗`，满足 `ρ(A ⊎ B)=ρ(A) ⊗ ρ(B)`，单位元为 `ρ(∅)`。这里的相等按可观察的结果判断，两个 NA 都表示缺值。若能只凭两个值并组，这个运算就由上式定义，多重集并的结合、交换和单位律随之成立。部分归约需另外验证定义域。

更一般地，若对每个有限的后续多重集 `D` 都有 `ρ(A ⊎ D)=ρ(B ⊎ D)`，则 `A` 与 `B` 可用同一摘要状态表示。这些等价类可以合并，因为追加同一批贡献后仍然等价。任何充分的可合并摘要都须区分会被某个 `D` 区分的输入。对精确实数、默认忽略 NA 且只求 sum 的问题，表中的三类状态恰好足够。空组与有效零当前都显示 0，再追加一笔 NA 后，前者得 NA，后者得 0。若还需要严格断言或原始订单数，所需状态由新的目标决定。

### 选择、映射与限制

其余定律都作用于已绑定的域。它们说明哪些操作可以交换，以及改变绑定会在哪里破坏等式。

| 定律 | 条件与结论 |
| --- | --- |
| L1 固定选择 | 在同一输入上固定逐行谓词 `p,q`，连续保留 True 与用 `p AND q` 保留 True 得到相同的键。nullable 谓词在 NA 处取反仍为 NA，因此取反筛选与集合补集可能不同。重新计算的排名和阈值有自己的输入域。 |
| L2 投影与关系像 | 函数取像保持并集。对任意两集合都保持交集需要单射。多值关系的存在性逆像保持并集，对交、差的普遍保持需要每个输入至多命中一个目标，保持相对于全部输入的补集还需要处处有定义。重叠时间区间也可能产生多个匹配。 |
| L3 同源成员约束 | 对选中的订单 `H` 和全定义客户映射 `f`，`H ∩ f⁻¹(f(H)) = H`。客户像的完整逆像还可能包含同一客户的其他订单，消去成员过滤时必须保留原 `H`。 |
| L4 映射合成 | 连续沿 `r:J→K` 和 `s:L→J` 取值，在 `l` 上都得到 `q(r(s(l)))`。在来源侧先变换上下文再求 Metric，同样按函数的次序合成，须保留每步绑定和定义域。 |
| L5 逐键合成 | 在同一键域上先用 `f` 后用 `g`，等价于逐键用 `g∘f`，前提是两步的值政策与检查都得到保留。`m/m` 在零处为 NA，不能无条件约为 1。 |
| L7 归约后取值 | 对 `a:C→K` 与 `r:J→K`，键 `j` 收到的出现恰是所有满足 `a(c)=r(j)` 的 `(j,c)`。因此在 `r(j)` 取已合并摘要，等于在这批出现上合并同样的摘要。`r` 非单射时出现会复制。限制到子集时仍须保留原结果的必要检查。 |

<a id="84-保留原坐标的分类是图扩展"></a>

`Population.classify` 的单值分类可写作 `k↦(k,g(k))`。在固定的完整键、同一读取状态和合法时间绑定下，此映射保留原键，故单射，保持行数及并、交、差。随后仅投影分类值则可能合并成员。沿路径组合关系时，中间见证、各步身份、版本时刻与实际读取解释都须匹配。`Frame.fix` 先固定一个普通轴的值，再投影其余轴，该投影在选中的子集上单射，故保留值和相对行序。固定最后一轴后的零行结果仍为空。[Population 集合语义](populations-and-observation.md#population-identity-and-set-semantics) · [固定坐标](operators-and-frames.md#single-member-coordinate-restriction)
