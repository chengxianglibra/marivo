# Marivo 分析代数：序列与构造器

Date: 2026-10-11

Updated: 2026-10-14

Status: proposed v0.17；项目设计提案，不代表实现完成或已获机器形式化验证。
Scope update, 2026-10-13: dedicated Event, journey, lifecycle, funnel, Anchor and retention extensions are deferred. This proposal does not authorize their implementation or expand the current library surface.


本文建立在[核心代数](algebra-theory.md)之上，沿用分析 `𝒜=(m,Γ)`、统一的类型化 Population、
求值 `q:K→A` 以及业务身份、贡献出现与坐标绑定的区分。需要主体的方法在 Γ 中显式绑定
单 Entity 身份域 `M=⟦P_E⟧_{𝓘,Γ}`，不使所有分析都先构造成员集合；本文也遵守
三类结果操作、T1 和核心第 2.3 节的有效域约定。
本文的结果编号为 S1–S6。

本文的数学结果复合描述定义和求值，不授予终端 Artifact 的 DSL 续算能力。
目标 DSL 在 Query 内完成组合，execute 后只读产物或 to_pandas；本篇扩展方法仍按原范围延期。

## 1. 范围

先用核心构造表达固定事件关系上的分析，再引入有序 fold 表达依赖前序处理结果的状态转移。
m 及其构造依赖声明业务顺序、状态规则和输出含义；Γ 绑定角色、贡献范围、观察边界及方法要求的身份域。
下文在固定实例、显式给定的身份域与上下文上描述构造，再将其输出作为后续 Metric 的输入。
结果是带所声明身份与坐标的有限索引族；顺序、出现次数和状态依赖不由载体形式自动决定。

## 2. 事件、顺序与观察范围

```text
Event    --actor--> Subject     Event --at--> Instant    Event --type--> EventType
Journey  --subject--> Subject
Step     --journey--> Journey   Step --event--> Event    Step --index--> ℕ
Interval --subject--> Subject   Interval --state/start/end--> State, Instant, Instant
```

图中名称表示本次求值的有限对象域；其身份类型不要求有限。Event 是事实对象。
Journey、Step、Interval 是构造器产生的带身份对象；多个 Step 可以指向同一 Event，
是否允许这种重复由构造器定义，不从外键或数值推断。来源 Event 的身份不替代 Step 的出现身份。
构造器声明各输出域的完整键及主体、时间等坐标映射；仅当 `(journey,index)` 唯一时，它才可作为 Step 的完整键。

主体域可来自事件的 actor 像、显式名单或其他声明来源，不要求独立主体表。
actor、Step→Journey 等是构造器明确声明的业务映射，不是任意汇总结果隐含保存的成员关系。
事件来源人群只包含其出现过的主体；若目标包括无事件主体，应由 P_E 及目标域明确给出，不能从空事件集恢复。

Γ 绑定观察边界 `[t_lo,t_hi)` 及所用事件范围。“窗口内从未发生”等解释要求该范围覆盖定义所需的事件；
仅分析所选事件流也可以成立，但不能扩张为全部行为。边界本身不提供窗口之前的初态，也不说明未来没有事件。
序列使用主体内有业务依据的全序 ≺，包括并列规则；否则须证明所有允许顺序给出同一所需输出。

## 3. 固定事件关系上的分析

本节显式以 M 为目标身份域，并使用 Γ 绑定的事件范围，因此保留 M 中的无事件主体；
这来自本构造的完整输出声明，不是一般字段分组或成员约束的默认行为。
记 `E_u=actor^{-1}(u)`。事件对由 `Event×_{Subject}Event` 再按条件过滤形成；各投影保留来源身份。

| 语义 | 核心构造 |
| --- | --- |
| 事件数、DAU | 按 `bucket∘at` 观察 count(*)、distinct(actor)，目标日期网格显式给出 |
| 首次、末次发生 | 按 actor 观察 min/max(at)，目标主体网格显式给出 |
| “A 之后 Δ 内发生 B” | 保留 `type₁=A ∧ type₂=B ∧ 0<at₂−at₁≤Δ` 的事件对 |
| 严格时间漏斗到达 A<B<C | 构造有序事件三元组，再取主体像；没有事件消耗约束 |
| 上一事件、顺序位置 | 在 `e'≺e` 的同主体事件对上按 e 取最大顺序位置，或计数后加 1 |
| 空闲间隔会话、回流 | 由前一事件时间计算间隔；会话号为切分点指示值的累计 |
| 从未做过 X | 在完整声明窗口内，沿 actor 对“非 X”取全称像 |
| 累计余额 | 已知初始余额加增量的累计；增量窗口不提供初始余额 |
| 右删失时长 | 已知起始与终止定义时，以终止时间或观察截止时间计算 `(duration,censored)` |
| 时刻状态、停留时长 | 在已构造的 Interval 上按 `start≤t<end` 取值，或对完整区间时长求和 |

无前驱事件的首成员须由首事件或左截断规则处理；前驱时间无定义时，不能直接相减。
窗口内首次不自动等于历史首次。转移次数须读取转移轨迹；合并后的占用区间可能已丢掉自循环等转移。
按主体与时刻求单一状态时，须有覆盖且唯一的匹配区间；否则须声明多值结果或拒绝求值。

### S1 窗口的纤维表示（核心归约的应用）

给定显式窗口关系 `W⊆Event×Event`，第一分量为输出事件，第二分量为被消费事件。
令 `a:W→Event`、`p:W→Event` 为两投影，交换幺半群 S 上的方法摘要 `λ:Event→S` 已有定义，
完成函数为 `φ:D_φ→B`、`D_φ⊆S`。
按核心的取值、纤维归约与基础规约定义，窗口结果是 `Map(φ,a_*(p^*λ))`；`a^{-1}(e)` 恰为 e 的窗口成员。

目标网格保留全部输出事件及其声明的坐标绑定，不使用被消费事件的坐标替代输出坐标。
结果有定义要求每个窗口摘要均在 `D_φ` 内；存在空窗口时要求 `0_S∈D_φ`，没有输出事件时为空族。
窗口、覆盖及求值检查须保持同一范围（核心 L7）；S1 不声称任何状态转移都等于某个窗口聚合。

## 4. 有序折叠与领域构造器

### 4.1 有序折叠

给定状态集 S、初态 `s₀` 与部分转移 `δ:S×Event⇀S`，把主体 u 的事件排成序列 `w_u`：

$$
\operatorname{fold}(s_0,())=s_0,\qquad
\operatorname{fold}(s_0,w\cdot e)=\delta_e(\operatorname{fold}(s_0,w)).
$$

转移无定义时折叠失败。序列连接满足结合律，通常不交换；与核心的交换幺半群归约使用不同前提。
每段序列也可表示为状态转移函数，连接对应函数复合，但该表示不承诺有限大小或高效计算。
本文的 fold 专指这种带初态的有序状态折叠。semantic/DSL 的
[时间样本规约](../semantic/expression-model-redesign.md#32-时间角色和时间样本规约)
以 per(采样轴) 后的 reducer 规约已完成子指标，不提供初态、状态转移或序列回放。

### S2 忽略顺序的信息不足（T1 的推论）

固定初态 `s₀` 与转移 δ，令 𝒲 为满足声明的顺序、边界约束且折叠成功的允许序列集。
若 `w,w'∈𝒲` 的无序 bag 相同而 `fold(s₀,w)≠fold(s₀,w')`，则只保留 bag 不能确定终态；这直接应用核心 T1。

局部非交换可给出这样的见证：存在合法前缀 p，令 `s=fold(s₀,p)`，且 `p·a·b,p·b·a∈𝒲`，
满足 `δ_b(δ_a(s))≠δ_a(δ_b(s))`。可达性与两种完整序列均被允许缺一不可。

反例：状态为 `{0,1,2}`，事件只有 a、b；令 `δ_a(0)=δ_b(0)=0`，`δ_a(1)=δ_a(2)=2`，`δ_b(1)=δ_b(2)=1`。
从 `s₀=0` 出发终态恒为 0；不可达状态 1 上的 ab 得 1、ba 得 2，不能作为该初态下的信息不足见证。
若事件同时保留明确排序键，bag 仍可编码序列并经排序执行 fold；S2 不否定这种实现。
把 fold 单列是为了显式声明顺序、转移和边界，不依赖计算复杂性猜想，也不把它藏在无声明的聚合函数里。

带消耗的匹配、带守卫的状态机、依赖此前切分的会话、FIFO 消耗都可用这样的 fold 描述。
它们不自动获得交换律；仅证明终态相同也不证明转移轨迹或中间输出相同。

### 4.2 领域构造器

构造定义 C 声明主体内顺序 ≺、状态、初态来源与转移、截断政策 β、输出投影。
令 `U₀=M=⟦P⟧_{𝓘,Γ}` 为目标主体域；Γ 绑定观察边界与定义所需的事件范围 `E⊆Event`，
要求 `actor(E)⊆U₀`。其在该环境中的求值简记为 `C(U₀,E)`。
U₀ 可由某个事件范围的主体像选出，构造所用 E 则按自身声明绑定；二者的窗口与过滤不必相同。
需要 Journey、Step 或 Interval 历史时，折叠状态或显式输出轨迹必须保留相应信息，不能只保留终态。

在固定参数与边界下，每个主体独立构造，`C(U₀,E)=⊔_{u∈U₀} C_u(w_u)`，其中 w_u 是 E 中主体 u 的完整有序事件序列。
输出以主体和主体内键标识；键的生成不依赖其他主体。
在可接受输入上，`U₀=∅` 时输出为空族；无事件主体仍保留在 U₀ 中，`C_u(())` 按其初态与输出定义构造，可能有整窗状态区间。
输出的主体、事件来源与维度绑定由构造声明；来源不能用单一事件表示时使用关系对象，确有缺侧时使用显式部分映射。
窗口之前的必要状态由初态或扩展的事件依赖提供，否则按 β 标记截断或拒绝求值。

### S3 分段折叠

在相关转移均有定义时，`fold(s₀,x·y)=fold(fold(s₀,x),y)`。

*证明：* 对 y 的长度归纳。∎

续算需要完整的中间状态；如果只保留终态标签而丢掉待匹配事件或剩余额度，S3 不授权从标签继续。

### S4 主体过滤穿过构造器

对固定 `U⊆U₀`，令 `E_U=E∩actor^{-1}(U)`，并将求值环境的成员与事件范围同步限制为 `U、E_U`，
不在限制后重新运行 P_E 来改变 U。
两侧输入均可接受，且保留主体的初态、参数、边界、其他绑定与输出定义不变时，
`C(U,E_U)=C(U₀,E)|_U`。

这是逐主体不交并的直接推论：两侧都只保留 `u∈U` 的相同构造结果。

主体网格与事件必须同步限制。例如 `U₀={A,B}`、`E=∅`，已知两主体初态均为 Active，并按定义各输出一个整窗区间；
只过滤空事件集仍输出两个区间，改用 `C({A},∅)` 才只输出 A 的区间。原构造的失败检查按核心第 2.3 节保留。
按时间或事件类型筛选一般会改变保留主体的序列，不能应用 S4。
构造后的量可以按核心规则取值或归约；把这些操作移动到构造之前、重新匹配或重新分段，须另证等价。

## 5. 留存与 Status

### 5.1 Status

行为定义声明判定规则，Γ 显式以 P_E 给出完整目标身份域 `Ω=M` 并绑定窗口。每个成员的判定值类型为：

```text
Status = true | false | pending
```

判定族为 `s:Ω→Status`；pending 表示在现有观察信息和声明的判定规则下尚未确定，是这个领域的结果值。
在固定且完整列举的逻辑输入域上，Status 使用 Kleene 强三值逻辑，pending 对应 U（R1）：

| 运算 | 规则 |
| --- | --- |
| ¬ | true 与 false 互换，pending 不变 |
| ∧ / ∀ | 有 false 则 false；全为 true 则 true；否则 pending；空合取 true |
| ∨ / ∃ | 有 true 则 true；全为 false 则 false；否则 pending；空析取 false |
| 至少 k 个 | true 数 ≥ k 则 true；true 与 pending 总数 < k 则 false；否则 pending |

∃、∀ 分别沿纤维用 or、and 归约；至少 k 个可先合并 `(true_count,pending_count)` 再逐点判定。
观察范围之外尚可能发生的事件，不能因当前没有记录就按空纤维判为 false 或 true；窗口行为须先产生相应的 pending。

### S5 信息单调

固定逻辑输入域，将 pending 有效细化为 true 或 false，且不撤回已确定事实，上表运算已确定的结果不变。

*证明：* 逐项检查：已确定结果由不再变化的证据或计数阈值保证。∎

K3 相对布尔补全可靠但不完全：p 为 pending 时 `p∨¬p` 为 pending，而每个一致补全都为真。

### S6 留存界

固定非空 Ω、行为定义与窗口，并假设存在允许的一致补全。true、false、pending 成员分别为 `K+、K−、K?`，划分 Ω。定义：

$$
L=\frac{|K+|}{|\Omega|},\qquad U=\frac{|K+|+|K?|}{|\Omega|}.
$$

1. 每个允许的一致补全下，留存率都在 `[L,U]` 内。
2. `K?` 的成员判定能联合补全为全假时 L 可达，能联合补全为全真时 U 可达。
3. 有效补充将 `K?` 中互斥子集 P 判为 true、N 判为 false，则 `L'=L+|P|/|Ω|`、`U'=U−|N|/|Ω|`。

*证明：* 最终真成员包含 K+，且包含于 `K+∪K?`，得 1；2 由端点等号条件；3 由 S5 与计数。∎

`Ω=∅` 时留存率及两界均无定义，S6 不适用。
原子独立不保证端点可达：两个成员的判定为 `p₁∨¬p₁`、`p₂∨¬p₂`，K3 界为 [0,1]，每个布尔补全的率却为 1。
这是确定性界，不是置信区间。变更 Ω、定义、窗口或撤回事实不属于单调收缩的前提。
必需输入不满足判定函数的定义域时，不能自动映射为 pending，也不能静默从固定分母中删除成员。

## 6. 边界反例

| 反例 | 被否定的推论 |
| --- | --- |
| 同时刻 activate/deactivate 的顺序改变终态 | 稳定排序就是业务顺序 |
| Active 自循环次数不同但占用区间相同 | 占用区间足以恢复转移次数 |
| 两个曝光都选择同一次最近点击 | 独立窗口匹配自动满足事件消耗约束 |
| 1 月 31 日加购、2 月 1 日下单，按月分别匹配丢掉配对 | 时间切片可穿过构造器 |
| 空闲间隔切分出的会话超过 24 小时 | 固定空闲阈值等于从会话起点计时的上限 |
| 相同终态标签但待匹配事件不同 | 终态标签足以续算 |
| 四周为 true、true、false、pending | “至少三周”已经为 false |
| 用回访事件的主体像作为留存分母 | 自动保留起始人群中的未回访者 |
| 改换目标人群后留存界变宽 | S6 覆盖问题定义改变 |
