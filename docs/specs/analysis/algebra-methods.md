# Marivo 分析代数：模型方法

Date: 2026-10-11

Updated: 2026-10-13

Status: proposed v0.15；项目设计提案，不代表实现完成或已获机器形式化验证。

本文建立在[核心代数](algebra-theory.md)之上，沿用分析 `𝒜=(m,Γ)`、统一的类型化 Domain、
求值 `q:K→A` 以及业务身份、贡献出现与坐标绑定的区分。需要主体的方法在 Γ 中显式绑定
单 Entity 身份域 `M=⟦P_E⟧_{𝓘,Γ}`，不使所有分析都先构造成员集合；本文也遵守
T1 和核心第 2.3 节的有效域约定。
本文的结果编号为 M1–M4。

## 1. 方法定义、上下文与求值

模型方法使用核心的扩展定义 `O_θ(m₁,…,mₙ)`，声明输入输出类型、估计目标、模型与版本、输入要求和失败条件。
Γ 绑定时间、贡献、维度、参照及方法要求的身份域。身份可来自任何已声明的来源，无需独立主表。
随机性 ξ 计入实例的显式求值输入，给定后求值确定。
方法须说明消费子定义已经完成的结果，还是改变输入或上下文后重新求值子定义。
在可接受输入上，输出为声明类型与坐标域上的量集 `q:K→A`；定义保留计算依赖，结果身份按输出域构造。
缺值、失败及其表示属于具体方法契约；若扩展结果类型，后续运算须适用于该类型。

模型结果可以追踪训练数据或抽样来源，但来源本身不保证可按原事实分区归约，也不保证可以从结果值重新拟合。
继续计算分别检查信息是否足够（核心 T1）、目标定义是否允许、实际输入是否可用。
对模型输出格子做统计是一个新的格子归约；它与改变输入后重新应用模型不是同一操作。

## 2. 预测

**签名。** 输入为时间网格 `T×J` 上的观察量集，以及不相交的未来时间集 `T_f`。
输出为 `(T∪T_f)×J` 上的带类型量集，区分 `Observed(value)` 与 `Estimated(point,interval,model)`。
Γ 绑定训练及未来时间域、J 的维度角色与参照；延长时间域保留这些声明的坐标含义。
目标若限定身份群，须明确固定身份域还是各期按 P_E 重选；相同的输出网格不保证相同人群。

**声明。** 模型与版本、训练窗口、预测目标、区间含义与名义水平、层级调和规则，以及输入缺值和失败政策。
未来格子没有已发生的观测事实；预测来源是训练依赖，不能按空观察的 `ε_ρ` 解释未来值。

### M1 预测反例：方法签名不蕴含交换律

仅知道方法输入输出都是量集，不能推出它与其他操作交换。
例如 `R_h` 沿 J 对数值求和，F 输出预测点值，不恒有 `F∘R_h=R_h∘F`。

*反例：* 对两期输入且前值非零的几何外推 `F(x)=x₂²/x₁`：两组序列 `(1,2)` 与 `(2,1)` 的预测和为 `4+1/2=9/2`，
合并后的序列 `(3,3)` 的预测为 3。∎

具体方法可另证交换律，例如核心 L6 的同态规律。对预测，若包含全部拟合步骤的 F 是同一个固定线性映射，
且两侧训练域、成员政策、参照与边界相同，则可用核心第 5.4 节的跨轴规律交换。
“拟合后使用线性公式”不保证重新拟合后的整体过程线性。层级调和是方法另行给出的一致化规则（R3）；
点预测相加也不自动给出具有原名义水平的预测区间。

## 3. 抽样与重抽样

**签名。** 输入声明抽样单位上的有限族 `x:X→A` 与随机性 ξ；X 可为业务成员 M，也可为带身份的贡献或簇。
第 b 个重复有抽取位置集合 `D_b` 和映射 `r_b:D_b→X`，
样本为 `r_b^*x`；全部抽取位置为带重复标签的不交并 `⊔_b D_b`。

**声明。** 抽样单位、有无放回、分层与聚类结构、随机机制及其复现参数、估计目标、参照政策。
配对与聚类结构须保持；抽样权重、分配权重和统计等权不能互换。

有放回抽样允许 r_b 非单射。同一原成员被抽中两次是两个样本位置；来源仍已知，但按原身份去重会改变样本。
这直接使用核心的取值与来源构造，不需要新增“不可追溯”结果类别。

对待重估的子定义 m，方法须声明如何把其成员、贡献及相关属性绑定到抽取位置。
例如按成员抽样时，若原贡献归属为 `u:C→M`，则样本贡献载体为 `D_b×_M C`，保留 (抽取位置,原贡献) 的身份。
若需将整个 m 重求值，定义须同时提升到样本出现类型；只消费完成后的 x 则是另一种较弱输入。
将已提升的定义、实例与上下文记为 `m_b、𝓘_b、Γ_b`，求值为
`q_b=Eval_{𝓘_b}(m_b,Γ_b)`；Γ_b 明确绑定抽取位置及样本贡献。它们是同一次静态分析的派生输入，不是数据更新。
按成员抽样时 D_b 是样本出现域，通过 r_b 保留原业务身份，不能冒充原 Entity 的去重身份域 `r_b(D_b)`。
统一 Domain 仍按完整坐标去重；要保留重复抽中，坐标须含不同抽取位置，不能只存原身份键。
成员级计数与均值按声明计样本出现；涉及 distinct 时仍须声明数原成员还是样本出现。
聚类抽样须连同簇内依赖构造；多值归属与分配不由上述单值 u 的例子自动决定。
跨重复合并时须声明输出坐标的对应及缺侧规则，不能按位置拼接或静默删除格子。

仅保留一次完成值一般不够。对数据 (1,1) 与 (0,2)，样本均值都为 1；
各按原经验分布独立、有放回抽取两次时，重抽样均值的方差分别为 0 与 1/2。
由核心 T1，均值本身不能确定这个重抽样分布；重新求值需要原样本或对该目标足够的信息。

### M2 固定参照与重估参照是不同程序

对统计量 `θ(X,W)`，固定参照 `W₀` 的重复值为 `θ(X_b*,W₀)`；若 W 本身也是估计程序的一部分，
联合重估的重复值为 `θ(X_b*,W(X_b*))`。二者一般不能互换。

*证明：* 取标量重复值 `X_b*∈{1,2}`、`θ(x,w)=x/w`、`W₀=2`、`W(x)=x`，
前一程序的值为 `{1/2,1}`，后一程序恒为 1。∎

声明为固定的标准化权重或份额分母须在重复间保持。若推断目标包含估计参照的不确定性，则方法应显式联合重估。
两种程序的抽样分布可以不同，但不能仅因此断言它们必然针对不同的总体参数。

重复结果是一个量集；把其分位数解释为置信区间，需要另给统计有效条件（R2）。
批次若捕获单次失败，输出值类型须显式区分成功与失败并保留重复位置；未捕获的失败使整次求值失败。
区间方法须声明如何处理失败，不能静默删除后把剩余样本当作完整重复分布。

## 4. 归因分配

**签名。** `attribute(target,basis,rule)` 输出 basis 网格 K 上的贡献量集 c。
target 是被解释的量，basis 是分层或路径等分解依据，rule 是显式分配方法。

**声明。** 目标与分解依据的对应、参照与规则版本、进入或退出分层的政策、负贡献是否允许。
分配不是因果证明，贡献的来源也不自动成为原事实的不交分区。

### M3 守恒不唯一确定分配

在 `c∈ℝ^K`、`|K|≥2` 时，仅约束 `Σ_k c_k=target` 不能唯一确定 c。

*证明：* 对任意解 c、`k₁≠k₂` 及 `ε≠0`，`c+ε(e_{k₁}−e_{k₂})` 是另一个解。∎

额外规则可以进一步限制解；守恒只核对数值，不能代替这些规则。可加量在完整互斥分区上的跨期差，
在两期对应完整且均为实数值时，可由各分层差值组成守恒分配（核心第 5.4 节）。

**率的分解。** 在两期相同的非空有限分层 K 上，令分母 `n_{t,k}>0`、分层率 `a_{t,k}∈ℝ`，
`p_{t,k}=n_{t,k}/Σ_j n_{t,j}`、`a_t=Σ_k p_{t,k}a_{t,k}`。Kitagawa 对称分解为（R1）：

$$
a_1-a_0
=\sum_k\frac{p_{1,k}+p_{0,k}}2(a_{1,k}-a_{0,k})
+\sum_k\frac{a_{1,k}+a_{0,k}}2(p_{1,k}-p_{0,k}).
$$

展开右侧即得等式。两项分别按此规则分配为率变化与结构变化，不由守恒唯一选出。
`K=∅` 时总体分母为零，总体率无定义，不适用此分解；不能用空加权和 0 代替该比率。
基期分层 `(num,den)` 为 `(0,0)、(10,100)`，当期为 `(10,100)、(10,100)` 时，两期总体率均为 10%，
但第一层基期率无定义。补成 0 或 10% 得到不同分项；没有显式进入/退出规则时，不适用上述分解。

## 5. 核对

在已对齐、单位与量定义相容且均为实数值时，`reconcile(target,parts)` 的数值残差为 `target−Σ parts`。
覆盖与重复须另由目标成员和分项对应关系判定；只有数值时不能生成“完整分区”的结论。

### M4 零残差不证明完整

`residual=0` 不推出 parts 覆盖 target 的全部事实。

*证明：* 完整分项为 `−100,+30,−30`，target 为 `−100`；只保留第一项时 residual 仍为 0。∎

同理，重复与遗漏可以数值抵消。残差、覆盖和出现次数是不同信息，适用核心 T1。

## 6. 边界反例

| 反例 | 被否定的推论 |
| --- | --- |
| 分组几何预测之和 9/2，总量预测 3 | 预测可自动穿过汇总 |
| 有训练来源但没有未来观测事实 | 知道来源就能按观察量上卷 |
| 固定分母与每次重估分母给出不同重复分布 | 参照政策不影响重抽样 |
| 重复抽中同一成员后按原身份去重 | 来源相同就只应计数一次 |
| 删除失败重复后计算分位数 | 剩余重复自动保留原区间有效性 |
| 两种分配都满足守恒 | 守恒唯一确定分配 |
| 分层组件完整，但某层分母为零 | 信息完整就保证率分解有定义 |
| 正负遗漏相互抵消、残差为零 | 零残差证明完整分区 |
